# 01 モデル間の正解率の差で、良いトリックを選べるか

「Sonnetには解けずOpusには解ける謎は、良いトリックと言えるのではないか」という仮説を確かめた実験。短編ミステリーを書き、問題編だけを各モデルに解かせ、解決編まで読ませた別のエージェントに採点させて、7稿まで改稿した。

## 結論

- Sonnetには解けずOpusには解ける差が出たのは、問題が曖昧だった第1稿だけだった。抜け穴をふさいで公正にするほど、Sonnetも正しい筋道で解いた。モデル間の差は、トリックの良さではなく曖昧さを拾っていた。
- 評価役の抜け穴探しに従って条件を足し続けた結果、最終稿は時刻十数個、部屋番号4つ、照明の規則複数を読者に覚えさせる論理パズルになった。人間が読むと情報を整理しきれなかった。
- 原因と、次に作るときの指針は [人間に評価されるミステリーの条件](../../research/人間に評価されるミステリーの条件/report.md) にまとめた。

## 方法

- 解答役: Haiku・Sonnet・Opusのサブエージェントと、Codex CLI（`scripts/run_codex.sh`）に問題編だけを渡し、犯人・決め手・確信度を答えさせた。正解は、犯人と決め手の筋道の両方が合っているもの。
- 評価役: OpusとSonnetのサブエージェントに問題編と解決編を渡し、抜け穴・公正さ・意外さ・読み返したときの納得度を採点させた。
- プロンプトは [prompts.md](prompts.md)、稿ごとの結果は [results.md](results.md)。

## ファイル

- `drafts/v1`〜`v7`: 各稿の問題編と解決編。v1は5分間ミステリー「二十一時の窓」、v2以降は「九時の消灯」から「見覚えのある図」へ改稿したもの。
