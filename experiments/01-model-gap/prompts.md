# プロンプト

## 解答役

サブエージェント（Haiku・Sonnet・Opus）には問題編のファイルだけを読ませた。v1は本文をプロンプトに直接貼った。

```
推理クイズを解いてください。Readツールで <問題編のパス> だけを読み、ほかのファイルやWebは一切見ないでください。本文だけから考え、最後に次の形式で答えてください。
犯人: <名前>
決め手: <2〜5文>
確信度: <0〜100>
```

Codex CLIには同じ指示と本文を渡した（`scripts/run_codex.sh`）。

## 評価役

```
推理小説の編集者として、短編ミステリーを厳しめに評価してください。Readツールで次の2ファイルだけを読み、ほかは見ないでください。
- 問題編: <問題編のパス>
- 解決編: <解決編のパス>

評価項目:
1. 抜け穴: 解決編の推理が成り立たない読み方、別の人物が犯人でも矛盾しない筋書き、犯人が言い逃れできる余地を具体的に挙げる。致命的なものとそうでないものを分ける
2. 公正さ (1-5): 解決に必要な手がかりがすべて問題編に出ているか
3. 意外さ (1-5): 一般のミステリー読者が問題編だけで正しい筋道に届く割合の予想（%）も添える
4. 読み返したときの納得度 (1-5): 解決編を読んだあと「最初から書いてあった」と思えるか
5. 改善案: 具体的な修正を3つまで
```
