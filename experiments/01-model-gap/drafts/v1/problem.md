# 二十一時の窓

　十二月の金曜、午後十時過ぎ。工学部四号館の四階で、博士課程三年の牧野が研究室の床に倒れているのが見つかった。後頭部を殴られて気を失っていたが、救急車の中で意識を取り戻した。命に別状はない。ただ、背後からいきなり殴られたので、誰がやったのかは見ていないという。最後に覚えているのは、坂井に声をかけられたあと、しばらくデータを整理していたところまでで、時計は見ていなかった。

　机の上からは、牧野の外付けSSDが消えていた。博士論文の実験データ三年分が入っている。銀色の筐体に猫のステッカーが貼ってあるもので、そのステッカーは、去年の忘年会で修士二年の坂井が全員に配ったものだった。

　研究室は細長い部屋だ。廊下側の壁の端にドアがあり、ドアには顔の高さに小さなガラス窓がはまっている。牧野の机は、ドアを入ってすぐ右、廊下側の壁に向かって置かれている。「誰か入ってくるたびに振り向かなきゃいけない」と、牧野はよくこぼしていた。ほかの学生の机は、奥の窓際に並んでいる。

　駆けつけた助教の霧島は、その夜まで四階に残っていた三人の学生から話を聞いた。

　最初は、牧野を見つけた修士一年の千田だった。
「七時ごろから、一階の図書室で一人で論文を読んでいました。十時に図書室が閉まったので、置きっぱなしだった鞄を取りに戻ったら、牧野さんが倒れていて……」
　図書室は無人の自習スペースで、千田がいたことを証明できる人はいない。牧野とは研究テーマが近く、次の学会でどちらが発表するかを巡って揉めていたことも、研究室の誰もが知っていた。

　次は坂井だった。
「僕は八時半に帰りました。帰りぎわに『お先に失礼します』って声をかけたら、牧野さんは振り向いて『おう、お疲れ』って。そのあとはずっと一人で家にいました」
　霧島がSSDがなくなったことを告げると、坂井は顔色を変えた。
「あの、銀色で猫のステッカーが貼ってあるやつですか？　あれがないと、牧野さんの博士論文は……」

　最後は修士二年の青木だった。
「僕は廊下の向かいの実験室で、九時ちょうどまで装置の片付けをしてました。帰る前に牧野さんに一声かけようと思って、研究室のドアの窓から中を覗いたんです。牧野さんはいつもみたいにパソコンに向かってたんで、邪魔しちゃ悪いと思ってそのまま帰りました。九時十五分過ぎには駅前のラーメン屋にいましたよ。ほら、レシートです」
　レシートの時刻は二十一時十八分。四号館から駅前までは歩いて十五分かかる。

　霧島はしばらく黙ってメモを見返していたが、やがて顔を上げた。

**問：牧野を殴ったのは誰か。霧島は何を根拠にそう判断したか。**
