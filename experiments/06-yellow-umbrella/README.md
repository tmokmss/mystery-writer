# 06 作中の人物もだまされる偽装「黄色い傘」

[実験05](../05-narrative-trick/README.md)の「八月の蔵」への人間の感想を受けて、別の型で短編を書いた。AIの解答役と評価役、[実験04の採点器](../04-scorer/README.md)で確かめながら6稿まで直した。

人間の感想は次のとおり。
- 「二人同時に現れなかったのが偶然なのかどうなのか・警察視点だと老婆が二人いる時点で、誰がやったのかは謎でもなく明確ではというツッコミどころは残るな」
- 「この方針は一旦分かったから、他のを書いてみて」

## 目指す方向

- 05の叙述トリックは読者だけをだます仕掛けで、作中の警察から見れば謎になっていなかった。06では、犯人が作中の人物を実際にだます偽装にした。だまされるのは語り手の娘と、向かいのマスターと、事故として処理する駐在さんで、読者はその証言を通してだまされる。
- 手がかりの型は、コナン・ドイル「白銀号事件」の、夜に吠えなかった犬から借りた（記憶から書いている）。起きるはずのことが起きなかったことを手がかりにする型で、話や仕掛けは借りていない。
- これまでの人間の感想を引き継いだ。
  - 方法と動機をはっきり書く（05）。
  - 全員に動機を持たせる（03）。
  - 人名を減らし、役割で呼ぶ（02）。固有の名前は大家の権藤さんと猫のクロだけにした。

## 結論

- **核の着想:** 背の高い大家の傘がいつも鳴らしていく軒先の風鈴が、その日だけ揺れもしなかった。傘の下にいたのは背の低い母で、大家はもう死んでいた。母は大家が生きていた時刻と場所をずらし、娘を証人にして事故に見せかけた。
- **作中の謎:** 評価役は全稿で「作中の人物にとっても偽装は成り立っている」と判定した。05で人間が指摘した弱点は解消できた。そのかわり、作中では事故として片づいていて、謎を持つのは語り手だけになる。
- **ヒントの量と意外さ:**
  - v1は母を指す描写が多すぎた。少しずつ読ませると、二章（事件の日）まで読んだ時点で3回とも母だった。
  - v2以降は、二章まで読んだ時点で3回とも息子を疑った。最後まで読むと母に移る回と、息子のままの回に分かれた。
  - v5では、三章まで3回とも息子のままで、最後に母へ移ったのは3回中1回だった。
  - 推理する解答役は、全稿でHaiku・Sonnet・Opus・Codexが母を当てた。直感で読む読者役は外し、じっくり解く解答役は当てる、という分かれ方になった。
- **評価役の点:**
  - 方法と動機の分かりやすさは4〜5で、05の前半（v1〜v4）より上がった。
  - 意外さは2〜3から上がらなかった。傘で別人になりすまして死亡時刻をずらす型が知られているため。
  - 同じ評価役に同じ稿を2回回すと、各項目が1点ほど揺れた。1回の点の差で稿の良し悪しを決めないほうがよい。
- **評価役の指摘で直した主な穴:**
  - 手前の欄干の傘は語り手から見えるはず（v2）。
  - 娘が窓を見たのが偶然で、計画になっていない（v2）。
  - 言い争いの声を消すために足した雨音のせいで、風鈴は鳴ったが聞こえなかっただけとも読めた（v3）。風鈴が鳴らなかったことを、音ではなく目で見た事実にして直した。
  - 窓の棚で傘の下が見えないのは語り手だけで、向かいのマスターには体が見えるはず（v5）。マスターが見たのは後ろ姿だけにして直した。

## ファイル

- `drafts/v1`〜`v6`: 各稿の問題編・解決編と、解答役・評価役の回答全文（`answers/`）。v6は、v5の評価の指摘を直した版で、解答役と評価役には回していない。
- 稿ごとの結果は [results.md](results.md)。
