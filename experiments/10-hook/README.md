# 10 引き込みの決まりを足して書いた「百かぞえるまで」

[実験09](../09-fable/README.md)の「甕覗き」への人間の感想（「文章が難しいのと、そもそも話に興味が湧かなくて、余り引き込まれる感じはなかった」「甕」「苧殻」「衣桁」「縹」が難しい、「祖父・叔父、祖母、伯母が見分けづらい」）を受けて書く手順（`scripts/writer_guide.md`）に足した決まりを、同じFable（`claude-fable-5-2`）に全部渡して新作を書かせた。決まりは次のとおり。
- 冒頭で問いを出す
- 事件を問題編の前半3分の1までに起こす
- 語り手を事件の当事者にする
- 平易な文章で書く
- 常用漢字表にない字を確かめる（`scripts/check_kanji.mjs`）
- 続柄の似る人物は名前を添えて呼ぶ

あわせて、舞台を現代の身近な家庭にするよう指定した。評価役（Opus・Codex）と読者役（Haiku・Sonnet）に読ませ、3稿まで直させた。

## 筋

- 夫を亡くした真希は、九歳の息子の陽太と、義母の佐和子の家の二階に住んでいる。春に陽太を連れて実家へ移ると告げた夜、膝が悪くて二階へ上がらない佐和子が、階段のいちばん上から背中を下にして落ちる。二階にいた大人は真希だけで、義姉の千尋は真希を疑い、金曜に陽太を連れて帰ると言う。義弟の修二も居場所を偽っている。
- 真相: 置いていかれないよう家出の荷造りをしていた陽太が、佐和子に取りあげられたリュックを階段の上で引っぱり返し、佐和子は一歩さがって落ちた。
- 核は、天井に貼った光る星のシール。電気を消した直後しか明るくないのに、九時に消したはずの部屋で、十時半すぎの転落直後に星がくっきり光っていた。真希が「この子は眠っている」という安心として見た絵が、直前まで電気がついていた証になる。

## 結論

- **引き込み:** 冒頭の一文（「あの夜、二階にいた大人は私ひとりだった。」）で問いが立ち、事件は問題編の約27%の位置で起き、語り手には「金曜までに潔白を示せなければ息子を連れていかれる」期限がある。常用漢字表にない字は0種。評価役は二つとも引き込みを4とし、方言・専門語がほぼないことを挙げた。ただし実験09で見たとおり、AIの引き込みの点は人間より甘い。
- **核の驚き:** v1では評価役の二つとも、核（星）で一番大きな驚きが出ていると判定した。v2で陽太を指すヒント（「暑がりで布団をけとばす子」「目の下が青い」、歯ブラシが消える場面）を削ると、二つとも、一番大きな驚きは核の外（陽太が母の歯ブラシまでリュックに入れていたこと、祖母が孫をかばって嘘をつき母がそれを受け入れること）に移ったと判定した。
- **犯人当て:** 読者役は4本のうち3本が陽太か真希に目を向け、v1のHaikuだけが千尋と読んで外した。評価役は犯人に届く読者を約45%と予想した。「二階にいた大人」という言い方が、子どもが残っていることを示してしまう。
- **人物の行動の筋:** v1で作者の都合として挙がった次の点を、v2で直した。
  - 刑事が二階のもう一人の陽太に話を聞かない（v2: 真希が聴取を強く拒む場面を足した）
  - 真相を探している真希が、ちぎれた恐竜を「そのまま忘れた」（v2: 千尋が玄関で拾って渡し、真希は言い合いの最中で握ったままになる）
  - 祖母の「行きなさい。二人で」への転換が早い（v2: 歯ブラシを見て、この子は母親と行くと決めていると分かった、と言わせた）
- **v3で直したこと:** v2で問題編から削った歯ブラシが、解決編で「水曜の朝に見あたらなかった」と後出しになっていたので、問題編の水曜の朝に目立たない一行で戻した。あわせて、「二階には、私しかいなかった」の言い切り、解決編の「星など見ていなかった」と問題編の描写の食い違い、千尋の謝罪の根拠を直した。v3は評価役・読者役に読ませていない。

## 人間の感想（v3）

- 「おーこれは結構いいね　陽太が関わってるのはわかったけど、ちょっと親子愛みたいな感傷も入ってるのがいいね　ただの謎解き・ウミガメのスープでは終わってない感じ」
- 「天井で、星が光っている。ひしゃくの七つが、柄の先までかぞえられる　ここもさりげない描写でありながら、鍵となる部分になってるのがいいね」
- 犯人（陽太）は予想できていたが、評価は高かった。効いたのは次の二つと読める。
  - 核の手がかりが、母の安心として書かれた何気ない描写に埋まっていた。
  - 謎解きのあとに、母が息子を受けとめ、祖母がかばい、二人を送り出すという感情の決着があった。
- これを書く手順の「引き込み」の節に足した。
- 評価役が「直さなくてよいもの」に挙げた「蓄光シールの減り方が現実と合わない」について: 「こういう常識的な感覚では7割くらいの人間はそう判断するだろうというものは、保守的に留保置かなくて良い　やや見え見えになっちゃうから」。書く手順と評価役の質問の1番に、この基準（一般の読者の7割くらいが受け入れるずれには説明や断り書きを足さない）を足した。
