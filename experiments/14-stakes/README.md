# 14 台東区・鳥越祭を舞台に事件性を持たせた「読み合わせ」

[実験13](../13-stranger/README.md)の「九時のコロッケ」への人間の感想を受けて書く手順（`scripts/writer_guide.md`）に足した決まりを、同じFable（`claude-fable-5-2`）に渡して新作を書かせた。人間からは、台東区を舞台にするよう頼まれた。足した決まりは次の三つ。
- 謎には事件性（損、盗み、失踪、死、だまし）を持たせ、感傷は事件の真相の上に乗せる（実験10〜13は四作続けて「善意が誤解されていた」型で、「謎解きをするには、平和すぎる」と言われた）
- 常用漢字表にある字の語は漢字で書く（「ひらがな多すぎる」「小学生向けの本みたい」と言われた）
- 真相の中心にある決断は、その人が取れたもっと小さな選択肢と比べても、その決断になる理由があるかを確かめる（「客が一人去るので、やっと店をしめられる」が分からないと言われた）

評価役（Opus・Codex）と読者役（Haiku・Sonnet）に読ませ、3稿まで直させた。

## 筋

- 舞台は台東区鳥越、六月の鳥越祭の金曜から日曜。語り手のふみは提灯屋の孫で、三年前に亡くなった祖父から、町会の奉納板（寄付をくれた人の名前と金額を一枚ずつ札に書いて並べた板）を書く仕事を継いだ。札は、会計の徳さんが清書した一覧を見て書き、二人で読み合わせる。日曜の夜の総会では、三年続けて四十万ずつ足りない会計を理由に、町会の神輿をやめるかどうかを決める。
- 事件: 土曜の朝、町を出た十二人の札だけが墨で塗りつぶされている。その十二人は、日曜の十時にバスで祭りを見に来る。町を出た者を嫌う魚屋の勝さんに疑いが向く。ふみは、勝さんの話から、松戸へ移った小沢さんの寄付が祖父の死後に五万円から五千円に減ったと知り、「出た人は祖父に義理があっただけだ」と傷つく。それでも、自分も町を出ていた人間として十二枚を書き直す。
- 真相: 祖父の生前、町を出た人は手紙を添えた現金書留を祖父の店へ直接送っていた。祖父の死後、書留は徳さんの店に届くようになった。徳さんは妻の施設の費用のために、十二人の寄付を十分の一に書いて差額を抜いていた。十二人が来ると決まった夜、札の額を本人たちに見られないよう、自分で墨を塗った。
- 一番驚かせる所: 日曜、十二人が書き直された札の前で同じ顔になり、小沢さんが「字が一つ違う。千じゃねえ。万だ」と言う。出た人の心が離れたように見えたことも、町が出た人を憎んで塗ったように見えたことも、一人の盗みが作ったうそで、その額を書いたのはふみの筆だった。
- 感情の決着: ふみと徳さんの関係だけに絞った。最後の読み合わせで、徳さんに本当の額を読み上げさせ、ふみが十二枚を書き直す。抜いた額の合計（三十九万六千円）は、三年続いた四十万の不足とほぼ同じだった。

## 結論

- **事件性:** 前作までの「善意が誤解されていた」型をやめ、横領とその口封じを核にした。v3では評価役の二つとも、一番大きな驚きは核の反転（嫌がらせに見えた墨塗りが、本当の額を隠すためだった）にあると判定した。Opusは意外さを4とした。実験10〜13で意外さが4だったのは、評価役の延べ24回のうち1回（実験10のv2のCodex）だけだった。
- **犯人の見当:** v1では、徳さんを指す材料（会計の役、遠方の書留が徳さんの店に届く、札を外せと言う、施設の費用、寝ずの番）が一人に集まり、読者役は二人とも徳さんを当てた。v2・v3でこれを「会計として帳面を読み上げる人」一つに絞り、町が出た人を憎んでいるという別の読みを感情の描写で立てた。すると、Haikuの読者役は勝さんを犯人と読むようになり、v3では核で一番驚いた。Sonnetの読者役は3稿とも徳さんを当て、一番驚いたのは周辺（四十万の不足が抜いた額と合っていた）だった。お金が消え、額を書いた一覧を会計が作る、という組み合わせでは、ミステリーを読み慣れた読者は会計を疑う。
- **核を先に見せすぎる:** v1では、三章で祖父の控え帳を開いて十二人とも「万」だったと見せていた。Opusは、核の半分が問題編で割れると指摘した。v2で小沢さん一人の一ページに絞り、v3では勝さんの台詞の「五万から五千円」だけにした（v2では台詞と控え帳の両方で見せていて、Codexが「千じゃねえ。万だ」の前に逆算できると指摘した）。
- **公正さとの引きかえ:** v3でCodexは公正さを3に下げた。徳さんを疑うところまでは問題編で届くが、徳さんが何を隠しているかを決める情報（書留の届け先が祖父から徳さんに変わったこと）が解決編に集中している、という理由。手がかりを減らすと、公正さの判定が下がる。
- **表記:** 漢字の割合は問題編・解決編とも35〜37%。常用漢字表にない字は「輿」（神輿）だけ。
- **評価のあとの直し:** v3の評価のあと、本文を二か所直した（再評価はしていない）。一つは、Opusが指摘した筆順の誤り（「千の字の最後の払い」。千の払いは一画目）で、「千の字の縦の一画」にした。もう一つは、Codexが指摘した結末の「万の字を書く。三年、一度も書かなかった字だ」。ふみは今年も「金十万円」などの札を書いているので、「この段には、三年、一度も書かなかった字だ」にした。
