# 11 感情の描写に手がかりを埋めた「木曜の弟子」

[実験10](../10-hook/README.md)の「百かぞえるまで」への人間の感想（「親子愛みたいな感傷も入ってるのがいい」「ただの謎解き・ウミガメのスープでは終わってない」「さりげない描写でありながら、鍵となる部分になってるのがいい」）を受けて書く手順（`scripts/writer_guide.md`）に足した決まりを、同じFable（`claude-fable-5-2`）に渡して新作を書かせた。足した決まりは次の三つ。
- 核の手がかりを語り手の感情として書いた何気ない描写に埋める
- 謎解きのあとに人物どうしの感情の決着を置く
- 常識で7割の読者が受け入れるずれには説明や断り書きを足さない

前作の課題だった「犯人の見当がつきやすい」を直すこと、前作と同じ型（子どもが犯人、家族の中の事故、光る物の手がかり）を避けることも指定した。評価役（Opus・Codex）と読者役（Haiku・Sonnet）に読ませ、3稿まで直させた。

## 筋

- 時計屋の父が死んで三週間後、ばらばらの部品だった修理途中の時計が、鍵のかかった店で組み上がって動いていた。娘の千夏は子どものころから父に作業台をさわらせてもらえず、父に弟子はいないと思っていた。金曜には兄と店の売却に判を押す期限がある。疑いは、時計好きの不動産会社員、十年前にやめた元弟子、鍵を持つ兄に向く。
- 真相: 時計を直していたのは千夏の夫。二年前、妻にもらった腕時計を落として止め、父に直してもらいに来たのがきっかけで、木曜の夜ごとに父に習っていた。指がふるえるようになった父の代わりに預かりものを組み、父の仕事として客に返すよう口止めされていた。
- 核は、地震でゆがんだ店の引き戸の音。千夏が開けると「がたん」と鳴るが、父が開けると「ことり」と鳴る。日曜に夫が「貸して」と手をのばしたとき「ことり」と鳴り、千夏はそれを「父が店を開ける音」として聞いて涙ぐんでいた。
- 感情の決着: 父が娘を作業台から遠ざけたのは、母と同じように店の奥で一生を終えさせたくなかったから。父は「千夏は不器用だが耳はいい。わしが戸を開ける音で起きてくる子だった」と夫に話していた。最後に千夏が夫に教わって戸を開け、初めて「ことり」と鳴る。

## 結論

- **引き込み:** 冒頭の一文（「父が死んで三週間たった火曜の朝、父が直しかけていた時計が、動いていた。」）で問いが立ち、時計が見つかるのは問題編の約3割の位置、常用漢字表にない字は0種。評価役のOpusはv1で引き込みを初めて5とした。ただしv2でHaikuの読者役は、二章の兄と不動産会社員のやりとりが長いところで普段なら一度やめていたと答えた（v3で短くした）。
- **犯人当て:** 読者役は4本とも夫を当てた。v1では、店に三度目の夫が戸を一度で開けたこと、皿を長く見つめる、「日曜までなら、まだ一週間ある」、帰りが遅いのが「一、二年」と、夫を指す描写が重なっていた。v2でこれらを削ったが、評価役は夫に届く読者を約45%のままと予想した。容疑者が男性四人で、三人が問題編の中で一人ずつ外れていくので、消去法で夫が残る。
- **核の驚き:** v1では評価役の二つとも、一番大きな驚きは核の外（泣かなかった夫の理由、父が娘の耳のよさを知っていた）にあると判定した。v2で決め手を「一度で開いた」から「音が父と同じだった」に移し（千夏が開けると「がたん」と鳴る描写を足した）、Opusは核の「ことり」の反転で一番驚くと判定を変えた。Sonnetの読者役も「ことり」が戸の音ではなく父の手の音だった点で「とても意外」と答えた。Codexはv2でも周辺（父の口止めの理由と夫の罪悪感）のほうが驚くとした。
- **v3で直したこと:** 兄に「正人くんか」と夫の名を一度出させ、千夏に「父と天気の話しかしなかった人よ」と笑い飛ばさせた（作中で一番自然な候補に誰も触れない不自然さを消し、読者の疑いを一度そらす）。夫の腕時計を問題編に一度出した。夫が売却を止めなかった理由、手紙を持ち帰った翌日にまた店に来た理由を夫の台詞に足した。解決編の「誰の手か見ていない」を「夫の手がなぜあの音を立てられたのかを、考えもしなかった」に直した。v3は評価役・読者役に読ませていない。
