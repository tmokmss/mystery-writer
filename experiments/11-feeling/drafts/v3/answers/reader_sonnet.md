## 手順1（問題編を読んだ直後の印象）

**何が起きたと思うか**
- 犯人は夫の正人だと思います。
- 方法は、父の生前から預かっていた鍵（行方不明の予備の一本）で夜に店へ入り、父に習った腕で時計を直した、というものです。
- 動機は、父の指が震えて店が閉じかけていたので、父の仕事と店を最後まで助けたかった、ということだと思います。千夏に黙っていたのは、父が娘に継がせたがらなかった事情に配慮したか、父から口止めされていたからでしょう。
- 兄の健一、弟子だった森下、不動産屋の片岡は、本人たちの否定と状況から外れます。そのため、消去法でも夫が残ります。

**怪しい、後で使われそうと思った描写**
- 「鍵は回ったのに、戸が開かない」のに、夫が横から手をのばすと「ことり、と小さな音がした」。夫は戸のコツを知っているように読めます。
- 「父と夫は最後まで、天気の話しかしなかった」。これは逆に、実は親しかったことを隠す書き方に見えます。
- 夫が皿のふたへ手をのばし、「さわらないで」と止められて「……細かいな」と言う。
- 「誰が直すのよ、こんなの」に夫が答えず、腕時計を見て二階へ話を逸らす。
- 片岡の「きれいに洗ってありますね」。
- 「帰りが遅いのは、このごろずっとだ」、「ひとごとじゃない」、「父の葬式でも、この人は泣かなかった」。
- 「悪さをしに入ったわけじゃないだろ。直して、帰っただけだ」。夫は侵入者の心理を知っているような言い方をします。
- 「戸は、父の言うことしか聞かない」「鍵が二つあるようなもんだ」と、予備の鍵が二階のどこからも出てこないこと。
- 敏子さんの「木曜の晩」「男の人」「自分で鍵を出して、戸を開けて入っていった」という証言。「健ちゃんじゃない」と兄を除外しています。
- 「不動産屋の若い人も、晩によく来てた」。これはミスリード、または片岡も何か知っているという匂わせに見えます。
- 「ねじを締める順番まで同じだ。ただ、油がほんの少し多い」「ていねいで、たぶん、遅い。本職じゃありません」。
- 返事の便せんだけが持ち去られ、名のりもしないこと。
- 父の指の震え（湯のみを両手で持つ）。
- 札の「命日　必ず」と、三好さんの時計の期限。

**章ごとの続きを読みたい気持ち**
- 一：4。「父が直しかけていた時計が、動いていた」という書き出しで引き込まれました。ただ、夫の描写がやや多く、話の方向が早めに読めてしまいます。
- 二：5。「木曜でもないのに」という敏子さんの話と、「父は、鍵を渡していた。」の段落で一番上がりました。
- 三：4。森下さんの見立てと、便せんが消えるくだりは面白いです。一方で、夫が犯人だと自分の中でほぼ固まったので、少し落ち着きました。
- やめるかどうかについては、短いので最後まで読みます。やめるとすれば、夫が犯人だとほぼ見えた二章後半の「ひとごとじゃない」のあたりです。

## 手順2（解決編を読んだ後）

**明かされた事実ごとの印象**

| 事実 | 印象 | 理由 |
|---|---|---|
| 犯人は夫だった | 予想どおり | 手順1で名指ししたとおりです。 |
| 戸を開ける「ことり」という音は戸の音ではなく、父の手の音だった。地震後は誰にも鳴らせず、夫の手だけが同じ音を立てた | とても意外（おー） | 一章の冒頭で泣きそうになった音が、犯人の手がかりだったことに驚きました。ただ、「夫は戸のコツを知っているのでは」とは感じていたので、完全な不意打ちではありません。 |
| 夫が木曜に通い始めたきっかけは、妻にもらった時計を落として壊し、言えずに持ち込んだことだった | 少し意外 | 結婚のときに選んだ時計が、始まりと現在をつないでいます。動機の予想より具体的で、よくできていると思いました。 |
| 父の指の震えが半年後に始まり、「お前の手を貸せ、目はわしが貸す」と言われた | 予想どおり | 震えの描写で予想できていました。「目はわしが貸す」という台詞は良かったです。 |
| 父が「千夏にも健一にも言うな」と口止めしていた | 予想どおり | 口止めがあるだろうとは思っていました。 |
| 父が千夏に言わなかった理由は、母がこの店の奥で一生を終えたので、娘を同じにしたくなかったから | 少し意外 | 「さわるな」は排除ではなく守るためだった、という反転です。ただ、これは問題編に手がかりが少なく、後出しに感じました。 |
| 「耳はいい。戸を開ける音で起きてくる子だった」と父が言っていた | とても意外（おー） | 冒頭の「子どものころ、二階の布団の中で、毎朝この音を聞いた」が、父の知っていた事実につながりました。一番胸に来た箇所です。 |
| 夫が父の胸の異変を二度見ていたこと、葬式で泣けなかった理由 | 少し意外 | 「葬式でも泣かなかった」の伏線が回収されました。ただ、「行っとる」と言われて信じた、という悔いは少し唐突でした。 |
| 三好さんの時計は、父がばらして洗ったところで止まっていた。夫が組めば父の仕事ではなくなるので、預かりものを直していた | 予想どおり | 「きれいに洗ってありますね」から予想できました。 |
| 森下さんの「ていねいで、たぶん、遅い」という手の見立てと、夫の手が一致した | 予想どおり | 「本職じゃない」と言われた時点で夫に決まったように感じました。 |
| 便せんは夫が持ち帰っていた | 予想どおり | 持ち去られた時点で、犯人の持ち物になったと分かります。 |
| 兄は中学で父に愛想をつかされたと思っていた | 少し意外 | 兄にも別の痛みがあったことが、短い台詞で分かります。 |
| 片岡さんは時計の数を数えていただけで、事件とは無関係 | 予想どおり | 赤いニシンだろうとは思っていました。 |

**一番「おー」となったのはどこか**
- 戸の「ことり」という音が、父の手の音であり、夫が同じ音を立てられるとつながった箇所です。その延長で、父が「戸を開ける音で起きてくる子だった」と言っていたと分かる箇所でも、同じくらい強く感じました。

**作者が一番驚かせたかったと思う真相で、実際に一番驚いたか**
- 作者が一番驚かせたかったのは、「夫が父の弟子で、父の死後も預かりものを直していた」という点だと思います。その点には、あまり驚きませんでした。
- 実際に一番驚いたのは、先ほどの「戸の音は父の手の音で、娘はそれを聞き分けていた」という点です。結果としては、作者の狙いより一段深いところで驚きました。

**引っかかった文や読みにくかった文**
- 「開くことは開くのだ。三週間、来るたびにこうしている。」は、問題編との整合に引っかかりました。問題編の千夏は三週間「来るたびに戸を開けている」とは書かれておらず、日曜と火曜の二度だけに見えます。「三週間」という数も、読んでいて合わなく感じました。
- 「この店に来るのは三度目のはずの人の手だ。前の二度は、どちらも地震より前になる。」は、解決編で初めて出る後出しの情報です。問題編では「結婚の挨拶と、五年前の母の葬式と、今日で三度目」としか読み取れません。三年前の地震より前の二度だったことに、問題編では気づけません。
- 「父が死んでから、私はその音を一度だけ聞いている。」は、「その音」が何を指すのか、一瞬分かりにくかったです。
- 「君にもらった時計」と「私がこの店で選んだ時計」は、どちらの時計か少し混乱しました。「結婚のとき、私がこの店で選んだ時計」という説明で分かります。
