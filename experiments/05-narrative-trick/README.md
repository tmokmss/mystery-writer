# 05 叙述トリックの短編「八月の蔵」

実験02・03への人間の感想を受けて、叙述トリックを使い、全員に動機を持たせ、無関係な細部を散りばめ、解決編を短くした短編を書いた。AIの解答役と評価役、[実験04の採点器](../04-scorer/README.md)で確かめながら4稿まで直した。

人間の感想は次のとおり。
- 「どれもバー超えてないな」「時計v4は説明しすぎてて容易に予測できる」
- 「見慣れな図はそもそも動機持ってるのが久我さんしかいない」
- 「もっと叙述トリックを駆使してほしいな」「無関係な要素も散りばめるべき？」「一つ既存の作品選んで目指す方向を決めたほうがいいかも」

## 目指す方向

綾辻行人『どんどん橋、落ちた』（1999年。記憶から書いている）の、読者への挑戦が付いた短編で叙述トリックを公正に仕掛け、読み返すと全部書いてあったと思わせる作り方を目標にした。参考にしたのは構造だけで、話や仕掛けは借りていない。

## 結論

- **核の着想:** 小学生の語り手が、祖母と祖父の妹（離れで暮らしている）をどちらも「おばあちゃん」と呼んでいる。縁側でぼくとスイカを食べていたアリバイは祖母のもので、読者はそれを犯人にも当てはめてしまう。
- **叙述トリックの公正さ:** 地の文に嘘は無い、と評価役2人が全稿で確かめた。v1では、伯父の「ぼけてきたのかもな」と大人たちの認識が真相と食い違っていて、v2で削った。
- **ヒントの量:**
  - v1はヒントが多すぎ、Haikuを含む解答役全員に見抜かれた。
  - ヒントを減らしたv2以降、Haikuは2回とも「おばあちゃんは一人で、足の悪さは見せかけ」と読んで外した。狙った誤読そのものだった。
  - v3では、Sonnetも「二人いる」までは分かったが、それが祖父の妹だとは特定できなかった（確信度55）。
  - これまでの実験で初めて、解答役の結果がモデルの能力の順に分かれた。
- **評価役の点:**
  - 意外さは3のまま上がらなかった。「同じ呼び名の別人」という型が知られているため。
  - 正しい筋道に届く読者の予想は、35〜40%だった。
  - 物語としての力は、v3でOpusの評価役が初めて4を付けた。
- **採点器の限界:** 少しずつ読ませると、読者役は途中で伯父やゆうちゃんを疑い、最後に「おばあちゃん」へ移った。ただ、二人いることに気づいたうえでの答えかどうかを区別できない。叙述トリックの作品では、名前が合ったかで当否を判定するやり方が使えない。
- **人間の読者の感想:** まだ無い。

## ファイル

- `drafts/v1`〜`v4`: 各稿の問題編・解決編と、解答役・評価役の回答全文（`answers/`）。
- v4は、v3の評価で指摘された「膝の白いほこりが蔵の二階のものだという裏付けが問題編に無い」を直した版で、解答役と評価役には回していない。
- 稿ごとの結果は [results.md](results.md)。
