# 「八月の蔵」編集者評

## 総評（先に結論）

「おばあちゃん」という呼び名一つで、祖母と祖父の妹の二人を一人に見せる仕掛けは、子どもの語り手にとって自然な呼び方なので無理がない。杖・コーヒー・「兄さん」の三組の矛盾も、問題編の中で正しく働いている。ただし、次の三点で完成度を落としている。
- 伯父の「ぼけてきたのかもな」は、真相を知っている作中人物が言うはずのない台詞で、読者を誤らせるために登場人物をねじ曲げている
- 「ひとりきりでいたのはゆうちゃんだけ」という大人たちの認識は、現場に最初にいたのが離れのおばあちゃんである以上、作中では成り立たない
- 犯人を決める根拠が「現場に先にいた」と「動機がある」だけで、推理になっていない。解決編で語り手が母に「茶碗の数」を話すのは、読者向けの手がかりを作中の人物に持ちこんでしまっている

## 1. 抜け穴

### 直すべきもの

1. **伯父の「また兄さんって言ってる。最近多いなあ」「ぼけてきたのかもな」（問題編59〜65行目）**
   伯父は、離れに祖父の妹が住んでいることを当然知っている。その妹が祖父を「兄さん」と呼ぶのは普通のことで、伯父が笑ったり「ぼけ」を疑ったりする理由がない。この台詞は、杖の祖母が言ったと読者に思わせるためだけにある。地の文の嘘ではないが、登場人物に真相と食い違う反応をさせており、読み返した読者には「ずるい」と受け取られる。解決編が「ぼけたのではない」と書いて自分で打ち消しているので、なおさら目立つ。

2. **「ひとりきりでいたのは、二階で寝ていたというゆうちゃんだけだ、と大人たちは思っているようだった」（95行目）**
   母と叔母は、蔵の戸口で息を切らしている離れのおばあちゃんを見ている。杖の祖母も、縁側にいたのが自分と孫だけだったと知っている。刑事が「大人たちは一人ずつ」訊いたのなら、離れのおばあちゃんにもアリバイが無いことはすぐ分かる。「思っているようだった」と語り手の推測にしているので地の文の嘘ではないが、作中の大人たちの認識として成り立たない。

3. **犯人を決める推理が無い**
   離れのおばあちゃんが戸口に先にいて息を切らしていたのは、音を聞いて離れや畑から走ってきたからだ、と言い逃れできる。家・離れ・蔵の位置関係が書かれていないので、「先に着けたはずがない」とも言えない。解決編は「二人いた」「戸口にいたのはもう一人」「動機がある」を並べただけで、この人でなければならない理由を示していない。

4. **解決編で語り手が母に「茶碗の数のことを話した」（解決編15行目）**
   茶碗が八つなのは、家族全員にとって当たり前の事実で、作中の誰にとっても手がかりにならない。語り手が母に話すべきなのは「蔵の前にいたのは離れのおばあちゃんだった」ことのはずだ。読者向けの手がかりを作中の会話に持ちこんでいる。同じ理由で、四章の「そして、ようやく分かった」も、語り手は最初から戸口の人物が誰か知っていたので、夜まで気づかなかった理由が要る。

### 直さなくてよいもの

- **茶碗の八つ目を、伯父の妻など別の人物で説明できる読み方**。伯父の妻の有無が書かれていないので、読者が八つ目をそちらに割り当てる余地はある。ただし杖とコーヒーの矛盾が別に効いているので、茶碗だけが決め手になる構造ではない。
- **伯父のアリバイが近所のおじさん一人の証言、母と叔母が互いの証言しかないこと**。別解を全部消す必要はない。
- **蔵の二階に散らばった帳面**。回収されていない細部だが、無関係な細部として許容できる（改善案2で使う案を出す）。

## 2. 叙述トリックの公正さ: 3

- **地の文の嘘**: 見当たらない。どの「おばあちゃん」の文も、二人のどちらかについて正しい。「おばあちゃんたちは仏間で」「台所で母を手伝って、茶碗を八つ並べた」「うしろから、杖の音がゆっくり近づいてきた」はどれもうまい置き方。
- **減点の理由**: 地の文ではなく台詞と語り手の推測で読者を誤らせている箇所がある。伯父の「ぼけてきたのかもな」と、「ひとりきりでいたのは…ゆうちゃんだけだ、と大人たちは思っているようだった」の二つ。どちらも作中で成り立たない認識を使っている。
- **ヒントの量**: 多めで、一部は強すぎる。
  - 叔母の「離れのおばあちゃん、またひとりで山まで行ったの?」は、ほぼ答えを言っている。
  - 四章の「きのうの晩に使った茶碗を食器棚にしまった。一つ、二つ、と数えながら」は、前の晩の茶碗を翌晩にしまうという不自然な場面を作ってまで数を指さしている。
  - 一方、杖の音が「うしろから」近づく描写は控えめで、決め手として一番良い。

## 3. 公正さ: 3

- 探偵役（語り手）が使う手がかりは、すべて問題編に出ている。
- 犯人は二章の朝（裏山から戻ったおばあちゃん）で登場し、一章の「おばあちゃんたち」にも含まれている。早さは十分。
- 減点は、推理の根拠が「現場に先にいた」だけで、犯人だと言い切れる筋道になっていないこと。手がかりは見せているが、その手がかりから犯人へ届く論理が弱い。

## 4. 意外さ: 3

- 一般のミステリー読者が問題編だけで正しい筋道に届く割合の予想: **35%前後**
- 杖の祖母と裏山まで歩く祖母、甘いコーヒーとコーヒー嫌いという矛盾は分かりやすく、「離れのおばあちゃん」という台詞まであるので、違和感には多くの読者が気づく。そこから「二人いる」まで進めば犯人は自動的に決まる。
- 「同じ呼び名で二人を一人に見せる」型は、叙述トリックとしてはよく知られた型なので、時々読む読者でも警戒しやすい。挑戦状が付いていることも警戒を強める。

## 5. 読み返したときの納得度: 3

- 杖が無いと歩けない人と、朝ひとりで山に行く人。砂糖三杯と、においだけでむかむかする人。戸口で息を切らす人と、うしろから近づく杖の音。読み返すと、この三組がきれいにはまる。
- ただ、伯父の「ぼけ」発言のところで、読み返した読者は「伯父がこう言うはずがない」と引っかかる。犯人を決める根拠が弱いことも、読み返すほど目立つ。

## 6. 仕掛けの面白さ: 3

- 「子どもが二人ともおばあちゃんと呼んでいた」は、説明すれば一言で伝わり、人に話しやすい。
- ただ、トリックの型そのものに新しさは無く、「二人いた」以上のひねり（たとえば、二人いることが分かったうえでさらに何かが反転する、など）が無い。話したくなるかと言えば、型を知らない人には話したくなる、程度。

## 7. 動機と機会

| 人物 | 動機 | 機会 |
|---|---|---|
| ゆうちゃん | 一万円を抜いて祖父に叩かれた | 二階でひとり。アリバイ無し |
| 伯父 | 店への借金を断られた | 近所のおじさんと立ち話。第三者の証言あり |
| 叔母 | 再婚を反対された | 母と台所。互いの証言のみ |
| 母 | 特に無し | 叔母と台所 |
| 杖の祖母 | 家を売られる（弱い） | 語り手と縁側。物理的にも無理 |
| 離れのおばあちゃん（犯人） | 離れを売られる。「約束がちがう」 | 誰とも一緒にいない |

- 動機は全員に配られていて、表面上の容疑者の数は足りている。
- ただし、機会のある人物は表向きゆうちゃん一人しかいない。ゆうちゃんは「露骨に怪しい」ため、読者は最初から外し、「アリバイが無いのは誰か、ほかに人がいるのではないか」と考える。結果として、容疑者の多さが読者を迷わせる役に立っておらず、隠された人物を探す方向へ読者を押してしまっている。伯父か叔母のアリバイに小さな穴を作り、二人目の容疑者として読者が本気で疑えるようにするとよい。

## 8. 説明の量

### 問題編
- 四章「ぼくは母を手伝って、きのうの晩に使った茶碗を食器棚にしまった。一つ、二つ、と数えながら。」: 一章の「茶碗を八つ」だけで十分。読者に数を思い出させる場面を別に作っている。
- 二章、叔母の「離れのおばあちゃん」: 答えをほぼ言っている。呼び方を「おばさん」などにして、離れに住んでいることは渡り廊下や明かりで伝えるほうが、読者が自分でつなぐ楽しみが残る。
- 二章、おばあちゃんの「わたしはいいの。においだけで胸がむかむかするから」の直前に、一章の砂糖三杯を「子どもみたいでしょ」とわざわざ強調している点は許容範囲。

### 解決編
- 冒頭の二段落で、どの場面がどちらのおばあちゃんだったかを全部並べている。杖の音の一点だけを示して、残りは読者が思い出すのに任せたほうが、驚きが強く残る。
- 「ぼけたのではない。あの人にとって、おじいちゃんは本当に兄さんだった」: 説明しすぎ。
- 「茶碗は八つあった。…それに、おばあちゃんが二人」: 人数の数え上げは不要。

## 9. 読みやすさ

- 文章は平易で、子どもの語りとして読みやすい。
- 「伯父」と「叔母」の漢字の違い（親の兄と、親の妹）を意識して読む読者は少なく、どちらが母の兄弟かも書かれていない。叔母がゆうちゃんの母であることも、四章の「叔母さんの顔が青くなった」まで確定しない。一章で「叔母さんとその息子のゆうちゃん」と書くとよい。
- 伯父に妻子がいるかが分からないため、茶碗の数を数える読者が迷う。
- 「帳面」は今の読者には少し古い語。「ノート」「手帳」でもよい。
- 人名はゆうちゃん一人だけで、覚えにくさは無い。

## 10. 物語としての力: 3

- 家を売る宣言で家族の不満が一度に噴き出す昼食の場面は、短いが効いている。
- 結末の「来ちゃだめって言ったのにねえ」は、戸口での「来ちゃだめ。見ちゃだめよ」と響き合っていて良い。
- 一方で、犯人である離れのおばあちゃんの人物像が薄い。若くして夫を亡くし、離れで暮らしてきたことは解決編で母が話すだけで、問題編では語り手との関わりが一度も描かれない。語り手がこの人を慕っていたことが問題編で伝われば、真相の痛みがずっと大きくなる。

## 11. 改善案

1. **伯父の「ぼけ」発言を、真相と食い違わない台詞に替える**
   「また兄さんって言ってる。最近多いなあ」「ぼけてきたのかもな」を削り、伯父が「おばさんには関係ない話だろ」と冷たく言い放つ形にする。伯父の苛立ち（借金を断られた直後）が出て伯父への疑いも強まり、「おばさん」という呼び方が、注意深い読者への公正なヒントになる。その場合は二章の叔母の「離れのおばあちゃん」を「おばさん」に弱めて、強いヒントが重ならないようにする。

2. **決め手を「先に着けたはずがない」に作り替える**
   一章で位置関係を一文置く（例: 離れは母屋の裏、蔵とは反対の端にあり、縁側から蔵までは庭を横切ってすぐ）。四章で、離れのおばあちゃんが刑事に「離れにいて、音を聞いて走ってきた」と話したことを書き、「ひとりきりでいたのは…ゆうちゃんだけだ、と大人たちは思っているようだった」を「大人たちが疑っているのは、ゆうちゃんだけのようだった」に替える。こうすると、縁側から音と同時に走りだした語り手より、遠い離れから来た人が先に着いて息を整えていた、という矛盾が決め手になる。解決編で語り手が母に話す内容も、茶碗の数でなくこの矛盾にする。蔵の二階に散らばった帳面に「離れには一生住んでいい」と祖父が書いた約束があった、と解決編で一行添えれば、回収されていない細部も動機の裏付けに変わる。

3. **離れのおばあちゃんと語り手の場面を一つ足し、指さしの強い手がかりを削る**
   二章の朝、裏山から戻ったおばあちゃんが、語り手にだけ「毎年来てくれるのがうれしい」と言ってトマトを一つ渡す、といった短い場面を足す。これで解決編の結末の一言が重くなる。代わりに、四章の「一つ、二つ、と数えながら」の茶碗をしまう場面を削り、茶碗の手がかりは一章の「八つ並べた」だけにする（一章で伯父が一人で来たことを一言書いて、八つ目の数え方の迷いを消す）。
