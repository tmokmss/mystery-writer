# 15 異世界転生ものの「聖剣を盗めるのは私だけ」

[実験14](../14-stakes/README.md)の「読み合わせ」への人間の感想を受けて書く手順（`scripts/writer_guide.md`）に足した決まりを、同じFable（`claude-fable-5-2`）に渡して新作を書かせた。人間からは、異世界転生ものを頼まれた。

書く手順の決まりは数十になり、実験14では「地の文で読みを解説する」のように決まりを形だけ満たす一文が出た。そこで今回は、次の三つを最優先として依頼の冒頭で渡し、書き上げてから残りの決まりに反していないかを確認させた。
- 題材を読者の暮らしに寄せる。異世界転生の約束事（召喚、ステータス画面、聖剣、転生）は説明なしで使い、作品独自の仕組みに謎を頼らない。謎の感情の芯は、読者が自分の経験で分かるもの（家族など）にする
- 犯人の動機に、読者が「自分でもそうするかもしれない」と思える切実さを持たせる（実験14は「お金をちょろまかした小男の話」に見えた）
- 手がかりは減らさず、見え方で隠す。役職や立場から犯人が連想される組み合わせを避ける（実験14は「お金と会計係」で犯人を当てられた）

評価役（Opus・Codex）と読者役（Haiku・Sonnet）に読ませ、3稿まで直させた。

## 筋

- 舞台は異世界の王城。語り手のヒカリは埼玉の高校二年生で、ひと月前、塾の帰りに勇者として召喚された。父はヒカリが二歳のときに事故で死に、母と二人で暮らしてきた。母を一人にしないために、早く魔王を倒して帰りたい。
- 事件: 出立の朝、礼拝堂の祭壇から聖剣が消える。聖剣は異界から来た者にしか持ち上げられないので、礼拝堂には鍵も番兵もない。持てるのはヒカリだけなので、怖くなって隠したと疑われる。宰相は、夜明けまでに剣が戻らなければ帰還の門は二度と開かないと告げる。ヒカリは、三年前に出立して亡骸の戻らない先代の勇者ユウトが、生きて城にいるのではと考える。
- 真相: 剣を盗んだのは世話係の少年ロイ（十五歳）。日本で死んでこの城で生まれ直した転生者なので、剣を持てた。満月の夜に剣を召喚の間の溝に差せば、魔王を倒さなくても門は開く。だが剣が百年眠るので、宰相は勇者に教えていなかった。出立は満月の日の朝なので、ロイは前の晩に剣を消し、薪の束に隠して出立を止めた。
- 一番驚かせる所: 召喚の間で、ロイが「三つの誕生日のケーキは、ちゃんと食べられたか」と聞く。ヒカリは三歳の誕生日まで卵アレルギーで、その日にケーキで卵を試すと決めたのは母と医者と、もう一人だった。ロイは、ヒカリの死んだ父の生まれ変わりだった。ひと月のあいだ卵を出さなかったこと、卵焼きの一口目のあとに首を見ていたこと、うさぎのりんごが、父の行動に変わる。
- 感情の決着: 父と娘の関係だけに絞った。父は、名乗れば娘が残ると言うので、名乗らずに帰すつもりだった。ヒカリは実際に「残る」と言い、父は「佳代を、二度も一人にしないでくれ」と止める。ヒカリは「盗んだのは、私でいいよ」と罪を引き受けて帰る。父の最後の台詞は「盗みは、盗みだ。……許してくれとは言わない。……ただ、今度は、間に合った」。

## 結論

- **犯人を当てられても、核の驚きが残った:** 読者役は延べ6回のうち5回、問題編の時点でロイを犯人と当てた。それでも6回とも、一番驚いたのは「ロイが父だった」という核だった（v2のHaikuは犯人も外した）。評価役も3稿とも二つとも、核で一番大きな驚きが出ていると判定した。実験14では、Sonnetの読者役が3稿とも犯人を当て、一番驚いたのは周辺だった。「誰が盗んだか」と「その人が誰か」を分け、後者を核にした。だから、犯人当てが簡単でも驚きが周辺に逃げなかった。
- **公正さ:** v1では、ヒカリの推理が問題編に無い事実を使っていて、Codexは公正さを3にした（部屋に入れたのはロイだけ、薪を包む麻布）。v2で麻布を毛布の晩の感情の描写に一度だけ置き、v3では卵アレルギーの回想を父の死の段落の後へ移した。v3で公正さはOpus 5、Codex 4に上がった。ヒントを減らさず置き場所を変えたが、父まで届く読者の予想は30〜35%で変わらなかった。
- **題材:** 評価役も読者役も、異世界の仕組みが分かりにくいとは指摘しなかった。謎に使った決まりは「聖剣は異界の者にしか持てない」と「満月の夜に剣を溝に差すと門が開く」の二つだけだった。
- **残った弱さ:** ロイが盗んだ朝にヒカリへ「今夜まで待って」とさえ言わなかった理由は、3稿とも評価役に弱いと言われた。v3の理由は「話せば、ヒカリはロイを守るために剣を戻すほうを選ぶ」。帰還の仕組みが解決編のロイの立ち聞きの話で初めて分かる点も、Codexに3稿とも指摘された。
- **表記:** 漢字の割合は問題編・解決編とも29〜30%。カタカナの人名・用語が多いので、30%を少し下回った。常用漢字表にない字は0種。
- **評価のあとの直し:** v3の評価のあと、Opusが指摘した設定の食い違いを二か所、問題編で直した（再評価はしていない）。一つは、召喚の間の溝が「何度も差したように」すり減っているという描写で、剣が一度使うと百年眠る設定と合わないので「何度も」を消した。もう一つは、七人の勇者が剣を持って出て戻らなかったのに剣が祭壇にある理由が無いことで、ガレスの台詞に「勇者が山で倒れるたびに、剣だけがひとりでに祭壇へ戻ってくるのを見てきた。七度だ」を足した。
- **読者役の手順違反:** v3のSonnetの読者役は、最初の回で手順1の回答を書く前に解決編を開いた。表には、別の回でやり直した結果を載せた。

## 人間の感想（v3）

- 「いいね　泣いちゃった　家族物に弱いね　文体はなろう小説っぽくはないが」
- 「父が絡んでるのは予想できたけど、そっちが転生してたとはw確かに主人公は転生ではないもんな　そこも伏線だったか」。父が絡むことは読まれたが、転生していたのが父のほうだという点で驚いた。召喚された主人公と転生した父の対比が、伏線として読まれた。
- 「ユウトはなんだったの？縁のあるものが召喚される設定は活かしても良かったか」。ユウトは、生きて城にいるのではと疑わせることと、ロイに「転生」という言葉を教えたことの二つの役目だけで、真相の中で何だったかが無かった。「縁のある者を呼ぶ」という設定も、ヒカリにしか使っていない。
- 「解答編のなんで〜しなかったの？のやりとりが冗長に思えた。一つずつ潰していくのが言い訳くさいと言うか理屈っぽいというか」。v2・v3で、評価役の指摘（朝に黙っていた理由、召喚の間に見張りがいない理由、ロイの証言がうそになる点）に答える問答を一、二行ずつ足させた結果だった。評価役の抜け穴の指摘に従うと論理パズルになる、という以前の失敗（`research/` の調査の発端）を、解決編の台詞の形でまた踏んだ。
- 「宰相達がこどもを異界から召喚して剣を持たせて旅に出させるという行動の目的がよくわからない　まあここは匂わせる程度でよいと思うけど　今は剣を眠らせたくない？みたいな理由しかなかった気がする」。v1には「魔王が山から出ない」「王家の習わし」があったが、v2で解決編の説明を絞ったときに消えた。
- 「卵食えたかずっと気にしてた理由がよくわからんかも　アレルギーあるのかないかが気になってたってこと？」。意図は、父は三歳の誕生日の試しを見届けずに死んだのでアレルギーが治ったかを知らず、卵で娘が死ぬかもしれないと思って卵を出さず、一口目のあとは発疹が出ないか首を見ていた、というもの。この理由は本文のどこにも書いていなかった。
- 評価役・読者役は、問答の冗長さ、ユウトの回収、宰相たちの目的、卵を気にした理由を、どれも挙げなかった（評価役は逆に、問答を足す側の指摘をしていた）。
- 「結構オヤジ訳分からなくね　なんでリスクある卵ケーキ買って行ったんだろ」。本文では「医者と相談して、三歳の誕生日に卵入りのケーキで初めて試す」計画で、父はそのケーキを予約しに行く途中で死んだ。卵アレルギーの子に初めて卵を試すのは、ふつうは病院で医者が見ながら少量ずつ行う（記憶から書いた。出典は確認していない）ので、家の誕生日ケーキで試すのは危ない賭けに見える。父が「普通のケーキ」にこだわった気持ちも書いていなかった。たとえば、病院での試験は誕生日の翌週で、父は「治ったら卵のケーキを買ってやる」と約束していた、とすれば、行動も気にかけてきた理由も一度で読める。書く手順の実在の町の決まりを、読者が経験で知っている手順（医療・育児・学校）にも広げた。評価役・読者役の回答は計11回ともケーキの場面に触れていたが、どれも手がかり（「もう一人」が父か）や時系列としてで、父の行動を暮らしの感覚で確かめたものは無かった。読者役の質問に、回想の中の行動も含め、自分や身近な人ならそうしないと思う行動を挙げる項目を足した。
- 書く手順に四つ足した。解決編で問いと答えを重ねて抜け穴を潰さない。人物が長く気にかけてきたことの理由は一度で読み取れる形で書く。疑いを向けるために置いた人物や設定は回収する。敵役や組織の行動には匂わせる程度でも目的を残す。評価役の質問（人物の行動の筋）にも同じ点を足した。
