# 読者役 Sonnet 回答（v3）

## 手順1　問題編だけを読んだ印象

### 何が起きたと思うか

犯人は世話係のロイだと思う。ヒカリが盗んでいない以上、剣を持てるのは異界から来た者だけのはずで、そこが謎の核になっている。ロイが異界の出身者か、異界の血を引く人（たとえばユウトの子、あるいは過去の勇者と関わる人）で、剣を持てるのではないか。

動機は、ヒカリを山へ行かせないこと。七人の勇者が誰も戻っていないので、ヒカリを死なせたくなくて出立そのものを潰したのだと思う。「もし、ほかに帰る道があったら」という発言から、帰還の方法は魔王を倒すこと以外にもあり、ロイはそれを知っているように読めた。

方法は、夜のうちに礼拝堂から剣を持ち出して、どこかに隠す、というところまでは想像できる。ただ、ロイは部屋の前で寝ていたと全員が言っているので、そのアリバイがどう崩れるのかは分からない。

もう一つの可能性として、ロイは実は父親か、帰ってこなかった勇者の関係者で、ヒカリの母のことを知りたがっていたのかもしれない。

### 怪しい、後で使われそうだと思った描写

- 「あの剣は、異界から来た者にしか持ち上げられん。この城でそれができるのは、今、お前一人だ」
- 円の中心の「指が二本入るくらいの細い溝があった。溝の縁だけが、硬い物を何度も差したように、白くすり減っている」
- 「ヒカリ様は、ゆうべ一度も部屋を出ておられません。私が戸の前で寝ていました」
- ロイの「お母上は、お元気ですか」「……そうですか」
- ロイが小刀でうさぎ林檎を作ったこと。ユウトに教わったと言うが、セラは「ユウトは果物の皮もむけず、いつもロイがむいていた」と言っている
- ロイが卵を出さず、卵焼きの作り方を聞いたあと、一口目を食べるヒカリの「首のあたり」を見ていたこと。泣きそうな顔になったこと
- 「勇者は卵を断つ決まりでもあるのかと思って」「卵は、お出ししないことにしています」
- ヒカリが昔、卵アレルギーだったという話と、母が毎日卵を焼いたという話
- 「毎日、ですか」というロイの反応
- 「行くのを、やめることはできませんか」「もし、ほかに帰る道があったら」「忘れてください。あれば、の話です」
- 夜中に毛布を掛け、靴を脱がせ、剣を剣掛けに戻し、薪をくべてくれた人がいたこと。暖炉の横にあった、赤い糸でつぎの当たったロイの麻の布
- 父がヒカリが二歳のときに事故で死んで、顔は写真でしか知らないという話
- 「亡きがらは、戻っていません。七人とも」
- 「あの方が生きて戻ったなら、まっすぐ私の所へ来ます」というセラの言葉
- 夜回りが見たのは「調理場の火の番と、お前の部屋の前で丸くなっている世話係だけ」
- 「出立がなくて得をする者は、この城に一人しかおらん」
- 稽古の日は剣を部屋の剣掛けに掛けておくことが多かったこと
- 「ステータス」の画面。年齢が十七歳で、レベルが1のまま

### 章ごとの、続きを読みたい気持ち

- 一章　4。聖剣が消え、犯人に仕立て上げられて、帰れなくなる期限まで切られる。掴みはよい。
- 二章　4。召喚の場面と母の話で一度落ち着くが、ロイとうさぎ林檎の場面が妙に気になり、続きを読みたくなる。卵アレルギーの話が長めで、少し「何かに使われるのだな」と構えて読んだ。
- 三章　4。卵焼きの場面は温かい。ロイが首のあたりを見ている描写に引っかかり、ここから先が気になる。
- 四章　3。聞き込みが続くだけで、動きは少ない。ただ「七人とも」の一言で持ち直す。
- 五章　4。思い出を並べる章で動きは遅いが、ロイの「もし、ほかに帰る道があったら」が効いて、最後の問いかけに引っ張られる。

途中でやめたくなるほど下がった所は無かった。強いて言えば、四章のガレスの説教の所は少し長く感じた。

## 手順1の最後の推理（まとめ）

ロイが剣を隠した、と見ている。ロイはヒカリを行かせたくなく、剣を持てる理由は分からないが異界に縁のある人物。卵と母にまつわる反応から、ヒカリのことを以前から知っているような気配がある。

## 手順2　解決編を読んだ後

### 明かされた事実ごとの印象

- 剣を隠したのはロイで、夕方から薪の束にくるんでヒカリの部屋の壁に置いていた　→　犯人は予想どおり。部屋に置いてあった方法は少し意外。騎士が調べた後の部屋が一番安全、という理屈が面白い。
- 剣の隠し場所は薪の束の中（麻の布のつぎ当てが目印）　→　少し意外。ロイの布の描写が伏線だったと分かって納得。
- 召喚の間の溝に剣を差せば、満月の晩に門が開く。魔王は倒さなくてよい　→　少し意外。溝の縁のすり減りは気になっていたので、仕掛けの正体としては範囲内。
- 宰相は門の開け方を知っていて、剣が百年眠るのを惜しんで勇者に教えなかった。七人は誰も教えられなかった　→　少し意外。宰相の動機としては筋が通る。
- ロイが剣を持てた理由は、日本で死んで、こちらで赤ん坊から始めた転生者だったから　→　少し意外。異界に縁のある人物とは予想したが、転生という形は想定外。
- ロイはヒカリに選ばせないために、前の晩に剣を消した　→　少し意外。先に話せばヒカリは「ロイを守る」ほうを選んでしまう、という理由が優しい。
- ロイが今朝ヒカリをかばったのは「黙って見ていられなかった」から　→　予想どおり。矛盾には気づいたが、感情で説明されて納得した。
- ロイは、ヒカリの亡き父だった　→　とても意外（おー、となった）。「お母上はお元気ですか」「毎日、ですか」「首のあたりを見る」「卵焼きを褒められて泣きそうになる」が全部ここに繋がった。三歳の誕生日のケーキという細かい情報が決め手になっているのも上手い。父が二歳で死んだという情報が伏線だった。
- 門は来た者を来た場所へ返すだけなので、父は帰れない　→　少し意外。切ないが、一緒に帰る道が閉ざされるのは納得。
- ヒカリが「盗んだのは私でいい」と引き受け、父は「盗みは盗みだ」と返す　→　少し意外。父の人柄が出ていて良いやり取り。
- ヒカリは無事に帰り、母に卵焼きを教わる　→　予想どおり。ただ「息を止めてた」の回収は、おー、となった。

### 一番「おー」となったのはどこか

ロイの「三つの誕生日のケーキは、ちゃんと食べられたか」という問いから、ロイがヒカリの父だと分かる場面。卵焼きの一口目を見つめる目の意味が、ここで一気に分かる。

### 作者が一番驚かせたかった真相と、実際に一番驚いたか

ロイがヒカリの亡き父の転生だった、という真相だと思う。実際にそこが一番驚いた。犯人がロイだというところまでは当てたが、動機が父娘だとは思わなかった。

### 引っかかった文、読みにくかった文

- 「向こうで死んで、こちらで赤ん坊から始めました。転生、と言うのだそうですね。」　→　ユウトから聞いたという説明は分かるが、少し都合がよい。
- 「写真の父は二十九歳で、私を肩車して笑っている。」　→　目の前のロイは十五歳で、年齢のずれを頭の中で整理する必要があった。
- 「お前が呼ばれたのは、たぶん、おれがここにいたからだ」　→　縁のある者を引き寄せるという説明は冒頭にあるが、この一文は少し後づけに感じた。
- 「三つの誕生日のケーキ」　→　「三歳の」と書いたほうが一瞬で通じる。
- ロイの口調が突然「おれ」に変わるのは意図的で効いている。読みにくさは無かった。
