# 03 「どうやったか」で読ませる短編「兄の時計」

[実験02](../02-one-idea/README.md) の「凪」への人間の感想（「誰が殺したかってよりは、どう殺したかのほうが面白いのかも」「蠅帳って馴染みない」「キャラの名前覚えづらかった」）を受けて、謎の中心を「どうやったか」に移した短編を書き、AIの解答役と評価役で確かめながら4稿まで直した実験。

## 結論

- **核の着想:** 「兄が死んだあとも心拍を記録し続けた腕時計は、猫の首に巻かれていた」。評価役は両方とも、全稿でこの核を一文で言えた。
- **トリックの面白さ:** 評価役2人とも、v2以降は4点だった（新しく足した項目）。どちらも「絵が浮かび、人に話したくなる」と評価した。
- **読みやすさ:**
  - 名前のある人物を2人（後藤、ミカ）に絞り、難しい語を使わずに書いた。評価役が挙げた読みにくさは、「十分」が「じゅうぶん」と読めることと、時刻が多いことくらいだった。
  - 先輩の苗字のカタカナ表記（ゴトウ）は、評価役に不自然だと言われてv4で漢字に戻した。
- **解答役の結果:** 全稿で、Haikuを含む全員が犯人とトリックの両方を当てた（17回中17回）。手がかりを公正に置くとAIには解かれる、という実験01・02と同じ結果になった。
- **意外さ:** 意外さはOpusの評価役で2点のまま上がらなかった。容疑者が2人で、「親切な先輩」が典型的な犯人役に見えるため。Sonnetの評価役は3〜4点だった。
- **改稿で直したこと:**
  - 心拍の記録の矛盾（v1では九時より前の記録が兄の生存を示してしまった）。
  - 「兄が自分で猫に時計を巻いた」という言い逃れ（毎晩届く運動会の動画が金曜だけ届かない、で消した）。
  - 一章で手がかりの数字を出しすぎる問題（「百五十」「十時」を一章から外した）。
  - いずれも条件を足すのではなく、物語の中の出来事として直した。
- **人間の読者の感想（v4）:** 「時計v4は説明しすぎてて容易に予測できる」。3作とも「バー超えてないな」。

## 方法

- 解答役と評価役のプロンプトは [prompts.md](prompts.md)。
- 実験02の評価項目に、「トリックの面白さ」「読みやすさ（馴染みのない語・分かりにくい描写・覚えにくい人名）」と、トリックの物理的・技術的な無理を足した。
- 結果は [results.md](results.md)。

## ファイル

- `drafts/v1`〜`v4`: 各稿の問題編・解決編と、解答役・評価役の回答全文（`answers/`）。Codexの回答は最終回答だけを抜き出した。v4の解決編は、評価役の指摘（後藤が嘘をついた理由の説明、再現の場面、通話履歴）を受けて評価のあとに直した。
