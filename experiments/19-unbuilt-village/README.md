# 19 Codex（Astra 6.2）の書いた「窓で買うパン」

[実験18](../18-test-floor/README.md)に続き、人間の依頼で書き手をCodex CLIのGPT-6.2-Astra（`gpt-6.2-astra`）にした。テーマは自由に選ばせた。Astraの前の2作が人間に「認知負荷が高い」と言われたので、最初の数段落で場所・人物・目的を分からせること、人物は初出で名前と語り手との関係を一緒に書くこと、手がかりの物を誰でも知っている語で書くこと、真相を一場面のごまかしで終わらせないことを、特に守るよう指示した。前の2作は問題編が1,200〜1,700字だったので、2,500〜4,000字まで長くしてよいと伝えた。第2稿・第3稿は、同じCodexの会話を再開し、直す場面を挙げて、挙げていない場面は変えないよう指示した。

今回から、最終稿に挿絵を入れた（`scripts/illustrate.sh`）。評価役・読者役は文章だけで評価し、挿絵は評価の後に入れた。

## 筋

- 舞台はダム湖のほとりの資料館。案内図を描く由美が、湖の底に沈んだ杉森村の絵地図を描いている。頼りにしたのは、子供のころ図書室で読んだ『杉森の子』。村が沈んだ年に十一歳だった巻田登志さんが書いた本で、病気で寝ている登志さんが、路地を挟んだ向かいのパン屋の窓から、同級生の冬馬君に焼きたてを渡してもらう場面がある。由美は登志さん本人と、その窓を描き込んでいる。
- 事件: 学芸員の石田香苗さんが、父の冬馬君の遺品から、店の写真と引っ越しの連絡用の古い地図を持ってくる。パン屋は川べりではなく、峠を越えた坂の上の石段の上にあった。由美の絵地図で学校を描いた所は、本当は墓だった。登志さんは「由美さんが描いてくれたパン屋は、私が覚えてる通りよ」と言う。
- 手がかり: 冬馬君が死ぬまで取っておいたお菓子の箱に、子供たちが一軒ずつ作った厚紙の家が入っている。パン屋の模型には、床すれすれに小指の先ほどの穴があり、その下にちぎった紙のパンが詰まっている。横倒しの郵便局の底に〈ひっこしたら〉と鉛筆の字がある。
- 真相: 登志さんの手の家にも同じ低い穴があり、二軒の窓を合わせると紙のパンが渡せる。本の路地は、病気の登志さんの枕元の机に並べた、二軒の紙の家の間の隙間だった。屋根の裏に〈ひっこしたら　とうまのとなり〉。子供たちは、立ち退いた後にみんなで住むつもりの「次の村」を作っていた。登志さんは原稿の冒頭の、机の上の村だと書いた二行を削っていた。
- 一番驚かせる所: 沈んだ村の記録のはずの本に残っていたのは、子供たちが建てたかった、ついに建たなかった村だった。
- 感情の決着: 由美は表を古い地図どおりに描き直し、自分の絵を裏に載せることにする。裏の余白に、登志さんが削った二行を自分の手で書く。

## 結論

- **冒頭は分かりやすくなった:** 第一段落で、資料館、語り手の名前と仕事、沈んだ村の絵地図を描いていることが出る。読者役に足した「どこで誰が何をしている場面か分かったのは何段落目か」の質問には、v1のHaikuが「1段落目で、衣子が資料館で水没した杉森村の地図を描く仕事をしていると分かった」と答え、場面が一つにつながったのは学芸員が出てくる9段落目からだと書いた。
- **長さは前の2作の約2倍:** 本文は問題編約2,900字、解決編約1,200字（v3）で、Astraの前の2作（問題編1,200〜1,700字）の約2倍、Fableの作品よりは短い。
- **犯人当ての形ではなかった:** 「犯人」は本の著者で、悪意のある人物ではない。読者役は延べ6回とも、問題編の時点で登志さんの記憶か書き方が原因だと見当をつけた（25〜75%）。「本の村は模型だった」まではv1のSonnet・v2のSonnetが当てた。「次に住む村だった」まで当てた回は無かった。6回とも、一番「おー」となったのは、次に住む村だったこと（4回）か、本の村や路地が紙の家だったこと（2回）だった。
- **評価役の判定:** Opusは3稿とも、核で一番大きな驚きが出ているとした。v3で読み返したときの納得度5、物語5。Codexは物語5、トリックの面白さ4〜5をつけたが、公正さは3〜4にとどめた。v3でも、由美が見た決め手（登志さんの家の模型、屋根裏の字の全文）が解決編で初めて出る、と指摘した。
- **問題編の終わりの位置を2回下げた:** v1は登志さんが模型の穴に指を入れて差し出すところまで問題編にあり、Opusは「村は紙の模型だった」がほぼ明かされているとした。v2で指を差し出す動作を、v3で登志さんの手の家にも穴があると気づく段落を、解決編へ移した。v3でもOpusは、問題編の最後に「パンだった」まで見せるので一段目は察せられる、と書いた。
- **物語が始まる前の行動の確認:** 登志さんが原稿の冒頭の二行を削ったことを、読者役は延べ5回、納得しにくいか変だと挙げた（v1のSonnet、v2・v3のHaikuとSonnet）。v2で「初めにそう書いたら、冬馬ちゃんがパンをくれた日まで、ただの作り話だと思われそうで」と理由を足したが、v3のSonnetは「本の主題が故郷の暮らしなのに、いちばん大事な事実を削るのは変」と書いた。
- **直す範囲を絞った指示は守られた:** v2・v3とも、前の稿との差分で、指示していない場面は書き換わっていなかった。
- **挿絵:** Codexは2枚を作った。問題編の1枚は、店の写真（石段の上の店とバス停）を由美の絵地図（川べりの店）に重ねた絵で、食い違いを見比べられる。解決編の1枚は、登志さんが瓦を描いた学校の模型を、穴のある自分の家の隣に置く手。どちらも本文と食い違う物は無く、問題編の絵は真相をほのめかしていないことを私が見て確かめた。差し込みのほかに本文が変わっていないことも差分で確かめた。
- **表記:** 漢字の割合は問題編36.4%、解決編33.1%。常用漢字表にない字は0種。
- **評価のあとの直し:** v3の評価のあと、四か所を直した（再評価はしていない）。パン屋の穴は「小指の先が入るくらい」なのに登志さんが「指を一本」出していたので「小指」にした（Opus）。「ちょうどそこだ」の指す先が分かりにくいので、絵地図で学校を描いた所が墓だった所だと書いた（Sonnetの読者役）。登志さんの告白「今日も私は、あの店が本当に川べりにあったような地図を、あなたに刷ってもらおうとしてたのね」は誰が誰に頼んだか取りにくく、その日に登志さんが表を古い地図どおりにする案を出していたこととも合わないので、「今日だって、裏に載せる絵が机の上の村だってことは、言わずに済ませようとしてたのね」にした（Haikuの読者役、Codex）。「最初に資料館へ来た日」の段落は誰が描いて誰が線を足したか取りにくいので、年配の客と孫の場面として書き直した（Opus）。

### 読み取れること

- **何を解く話か言葉にならなかった:** 本の村と古い地図の食い違いが、店の位置、石段、学校と墓、と増えていくが、由美も地の文も「なぜ本は実際と違うのか」を問いとして言わない。読者は食い違いの列を読まされ、謎解きだと気づかなかった。冒頭の場面は分かりやすくなったが、問いの形が無かった。
- **人物の基本の事実が伝わらなかった:** 「登志」の読み、登志さんが女性であること（本文に女性と分かる言葉は無く、「頂いたわ」のような話し方だけ）、冬馬君が亡くなっていること（「冬馬君が死ぬまで取っておいた工作」という修飾の中だけ）、香苗さんが冬馬君の娘であることが、一度で読めなかった。評価役のOpusはv1で「弓削」「衣子」が読みにくいと挙げたが、「登志」は挙げず、性別と生死に触れた評価役・読者役はいなかった。
- **語り手の切り替え:** 「熱のある日は私も家で窓を開けた」は、本の中の登志さんの場面を要約した段落の続きにある。由美が子供のころの自分に戻ったつもりだったが、本の中の登志さんの続きと読まれた。読者役のSonnetもv3で「手を出した先にあるのは、いつも室外機の風だった」を意味が取れない文に挙げていた。
- **AIが挙げていたのに直さなかった:** 「ずいぶん久しぶりに一つ頂いたわ」は、読者役が3稿で延べ5回、分かりにくい・何の比喩か引っかかると挙げた。評価役のCodexが「初読では親しさの描写になり、再読では紙のパンを受け取る結末と重なる」として残すよう勧め、私は直させなかった。「いくら腕の長い子でも、パンは渡せない」は、評価役のCodex（v2）とOpus（v3）が削ってよいと書いたが、直しの指示に入れなかった。
- **食い違いへの反応:** 登志さんは写真と古い地図を示されても「由美さんが描いてくれたパン屋は、私が覚えてる通りよ」と言うだけで、驚きも動揺も見せない。真相（自分で削った）を隠すための沈黙のつもりでも、読者にはそれが読み取れず、不気味に見えた。評価役のOpusはv2で、冬馬君の死に反応しないことだけを挙げた。
- **Astraの3作:** 実験17〜19の3作とも、人間に「ほとんど理解できなかった」「認知負荷が高い」「マジで意味分からん」と言われた。
- **挿絵:** ペンと鉛筆の線画に淡い水彩を乗せた写実寄りの絵は、写実的すぎた。

これを受けて、`scripts/writer_guide.md` に、何を解く話かを一度言葉にすること、人名の読みと性別と生死を一度で分かるようにすること、他人の話の要約に語り手の思い出を混ぜないこと、ふりと大げさな比べ方、食い違う証拠を出された人物の反応を足した。評価役・読者役の質問にも足した。`CLAUDE.md` に、読者役が二つの稿以上で挙げた文と、評価役が削ってよいと書いた文は直させることを足した。挿絵は、色を付けないか一、二色をごく淡く置くだけの、線の少ないペンの線画にした。
