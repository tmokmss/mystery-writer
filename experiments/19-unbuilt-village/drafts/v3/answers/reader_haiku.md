# 読者回答（Haiku）

## 手順1: 問題編だけを読んだ時点

### 読み始めの印象
- どこで・誰が・何をしているかが分かったのは、第1段落の2文目（「今度の仕事は、ダムの底に沈んだ杉森村を描くことだった」）。由美が資料館で地図を描いている場面と分かった。
- 第2段落で、登志が『杉森の子』の著者だと分かった。この時点で、本と地図の関係が話の中心だと思った。
- 「これは何？」: タイトルの「窓で買うパン」。窓越しに買い物をする村の習慣なのか、比喩なのか分からなかった。
- 「この人は誰？」: 巻田登志（本の著者）、石田香苗（学芸員）、冬馬（登志の同級生。「冬馬ちゃん」「冬馬君」と呼ばれ、後で香苗の父と分かる）。
- 「窓が両方とも低い所にある」「パン屋の屋根を取る」の位置関係が頭の中で描けず、何度か立ち止まった。

### 問題編の内容（自分の言葉）
由美は沈んだ杉森村の地図を描いている。登志は村が沈んだ年に11歳だった人で、本には、路地の向かいのパン屋から窓越しにパンを買ったと書いてある。由美は、屋根を外した上からの絵にして、窓の両方を描こうとした。ところが学芸員の香苗が、パン屋の写真と古い地図を出した。地図では、パン屋は坂の上のバス停の所にあり、登志の家は川べりにある。二軒の間には郵便局も畑もあり、窓越しにパンは渡せない。さらに香苗は、校庭の絵が本当は墓だと指摘した。最後に、冬馬の工作の箱が出てきて、郵便局の底に「ひっこしたら」とあり、パン屋の模型の穴に茶色い紙のパンが詰まっている。

思い浮かべられなかったこと:
- 香苗が何のために写真と地図を出したのか。
- 「ひっこしたら」の続きに何が書いてあるのか（綿に隠れていて書かれていない）。
- 登志がなぜ「私が覚えてる通り」と言い切れるのか。
- 模型の穴とパンが、話の中でどう使われるのか。

### 何が起きたと思うか
はっきりした事件はまだ見えなかった。一番ありそうなのは、登志の記憶（窓越しのパン）と古い地図が食い違っていて、その理由を隠しているという筋。方法と動機は分からない。

### 途中で怪しいと思った描写
- 「由美さんが描いてくれたパン屋は、私が覚えてる通りよ」。古い地図と合わないのに言い切っている。
- 「裏にしたらどうかしら」と登志が言った。表は古い地図の通りにして、自分の絵は裏に回す案。
- 「ずいぶん久しぶりに一つ頂いたわ」。描いた絵のパンを、本当に食べたような言い方。
- 「この子まで写ってる」。写真の犬に目を細める場面。
- 本の一節「冬馬ちゃんのパン屋も、その向かいのわたしの家も、ここにあった」。
- 「ここ、本当はお墓ですよ」。
- 「横倒しになった郵便局の底に、鉛筆で〈ひっこしたら〉とある。続きは綿に隠れていた。」
- 「手のひらにこぼしてみると、細長いのや丸いのがあった。…パンだった。」
- 「登志さんは写真の中の冬馬君の頬にそっと触れた。」

### 続きを読みたい気持ち（本文は途中で区切って読んだ）
- 前半（資料館で本と写真が出るまで）: 4。窓越しのパンという設定が面白かった。
- 中盤（古い地図で二軒の距離が分かり、墓の話が出るまで）: 3。「パンは渡せない」で話の狙いが分からなくなった。「表か裏か」の話が長く、普段なら一度読むのをやめたと思う。
- 後半（箱の中のパンまで）: 4。箱を開けるところで、続きが気になった。

### 章（区切り）ごとに、犯人だと思う人と確かさ
犯人と呼べる人は、まだいなかった。登志の名前だけが、ずっと気になった。
- 前半の終わり: 登志 25%。理由は出来事の中身。本の記述と写真・古い地図が食い違っていると感じたため。
- 中盤の終わり: 登志 40%。理由は出来事の中身。地図の食い違いを認めず、裏に回す案を出したため。書き方の理由としては、登志の台詞が多い、という程度。
- 後半の終わり: 登志 45%。理由は出来事の中身。「ひっこしたら」の工作と、冬馬の一家が引っこした話が関係しそうだと思った。誰が何を隠しているかは、まだ分からない。

## 手順2: 解決編を読んだあと

### 解決編で明かされた事実と、驚きの度合い
1. 登志が寝込んでいた頃、枕元の机に箱の家を並べ、見舞いに来た子と窓越しに紙のパンをやりとりする遊びをしていた。本の「路地の向かいのパン屋」は、この机の上の模型のこと。 → とても意外（おー）。村の地図と合わないのは、そもそも現実の村ではなかったから、と分かった。
2. 由美が描いた校庭の場所（墓だった所）に、登志は模型の学校を自分の家の隣に置いていた。香苗に「お墓」と言われた場所は、登志の模型の配置だった。 → 少し意外。墓の指摘が、模型と地図の食い違いとして回収された。
3. 冬馬が模型の店の窓から紙のパンを出し、登志が受け取っていた。工作の箱の穴に詰まっていた茶色い紙はこの遊びのパン。 → 少し意外。穴とパンの役割が、ここで初めて分かった。
4. 「ひっこしたら」の工作は、冬馬と登志が引っ越す前提で作った村の一部。郵便局の底の字も、遊びの中の言葉だった。 → 予想どおり。引っ越しの話と結びつくことは、読みながら推測していた。
5. 登志が本の初めの一文（模型の村だったと書いた所）を削った。作り話と思われるのを避けるため。 → 少し意外。犯人や隠しごとではなく、作者の判断だと分かった。
6. 冬馬が死ぬまで取っておいた工作が、同じ引き出しの古い地図と一緒にあった。 → 予想どおり。

### 一番「おー」となった所
「本に書いてあったのは、この机の上の家並みだった」（解決編の段落）。本の村が現実の村ではなく、病床の机の上の模型だったと分かった所。

### 問題編の手がかりと、読んだときの記憶
- 窓が低い所にあり、寝たまま手を伸ばす（問題編に出てくる）: 読んだ覚えがある。窓越しに届く距離がつかめなかったので、気にとめていた。
- 古い地図で二軒の距離が離れている: 覚えていた。「パンは渡せない」を読んで、ここが引っかかった。
- 学校が本当は墓: 覚えていた。ただ、模型の話とどう関係するかは、読んだ時点では分からなかった。
- 窓越しの写真の犬、登志が冬馬の頬に触れる場面: 覚えていた。ただ、この二つには気をとめなかった。
- 「ひっこしたら」の工作、穴に詰まったパン: 覚えていた。どちらも気になって、続きを読んだ。
- 登志が裏の案を出した場面: 覚えていた。ただ、登志が表の地図を気にする理由が分からなかった。

### 作者が一番驚かせたかったと思う真相と、実際の驚き
作者は、本の思い出が病床の模型の遊びだったことを、一番驚かせたかったのだと思う。実際、一番驚いた。ただ、「おー」と同時に、論理の組み立て（模型の村なのに、なぜ地図の話が出てくるのか）を一度で整理しきれなかった。

### 読んでいて引っかかった文、読みにくかった文
- 「冬馬ちゃんのお店まで勝手に私の思い出にして、今日も私は、あの店が本当に川べりにあったような地図を、あなたに刷ってもらおうとしてたのね」: 誰が誰に頼んだのか、「あなた」が由美なのか、読み取りにくかった。
- 「学校を作った子に、私の家の隣に置いてって頼んだの。そしたら運動会の日、布団の中からでも、びりの子がゴールするまで見ていられるでしょう」: 運動会と模型の学校がどうつながるか、ここで一度立ち止まった。
- 「私が本の通りに学校を描いて、香苗さんにお墓だと教えられたのも、ちょうどそこだ。」: 「そこ」が何を指すか、前後を読み返した。
- 「原稿の初めには、私の机の上の村だって書いてあった。」: 削られた文が本のどこか、すぐには思い浮かばなかった。

### 結末で「もう終わってよい」と思った所
終わりは、登志が初めの二行を書く場面で十分だと思った。段落29の「あそこを削ったのは私よ」以降の説明が、やや長く感じた。段落29の途中、「作り話だと思われそうで。」で止めても、読者には伝わったと思う。

### 回想・台詞で語られる、物語の前の行動と決断（一つずつ）
1. 登志が寝込んだ頃、枕元の机に箱で家を作って並べた（誰が：登志、いつ：病気で学校を休んでいた頃）。→ 病気の子が遊びで村を作るのは、暮らしの感覚でも自然。
2. 登志が、学校を作った子に、自分の家の隣に学校を置くよう頼んだ（誰が：登志）。→ 変ではないが、運動会の理由がつながらず、なぜそう頼んだのかは納得しきれなかった。
3. 冬馬が店の窓から紙のパンを出し、登志に渡す遊びをした（誰が：冬馬、いつ：引っ越す前）。→ 自然。子どもの遊びとして納得できる。
4. 冬馬が工作を死ぬまで取っておいた（誰が：冬馬）。→ 自然。思い出の品として残すのは納得できる。
5. 冬馬と登志が、別々の町へ引っ越した（誰が：両家、いつ：村が沈んだ後）。→ 自然。
6. 登志が、原稿の初めの一文を削り、模型の村を実際の村のように書いた（誰が：登志、いつ：本を書いたとき）。→ 作り話と思われたくない気持ちは分かるが、自分の思い出を現実の村として書いたことは、暮らしの感覚では少し変に感じた。なぜそう書いたのか、本の中で理由が十分に示されていない。
