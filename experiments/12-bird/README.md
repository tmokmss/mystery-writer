# 12 文鳥が鍵になる「くもり」

人間から「次は文鳥が登場すると良い」と頼まれ、同じFable（`claude-fable-5-2`）に書く手順（`scripts/writer_guide.md`）に従って新作を書かせた。前作の課題から、次の三つも指定した。
- 容疑者を一人ずつ外していく形を取らない（前2作は消去法で真相の人物が残った）
- 核の謎の反転そのものが一番驚くようにする（前2作は周辺の感情の打ち明けのほうが驚かれた）
- 手がかりの前提は一度だけ見せ、意味を言い当てる地の文を続けない（実験11で足した「因数分解」の決まりを初めて試す）

前作までと同じ型（家族が故人の仕事をこっそり継いでいた、子どもが犯人、光る物や音が唯一の決め手）も避けさせた。評価役（Opus・Codex）と読者役（Haiku・Sonnet）に読ませ、3稿まで直させた。

## 筋

- 十歳の秋、春香は父が自分の育てていた灰色の文鳥のヒナ「くもり」を逃がして家を出ていった、と信じている。翌春に父は白い文鳥を持ってきたが、春香は「くもりは灰色だった。うそつき」とドアを閉めた。二十歳の秋、入院する父から年寄りの白い文鳥が届く。春香は父の鳥を手放そうと引きとり手を探し、日曜の朝に渡す約束をする。容疑者はおらず、謎は「父はなぜこの鳥を私に預けたのか」。
- 真相: 届いた鳥は、くもり本人。白文鳥のヒナは灰色で、大人になると白くなる。父は逃がしておらず、昼にえさをやる者がいなくなるので連れて出て、小鳥屋に育て方を習った。春に持ってきたのは、白くなったくもりを返すためだった。「逃がした」は母の当て推量だった。
- 核の手がかりは、小鳥屋の入口の貼り紙「ヒナ入りました。白文鳥、桜文鳥」と、帰りぎわにレジの横で見たヒナのケースの「四羽とも、くもりだった」。
- 一番驚かせる所: 引きとり手への覚え書きに「白文鳥」と書いた春香が貼り紙を思い出し、「色しか覚えていなかったのは、私だ」「本物を追い返したのは、私だった」と気づく。責めていた父と自分が入れかわる反転。
- 感情の決着: 病室で春香は謝るより先に「どうして、一度しか来なかったの」と父を問い詰め、父は「閉められるのが、こわかった」と答える。最後に春香が十年ぶりに「くもり」と呼ぶ。

## 結論

- **核の驚き:** 前2作と違い、v3では評価役の二つとも、一番大きな驚きは核の反転にあると判定した。読者役も二人とも核で一番驚いた。周辺の打ち明け（父が昼にえさをやっていた、かごの布が春香のハンカチだった、誕生日の包みが毎年の鳥の写真だった）は、v1・v2では核より驚かれた。v3では、これらを削るか、核のあとの小さな確かめにとどめた。
- **因数分解の効果:** v1では、同じ鳥だと示す材料が重なっていた（父の伝言「見ればわかる」、玄関の「ほら、帰ってきたぞ」「春香の鳥だ」、年齢の強調、小鳥屋の「白の子たち」）。v2で言葉の手がかりを削ったが、玄関の「帰ってきたぞ」と、値札の直後に並ぶ灰色のヒナが残った。Haikuの読者役はかえって「くもりが白くなった姿か」と迷った。v3で手がかりを小鳥屋の一つに絞り、玄関の父の台詞を「これ」「春香に」だけにすると、Haikuは白い鳥を「代わりの別の鳥」と読んで核に気づかなかった。評価役が予想した、核に届く読者の割合も、50〜55%から40〜50%に下がった。
- **残った課題:** 白文鳥のヒナが灰色だと知っている読者には、白い鳥が届いた時点で見当がつく（Sonnetの読者役は3稿とも問題編で核に届いた）。題材の知識で決まる核は、知っている読者には驚きが残らない。
- **引き込み:** 冒頭の二文で問いが立ち、常用漢字表にない字は0種。読者役は3稿とも三章（鳥の世話の描写）で続きを読みたい気持ちが3に下がった。それでも、v3で途中でやめたくなる箇所は無かった。
- **評価役の読み違い:** v3でOpusは、手術の日付が合わない（おばさんの「来週」と小川さんの「あさって」）と指摘した。本文では、おばさんが来た日曜の9日後の火曜で合っているので、直していない。
