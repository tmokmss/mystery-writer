# 読者回答（Haiku）: 九時のコロッケ v4

## 手順1: 問題編だけを読んだ時点

### 何が起きたと思うか

- 犯人・方法・動機は見当がつかなかった。
- 「三年間ずっと客は私だけで、店は私のために開いていたのではないか」という程度の推測はした。店をしめる理由は、表向きは私の転勤だが、桜井さんの体のことや別の事情があるのかもしれないと思った。

### 怪しい・後で使われそうだと思った描写

- 「売るものがないのに、ふいてある。」（一）
- 「残りもんだよ。二つ。」が毎回同じ形で繰り返される（一、二）
- 「ただいま、と返したことはない。私は客だからだ。」（一）
- 「ひざも、もう言うことをきかないしね。」（二）
- 息子の言葉「かあさん、座ってろよ。ひざが悪いんだから。」（三）
- 一万円を受けとらず、小銭を前かけのポケットに落とす（三）
- 「おかえり、とは、ここではだれも言わない。」（四）
- 「三年間、私はあの店の何だったのだろう。」（四の末）

### 章ごとの続きを読みたい気持ち（1〜5）

- 一: 4。売るもののない盆と、二つだけの買い物が謎として引っかかった。
- 二: 4。店をしめる理由が「私のせい」と言われ、話が動いた。
- 三: 4。息子が出てきて、店の事情が一段見えた。
- 四: 3。送別の席の場面は少し間が延びた。ただ、続きは読めた。

## 手順2: 解決編を読んだあと

### 解決編で明かされた事実と意外さ

1. 夜の「残りもん」は、売れ残りではなく、私の電車に合わせて九時に揚げた二つだった。 → とても意外（おー、となった）。「残りもん」という一語が、売れ残りの意味からひっくり返るところ。
2. 桜井さんは、夜のケースの中身を、私が来る前に作っていた。ケースは毎晩空に見えていた。 → 少し意外。空の盆を「売れない店の夜」と読んでいたので、仕込みを夜にずらしていたという説明で納得した。
3. 昼の店は、十人ほどの行列ができるほど客が来ていた。 → とても意外（おー、となった）。昼の店を見ていなかったことを、本文の「昼のあの店を、一度も見ていない」で予告されていたのに、実際の行列の量には驚いた。
4. 店をしめるのは、私のせいではなく、桜井さんが「もう、じゅうぶん」と決めたから。私の引っこしは、その時期に重なっただけ。 → 少し意外。「しおどき」は二章で言われていたので、予想に近いが、「私が引きとめていた」という結論は意外だった。
5. 私のチラシが、レジの横の壁に貼ってあった。 → 少し意外。三章で桜井さんが一枚だけ受けとったのを覚えていたので、回収のされ方に意外さがあった。
6. 息子が十時半に桜井さんを連れて帰ったこと、桜井さんが九時に二つ揚げて待っていたこと。 → 予想どおり寄り。息子が「ひざが悪い」と言っていた時点で、夜の体の事情は予想できた。

### 一番「おー」となった場所

- 「九時に揚げてたよ。あんたの電車に合わせてね。」と言われた場面。「残りもん」の嘘が、私を待つための言葉だったと分かったところ。

### 作者が一番驚かせたかったと思う真相と、実際の驚き

- 作者が驚かせたかったのは、おそらく「夜の二つは、私のための仕込みだった」という一点だと思う。
- 実際に一番驚いたのもそこだった。ただし、「三年間、店は私のために開いていたのでは」という推測を問題編の時点で少し持っていたので、驚きは半分は予想どおりだった。

### 読んでいて引っかかった文・読みにくかった文

- 「私がいなくなるから、店がつぶれるのではなかった。私がいなくなるから、やっと、しめられるのだ。」: 私がいなくなったことで、なぜ店をしめられるのか、一読では理由がつかみにくかった。
- 紙袋: 「二つを紙袋に入れて、口を折った。」の後に「紙袋の底には、もう一つ残っている。」とある。購入は二つのはずなのに、三つ目がどこから来たのかが一読では分からなかった。
- 「せがれに連れて帰られちまってね」: 「せがれ」は息子のことと分かるが、読み慣れない語。
- 「帳面つけで遅くなった、あたしの晩めしの」: 何の帳面か、どこから来た残りかが分かりにくい。

### 2つの問題の性質

- 一つ目（紙袋の三つ目）は、説明が一文足りないだけで、読み手は意味を追えなかった。
- 二つ目（「やっと、しめられる」）は、論理の飛びが大きい。読み返す人が出てくる箇所だと思う。
