# 読者役 Haiku の回答

## 1. 問題編を読んだ時点の推理

- 犯人・方法・動機はまだ分からなかった。一つ思いついたのは、桜井さんはすでに亡くなっていて、この店は三年間「早瀬さんだけのため」に開いていたのではないか、という想像。
- 「早瀬さんが実は客ではなく、この町にもういない存在なのではないか」とも一瞬思った。

## 2. 問題編の怪しい・後で使われそうな描写

- 「三年のあいだ、私はあの店で、自分のほかの客を一度も見たことがない。」（一）
- 「歩いているのは私だけで、自分の足音がついてくる。」（一）
- 「ただいま、と返したことはない。私は客だからだ。」（一）
- 「売るものがないのに、ふいてある。」（一）
- 「残りもんだよ。二つ。」の繰り返し（一、二、三）
- 「おかえり、とは、ここではだれも言わない。」（四）
- 「まだ、ありますか」「残りもんなら、あるよ」という初対面の会話（一）
- 「息子さんらしい」と、桜井さんを「かあさん」と呼ぶ人物の登場（三）。店がまだ生きている人の店だと示す描写に見えた。

## 3. 章ごとの続きを読みたい気持ち（1〜5）

- 一：4。店の終わりと主人公の転勤が重なり、何か隠されていると感じて続きが気になった。
- 二：4。「私のせいだ」と「しおどきってやつさ」のやりとりで、関係の裏が気になった。
- 三：4。息子さんの登場で「桜井さんは本当に生きているのか」と引っかかり、かえって続きが気になった。
- 四：3。送別会の場面（「八時半。九時。九時半。」あたり）で少し間延びした。スーパーの場面（「ここにはこんなに物があって」）で持ち直した。
- 普段の読書なら、四の送別会のあたりで一度やめていたと思う。ただ、今回は解決編まで続けて読んだ。

## 4. 解決編を読んだ後

解決編で明かされた事実と、驚きの度合い。

- 桜井さんは昼にも店を開けていて、昼のうちにすべて売り切っていた。「昼間もあかない店のほうが多い」と書かれていたので、昼の店が生きていたのは完全に想定外だった。とても意外（おー、となった）。
- 夜のケースが空だったのは、売り切ったあとだった。ケースの空を「売るものがない店」と読んでいたので、これも強く意外。とても意外。
- 毎晩の「残りもんだよ、二つ」は、夜のために揚げた分だった。「はじめの晩のだけは、ほんとに残りもんだった」と本人が言うので、嘘の繰り返しだったとわかる。とても意外。ただ、解決編の五で「売れ残り」と言い直されたときは、なんとなく予想していた。
- 夜の二つを九時に揚げて、早瀬さんの電車に合わせて待っていた。少し意外。「客が店に気をつかうもんじゃない」と言われた場面の意味が、ここでつながった。
- 「私がいなくなるからですか」への「そうだよ」は、店がつぶれるという意味ではなく、早瀬さんが来なくなって夜の店をしめられるという意味だった。少し意外。読み返せばそう読めるが、一度目では気づかなかった。
- 息子さんが十時半に連れて帰ったことや、手元の一つがまだ温かいことは、予想どおり。

- 一番「おー」となったのは、昼の列の場面で、レジの横の壁に早瀬さんのチラシが貼ってあったところ。チラシを「金曜でしめる店に、チラシはいらないよ」と断られた場面と結びついて、桜井さんが早瀬さんの仕事を受けていたとわかった。

- 作者が一番驚かせたかったと思う真相は、「夜に来る客のための店だと思っていた店が、実は昼に売り切る店で、夜の二つは客のために揚げて待っていたもの」という点だと思う。これには、実際に一番驚いた。

- 引っかかった文・読みにくかった文：
  - 「いま、ひざの前で冷えているものも、同じ名前で呼ばれている。同じ残りものが、どうしてあんなにちがうのか。」（解決編 五）。「ひざの前」が何を指すか一度で分かりにくく、「同じ名前」の意味もつかみにくかった。
  - 「それなら、「そうだよ」は逆の意味になる。」（解決編 六）。一度読んだだけでは、どう逆になるのかがすぐに分からなかった。
