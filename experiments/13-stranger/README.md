# 13 家族ではない人との「九時のコロッケ」

[実験12](../12-bird/README.md)の「くもり」への人間の感想（「泣いてしまった」「解答編の7、8はちょっとくどかった」）を受けて、書く手順（`scripts/writer_guide.md`）に「感情の決着は一つの関係に絞り、核の反転のあとは真相を別の人物に順に確かめさせない」を足し、同じFable（`claude-fable-5-2`）に新作を書かせた。前作までの課題から、次の三つも指定した。
- 型を変える。実験10〜12は三作続けて「家族が隠れて善いことをしていて、語り手が誤解していた」型だったので、家族以外の関係を中心にする
- 核を専門知識に頼らない（前作は「白文鳥のヒナは灰色」という知識で決まり、知っている読者には早く見えた）。日常の感覚で解ける核にする
- 中盤の生活描写の場面にも、謎か期限か人物の対立を一つ動かす

評価役（Opus・Codex）と読者役（Haiku・Sonnet）に読ませ、4稿まで直させた。

## 筋

- 会社員の早瀬は、金曜に転勤で町を出る。三年間、毎晩九時すぎに商店街の揚げ物屋「コロッケ　さくらい」で、「残りもんだよ」と言われるコロッケを二つ買ってきた。ほかの客を見たことがなく、ケースはいつも空なので、自分が一日百六十円で店を支えていると信じている。転勤を告げると「金曜で店をしめます」の貼り紙が出て、「私がいなくなるからですか」に店主の桜井さんは「そうだよ」と答える。客集めのチラシも、まとめ買いも断られる。
- 真相: 店は昼に行列ができ、夕方には売りきれる。桜井さんは、三年前に「あしたも来ていいですか」ときいた早瀬のために、電車に合わせて二つだけ揚げて、ひざが悪いのに夜九時まで待っていた。早瀬が去るので、やっと店をしめられる。
- 核の手がかりは、一章の「盆の上には何もない。きれいにふいてある」と、毎晩温かい紙袋。四章で早瀬はスーパーの総菜の棚に半額のパックが山になっているのを見て、「ここには物があって、あの店には何もない」と、店が負けている証拠として読む。
- 一番驚かせる所: 金曜の昼に初めて店へ行くと、十人の列ができている。「私がいなくなるから、やっと、しめられるのだ」「引きとめていたのは、私だ」。
- 感情の決着: 列に並んだ早瀬と桜井さんのやりとり一場面だけ。三年間「おかえり」と言われてきた早瀬が、初めて「いってきます」と言う。

## 結論

- **核の驚き:** 4稿とも、評価役は二つともほぼ一貫して、一番大きな驚きは核にあると判定した。読者役も4稿を通して核で一番驚いた（v3のHaikuだけは、昼に売りきる店だったことに「とても意外」と答えつつ、一番「おー」となったのはレジ横の自分のチラシだった）。v1でCodexだけが周辺（最初の二つは桜井さん自身の晩ごはんだった）のほうが驚くとしたが、v2でこの一言を軽くすると判定が核に移った。
- **専門知識に頼らない核:** 繁盛店だという反転は、読者役が4稿とも問題編では読めなかった（Haikuは体調のせい、亡くなっているのでは、などと読んだ）。評価役が予想した、昼の繁盛まで届く読者は20〜40%で、前作の40〜55%より低い。ただし「夜の二つは早瀬のために揚げていた」には、40〜65%が先に気づくと予想された。Opusは、先に気づいた読者は「夜にわざわざ揚げるほど客がいない店」と読むので、かえって誤った方向へ誘導される、と見た。
- **因数分解の決まりの続き:** v3まで、解決編の五章で語り手が「売りきった店の、空っぽだったとしたら」と真相を先に言葉にしていた。評価役の二つとも、これで六章の昼の行列が発見ではなく答え合わせになると指摘し、Sonnetの読者役も「五章で主人公が早く気づきすぎた」と答えた。v4で五章の仮説を削り、真相は行列の光景で初めて見える形にした。ただし、語り手の説明を削ったぶん、Haikuは「私がいなくなるから、やっと、しめられる」の理由を一読では追えなかった。
- **解決編の重なり:** 新しく足した決まりに従い、真相を確かめるのは昼の列という光景一つと、桜井さんとの一場面だけにした。息子は問題編で一度出るだけで、真相の説明はしない。前作で言われたくどさは、評価役・読者役のどちらからも指摘されなかった。
- **引き込み:** 冒頭の一文（「金曜に、私はこの町を出る。」）で期限が立ち、常用漢字表にない字は0種。v3・v4では読者役が二人とも、四章の送別会の場面で続きを読みたい気持ちが3に下がった（Haikuはv3で「普段ならここでやめていた」と回答）。
- **読者役の手順の乱れ:** v4のSonnetは、手順1（問題編の推理）を解決編を読んだ後にまとめて書いたと申告した。この回の問題編の推理は参考にとどめる。v2のHaikuは解決編を読まずに止まったので、続けて読ませた。

## 人間の感想（v4）

- 「引っこします→引っ越しますダネさすがに　ちょっとひらがな多すぎる気がする　膝、戻した、など　小学生向けの本みたいになってる　これは何かの慣習なの？昨日→きのうとかも、一見やりすぎに見える」
- 「話自体はまあまあ面白いね　もうちょっとミステリーに寄せたいかなあ　謎解きをするには、平和すぎるというか」
- ひらがなについて: 書く手順には「読めない漢字は開く」という決まりしかなく、常用漢字表にある語を漢字で書く決まりがなかった。Fableは「平易な現代の文章」の指定を表記にまで広げ、膝・戻す・昨日・引っ越すのような常用漢字の語まで開いていた。漢字の割合（漢字÷(漢字＋ひらがな)）は、v4の問題編・解決編で26.3%。実験12のv3の問題編は25.1%、実験09のv3の問題編は31.0%だった。評価役・読者役は誰も指摘しなかった。
- 「あと、早瀬が去るので、やっと店をしめられる。はよくわからなかった　早瀬は細客なので、そこまで店の方針には影響しないのでは　昼間の常連さんもたくさんいそうだけど」
- 核の反転が、店主の動機の弱さの上に乗っていた。店は昼に常連でにぎわっていて、ひざが悪いなら夜の営業だけやめればよい。早瀬が去ることは店全体をしめる理由にならない。v4でHaikuの読者役は「『私がいなくなるから、やっと、しめられる』の理由は一読では追えなかった」と答えていたが、評価役は二つとも、人物の行動の筋の項目でこれを挙げなかった。書く手順と評価役の質問に、真相の中心にある決断はもっと小さな選択肢と比べても、その決断になる理由があるかを確かめる、を足した。
- 平和すぎることについて: 実験10〜13は四作続けて「善意が誤解されていた」型で、この作では誰も損をしていない。
- 書く手順に三つ足した。常用漢字表にある字の語は漢字で書く（開くのは形式名詞・補助動詞などだけ）。平易さは語と文の長さで出し、表記を子ども向けにしない。謎には事件性（損、盗み、失踪、死、だまし）を持たせ、感傷は事件の真相の上に乗せる。評価役の読みやすさの項目に、開きすぎも挙げるよう足した。`scripts/check_kanji.mjs` は漢字の割合も出すようにした。
