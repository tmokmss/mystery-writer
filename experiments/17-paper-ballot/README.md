# 17 Codex（Astra 6.2）の書いた「半券」

[実験16](../16-hard-sf/README.md)までの書き手はFable（`claude-fable-5-2`）だった。今回は人間の依頼で、書き手をCodex CLIのGPT-6.2-Astra（`gpt-6.2-astra`、思考の深さはCodexの既定のmedium）に変え、テーマも自由に選ばせた。書く手順（`scripts/writer_guide.md`）、前作の結論と人間の感想、過去の実験の筋を読ませた。第2稿・第3稿は、同じCodexの会話を再開して直させた。

評価役（Opus・Codex）と読者役（Haiku・Sonnet）に読ませ、3稿まで直させた。評価役のCodexは、書き手とは別のモデル（GPT-6.2-Sol）である。

## 筋

- 舞台は高校の映画部。向かいの映画館が、日曜の朝に部の短編を一本、舞台挨拶つきでかけてくれる。部室で二本を見て、九人で投票する。一本は語り手の佐知が監督し、来月引っ越す律が主演した『水曜日』。もう一本は一年生の『裏口』で、足元しか映らない。
- 投票用紙は、真ん中に切り取り線のある入場券用の紙で、左右に二本の題名を印刷した。カーテンの陰で選んだ方を菓子箱に入れ、残った方はくず入れに捨てる。佐知は『裏口』に入れたが、切り離すときに角が欠けた。残った『水曜日』の半分で口紅を押さえて捨てる。
- 事件: 顔を洗って戻ると、ふたの閉まった菓子箱の上に半券が並び、『水曜日』が八対一で勝っている。だが、ただ一枚の『裏口』には角の欠けがない。一年生は「一票あった」と喜んでいる。
- 真相: 八枚の『水曜日』の一枚に、佐知の唇の跡があった。並んでいたのは、律がくず入れから拾った「選ばなかった方」の半券だった。箱を開けると、本当の票は『裏口』が八枚、『水曜日』は律の一枚だけ。
- 一番驚かせる所: 八対一の大勝が、そっくり一対八の大敗に裏返る。『裏口』に入れた八人は、それぞれ机の一枚を自分の票だと思って黙っていた（一年生の「『裏口』に入れたの、私だけだと思ってた」）。
- 感情の決着: 律は「これじゃ佐知と舞台挨拶に立てない」と思って並べたと認め、映画館への返事を『裏口』に打ち直す。佐知は角の欠けた半券を見せ、「律の卵焼き、何度見ても泣くよ。でも日曜は、あの足の裏が見たい」と言う。律の「私の隣で？」に「うん。席、二つ取ろう」。

## 結論

- **書き手が変わると、長さが大きく変わった:** 本文は問題編約1,200字、解決編約600字で、Fableの前作（問題編約3,700字、解決編約2,700字）の4分の1ほどだった。直しでも、v1の約1,700字から大きくは増えなかった。人物は二人と一年生一人に絞られ、場面は投票の前後だけだった。
- **犯人は当てられたが、核の驚きは残った:** 読者役は延べ6回とも、問題編の時点で律を犯人と当てた。方法（並んでいたのは捨てた方の半券）まで見当をつけたのは、v3のSonnetの1回だけだった。6回とも、一番驚いたのは票が逆だったという核だった。評価役も3稿とも二つとも、核で一番大きな驚きが出ていると判定した。
- **評価役の点:** Codexの評価役は、v2で公正さ5、トリック5、物語5、引き込み5をつけた。Opusは3稿とも意外さ3〜4、物語4〜5で、前作と同じくらいだった。
- **核の仕組みは、評価役の指摘で本文に出た:** v1では、『裏口』に入れた八人が誰も異を唱えない理由（それぞれ机の一枚を自分の票だと思う）が本文に無かった。私も最初は、八人が結果に気づくはずだと読み違えた。Opusの指摘で、v2に一年生の「一票あった」と「私だけだと思ってた」を足した。読者役2人とも後者を一度で読めなかったので、v3で「『裏口』に入れたの、私だけだと思ってた」にした。
- **物語が始まる前の行動の確認:** 律がくず入れから半券を拾って票として並べたことを、読者役は延べ4回、普通はしないと挙げた（v2のHaiku・Sonnet、v3のHaiku・Sonnet）。v1で律が投票の前から舞台挨拶の服を母親に借りていたことは、読者役2人とも気が早いと言い、v2で削った。
- **結末:** 読者役に足した「どの文で終わればよかったか」の質問に、v3のSonnetは律が『裏口』と打って送った文、Haikuは「席、二つ取ろう」を挙げた。Opusはv2で、結末が間延びしていないことを高く評価した。
- **表記:** 漢字の割合は問題編40.3%、解決編41.8%で、Fableの作品（30〜37%）より高い。常用漢字表にない字は0種。
- **評価のあとの直し:** v3の評価のあと、四か所を直した（再評価はしていない）。同じ物を問題編は「くず入れ」、解決編は「ごみ箱」と呼んでいたので「くず入れ」に揃えた（Opus）。口紅を押さえた位置が問題編では「口の端」、解決編では「下唇」だったので、解決編を「三枚目の端に、唇の縦じまが少しだけ」にした（Haikuの読者役）。律が『水曜日』と打ち込む描写が二度あり犯人を指しすぎるので、問題編の後ろの一度を消した（Opus）。律の「佐知と舞台に立てない」は、上映作品とのつながりが読みにくいので「舞台挨拶に」にした（Haikuの読者役）。
- **残った弱さ:** 佐知以外の八人も残りの半券を同じくず入れに捨てたことは、佐知の場面から推すしかない、と評価役が二人とも指摘した。常識で受け入れられる範囲と見て、説明を足さなかった。
