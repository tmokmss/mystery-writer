# 16 ハードSFの「最初の三分」

[実験15](../15-isekai/README.md)の「聖剣を盗めるのは私だけ」への人間の感想を受けて書く手順（`scripts/writer_guide.md`）に足した決まりを、同じFable（`claude-fable-5-2`）に渡して新作を書かせた。人間からは「三体みたいなSFもの」を頼まれた。特定の既存作品の設定・人物は使わず、異星の知性との接触、天文の観測、科学者の組織という手触りだけを借りた。

依頼の冒頭で渡した条件は次のとおり。
- 謎に使うSFの決まりは二つまでにし、問題編で一度読めば分かる形で示す。数式や時刻の条件を並べない
- 電波望遠鏡の観測や研究所の運営など、実在の手順は現実と合わせる。物語が始まる前の人物の行動も、その立場ならそうすると思える形にする
- 犯人の正体が主人公の家族という前作の型は使わない
- 解決編で問答を重ねて抜け穴を潰さない。疑いを向ける人物は回収する。組織の行動に目的を残す
- 「誰がやったか」と別に、核の一番大きな驚きを置く

評価役（Opus・Codex）と読者役（Haiku・Sonnet）に読ませ、3稿まで直させた。読者役の質問には、実験15のあとに足した「物語が始まる前の行動を一つずつ書き出して確かめる」項目が入っている。

## 筋

- 舞台は長野の高原の高森電波観測所。語り手の真木（三十三歳、研究員）は、当直の終わりの十分で直径六十メートルのアンテナを、十二光年先のくじら座タウ星へ向ける習慣を三年続けてきた。九つの秋、この観測所の公開日の「星へ手紙を送ろう」でボタンを押したとき、天井の明かりがまばたいた記憶があるからだ。そのとき横にいた若い技師が、いまの技師長の戸倉だった。
- 火曜の未明、タウ星から人類初の異星の信号が届く。初めに一度だけ「揺れる三分七秒」があり、その後は素数と四十分の本文が繰り返す。同僚の久保は、三分には人間の作った電波の癖があるので地上の混信だと言う。
- 事件: 検証班が来る前日の日曜、初日の記録から最初の三分だけが、当直の共用の名前で削られていた。最初の三分は世界でこの記録にしかなく、バックアップは日曜の夜に取る予定だった。当直だった真木が、混信を消して記録をきれいにしようとしたと疑われる。
- 真相: 消したのは戸倉。二十四年前の公開日の夜、三度並び直して最後になった九つの真木の声を、試験送信の枠を使って本当にタウ星へ送り、日誌には予定どおりの方角を書いていた。
- 一番驚かせる所: 行きに十二年、帰りに十二年。最初の三分は、向こうが受け取った手紙をそのまま送り返した部分で、中身は九つの真木の息と沈黙、「ほんとうに、届くの」「届くよ」、そして「返事をください。まってます」だった。人類は見つかったのではなく、こちらが呼んでいた。
- 感情の決着: 真木と戸倉の関係だけに絞った。戸倉は「名前まで名乗っている子が、怖がる何十億人の前に出る」のを防ぐためと自分の保身の半分ずつで消した。真木は「一度目（送信）は怒っていません。二度目（削除）は怒っています」と言い、名前が出るのを受け入れて記録を戻す。戸倉が去る朝、真木は次の返事を知らせるために住所を聞く。

## 結論

- **犯人は当てられたが、核の驚きは残った:** 読者役は延べ6回とも、問題編の時点で戸倉を犯人と当てた。それでも6回とも、一番驚いたのは「最初の三分は自分の声だった」という核だった。核まで見当をつけたのは、v3のSonnetの1回だけだった。評価役も3稿とも二つとも、核で一番大きな驚きが出ていると判定した。実験15と同じく、「誰が消したか」と「消されたものが何か」を分け、後者を核にした。
- **公正さ:** v1では、往復二十四年を計算するための語り手の年齢が問題編になく、Codexは公正さを3にした。v2で「三十三にもなって」を、九つ・十二年と別の章に一度置き、Codexの公正さは5に上がった。評価役の見積もりでは、核まで届く読者はv1からv3まで25〜35%で、大きくは変わらなかった。
- **題材:** 謎に使ったSFの決まりは「タウ星まで光で十二年」と「大電力の送信機に火を入れると所内の明かりが一瞬暗くなる」の二つだけだった。評価役・読者役の指摘は人物の行動に集まり、SFの仕組みが分かりにくいという指摘は出なかった。
- **残った弱さ:** 戸倉が「君を守るため」と言いながら、真木の当直中に共用の名前で消した点は、3稿とも評価役か読者役に指摘された。v3で「日曜の夜のバックアップの前に消せるのは、真木の当直の夜しか残っていなかった」を一文足したが、読者役はまだ納得しなかった。評価のあとの直しで、戸倉が「疑いが君に向くと分かっていて、消した」と自分で認める形にした（再評価はしていない）。久保を外す根拠が本人の言い分だけである点と、一度きりの三分を真木の十分の観測で受けられた偶然は、評価役の指摘があったが、説明を足さなかった。
- **物語が始まる前の行動の確認:** 読者役は、戸倉が二十四年前に免許にない電波を出して日誌を偽ったことを、3稿を通じて計3回、暮らしの感覚では納得しにくいと挙げた（v1のHaiku、v2のSonnet、v3のHaiku）。
- **解決編の問答:** v1の解決編で戸倉が並べた言い訳（操作の記録が残るとは知らなかった、真木が疑われるとは考えなかった）は、読者役2人とも納得しなかった。v2で削り、問題編の日曜の昼に、真木が携帯の録音を聞かせると戸倉が「真木さん」と言いかけてやめる場面を足して、行動で見せた。
- **表記:** 漢字の割合は問題編36.6%、解決編33.2%。常用漢字表にない字は0種。
- **評価のあとの直し:** v3の評価のあと、三か所を直した（再評価はしていない）。
  - 問題編の「試験のあいだ、電波は外へ出さず、地下の装置に吸わせるのだと聞いている」を消した。Opusの指摘で、この一文があると「明かりが暗くなったから電波が出た」という推理が成り立たない。
  - 戸倉の「三日もあれば、誰かが声に戻す」を「いつか誰かが、うちの送信機の癖に気づいて、声に戻す」にした。Sonnetの読者役の指摘で、同じ台詞の「普通に音に直しても、うなりにしかならない」と食い違っていた。
  - 上の「残った弱さ」の一文を足した。
- **実在の手順:** 発見したら別の観測所で確かめ、検証を受けてから発表する、返信は国際的な協議まで送らない、という手順は、地球外知性の発見後の国際的な取り決めに合わせた。Fableも私も記憶から書いていて、出典は確認していない。

## 人間の感想（v3）

- 「守るというのは、半分は本当だ。残りの半分は、日誌にうそを書いた自分の首だった。　これちょっと分かりづらいな　自分の首を守るってこと？」。意図は「自分の職（首）を守るため」。「首を守る」の「守る」を前の文に任せて省いたので、一度では読めなかった。
- 「アンテナを皿というのって、共通語彙なんだろうか　初めて聞いたが　主人公特有の呼び方かと思ったらみんなそう呼んでて違和感あった」。日本の電波天文の現場では「アンテナ」「パラボラ」「電波望遠鏡」と呼ぶのが普通で、「皿」は英語の dish の直訳に近い（記憶から書いた。出典は確認していない）。語り手の思い出の呼び方なら通るが、所長・久保・戸倉も同じ呼び方をしていた。
- 「最後間延びした感じあるな　戸倉さんの声だ。　この辺りで終わっても良かったのかもしれない　余白を残す終わらせ方？」。核の驚き（三分は自分の声だった）と感情の山は、ヘッドホンで「届くよ」が若い戸倉の声だと分かる場面でほぼ出ている。そのあとに告白、駐車場での別れ、世界のその後、三年後と四つ続いた。駐車場の場面は、v1のCodexが「戸倉との別れが薄い」と言ったのを受けて、v2で足させたものだった。
- 「それから少しずつ、問いの形が変わっていった。なぜ見つかったのか、ではない。　なぜ見つかったかは明白（こっちが電波送ったから）なんだから、問われることない気がする」。真相で「こちらが呼んだ」と答えが出ているのに、結末で世界がまだその問いを持っているように書いていた。
- 「Dishの直訳だろうとは思ってた　日本語としてナチュラルな表現をすべきだね」。呼び名だけでなく、英語の直訳のような語や言い回し全般を避ける決まりに広げた。
- 評価役・読者役は、四つとも挙げなかった。評価役は逆に、別れの場面を足す側の指摘をしていた。
- 書く手順に三つ足した。核の反転と感情の決着のあとは早めに終え、結末の文が真相と食い違わないかを確かめる。職場の物の呼び名は現場で実際に使われている呼び方にする。慣用句の一部を省かない。評価役の質問（読みやすさ、物語としての力）にも同じ点を足し、読者役には、どの文で終わればよかったかを聞く項目を足した。この形でv3をSonnetに読ませると、六章の戸倉の「全部だ」で一度きれいに閉じていて七章は長いと答え、削ってよい段落に「世界は、怖がった。……証言に呼ばれた。」（「なぜ見つかったのか」の文を含む段落）を挙げた。ただし、その文が真相と食い違うことは指摘せず、終える位置も人間より後ろだった。「皿」と「自分の首」は拾わず、代わりに評価のあとの直しで足した「消せるのは、君が当直のゆうべしか残っていなかった」の日本語がねじれていると挙げた。
