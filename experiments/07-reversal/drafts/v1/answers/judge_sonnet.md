# 総評

お盆の欠けた角を自分のほうに向ける癖が、毒入りの茶を入れた義父の湯呑みと息子の湯呑みを入れ替えた、という着想は小さくてきれいです。この短さなら核として立ちます。「お盆」というタイトルが行事と道具の二重の意味になる点もよく効いています。

弱点は次の3つです。

- お盆の向きの手がかりを三度も繰り返しているので、勘のいい読者は二章の途中で解けます。
- お盆が半回りして左右が入れ替わる、という幾何が、書かれた条件だけでは確定しません。核の論理に穴があるので、ここは直すべきです。
- 作中には謎がありません。警察は自殺で納得し、疑っているのは語り手だけです。

# 1. 抜け穴

**直すべきもの**

- **お盆の幾何が確定していない。**
  - 「角」が欠けた四角いお盆だと、角は向こう左と向こう右の二通りがあり、「手前に向けた」は90度回すだけでも成り立ちます。180度の回転でなければ左右は入れ替わらず、核の推理が崩れます。
  - 湯呑みをのせたまま持ち上げたのか、卓に下ろしたのかも書かれていません。
  - 語り手と義父の座る位置もありません。「右」が誰から見て右なのかが固定されていません。
  - 直し方は、お盆を丸くして縁の一か所が欠けている形にし、語り手を義父の向かいの席に座らせ、「湯呑みをのせたまま持ち上げた」と一語足すことです。
- **義父の反応の順序に無理がある。**
  - 義父は「右は冷ました分」と思っているので、夫の「熱っ」を聞いた時点で、取り違えと自分の湯呑みの毒に気づくはずです。
  - ところが本文では、「熱っ」を聞いてから「そうか」と言い、そのあと平然とひと口飲みます。
  - 義父を愚かな人にしないため、義父が先に自分の湯呑みをひと口飲み、ぬるいと気づいたところへ夫が「熱っ」と言う順にします。そうすれば、気づいたうえで黙った、という解決編の説明と整合します。

**直さなくてよいもの**

- 義父が毒を入れた瞬間が描かれていないこと。入れる機会は十分にあります。
- 猫が花瓶を倒すことと本家の電話が重なる偶然。猫は冒頭から登場しており、偶然が義父を裏切る話なので、主題に沿っています。
- 義父が自分の湯呑みに縁側で毒を足した、という別解。「右が夫の分」という発言があり、基準の二点には関係しません。
- 毒の量や味、ひと口で夜中に倒れるかどうか。
- 義父がなぜ助けを呼ばなかったか。解決編の説明で足ります。
- 警察が取り違えを見抜けないこと。

# 2. 作中の謎の成立

作中に謎はありません。警察は「自殺」で納得し、近所の噂は息子への疑いに流れるだけです。「何かおかしい」と思っているのは語り手だけで、その語り手も問題編では考えを語りません。事件は読者に向けた出題にとどまっています。

「読者だけがだまされる」仕掛けではありません。語り手は行動を正直に書いています。ただ、読者への挑戦の「自分で命を絶ったのではない」は、作中の誰も持たない疑いを前提にしています。偶然についても、取り違えを起こす猫と電話は偶然ですが、この話では偶然が主題なので許容できます。

作中の人物にも引っかかりを一つ持たせると締まります。たとえば刑事が「お父さんは熱いお茶が好きでしたか」と聞き、語り手が「はい」と答える場面です。

# 3. 公正さ: 4

- 手がかりはすべて問題編にあります。
  - お盆の決まり、湯呑みが二つ同じ柄であること、猫舌、注ぐ時間差、「右が健一の」、お盆を回したこと、「熱っ」、毒は義父の湯呑みのみ、という材料が揃っています。
- 義父は一章から登場しており、犯人の登場も早い。
- 減点は、前述の幾何の曖昧さです。「右」と「手前」が誰から見た向きか分からないので、読者が検算できません。
- 毒が夫用の湯呑みに入っていたことは、回転を前提にすれば論理的に出ます。義父が自分用に入れたなら、夫が毒を飲むはずだからです。この推論自体は堅いです。

# 4. 意外さ: 3

- 一般のミステリー読者が、問題編だけで義父が犯人で方法はお盆の回転だと届く割合は、約40%と予想します。
- 気づく箇所は主に二つです。
  - 二章で、語り手が欠けた角を手前に向け直す一文を読んだとき。「教えられた決まり」と「その通りに直した」が隣り合うので、勘のいい読者は「左右が入れ替わった」と結びつけます。
  - 「熱っ」の場面。ここで確信する読者が多いはずです。
- 毒入りの湯呑みを取り違える筋は古典的な型です。意外さは動機よりも、決まりごとの癖が原因だと分かる点に頼っています。
- 義父がひき逃げ犯で、夫を殺そうとしたという動機は、トラックのへこみと「今夜話す」から推測できます。ただし、息子を殺すほどの切迫感は、読者が補わなければなりません。

# 5. ヒントの量

多すぎます。お盆に関する記述が一章、二章、三章の三か所にあり、さらに解決編の締めにも同じ描写があります。削ってよいのは次の描写です。

- 一章の「癖になってしまって、テーブルにのっているのを見ると、つい向きを直してしまう」。決まりの説明で十分で、この一文は答えを予告しています。
- 二章の「欠けた角が向こうを向いていたので、いつものように手前に向けて置いた」の「いつものように」。語り手の無意識さは、動作だけで伝わります。
- 三章の「私がお盆にさわったのは、花瓶の水を拭いたときだけだ」。聞き取りの要約にお盆が出ること自体が、手がかりの指差しです。
- 三章の「茶を淹れたのは義父で、湯呑みを配ったのも義父だった」。誰が配ったかを念押しするので、読者の疑いが一点に絞られます。
- 二章の「しばらく湯呑みの中を見つめていた」。この描写は削らず、解決編で説明する気づきの根拠として残してもかまいません。ただし「熱っ」の場面と近いので、書き方を弱める余地はあります。

# 6. 読み返したときの納得度: 4

- 猫舌だから先に注ぐ、という義父の説明は、犯行の準備と読者への目くらましを兼ねていて、読み返すと巧妙です。
- 夫を指す「右」の指示と、隣のおばさんの「機嫌がいい」も、読み返すと意味が変わります。
- 減点は、義父がなぜ「熱っ」のあとで平然と飲んだのか。前述の順序の問題です。

# 7. 方法と動機の分かりやすさ: 4

- 方法は一言で言えます。「息子に飲ませる毒入りの茶を、お盆を回されたせいで義父自身が飲んでしまった」。
- 動機も一言で言えます。「ひき逃げを息子に気づかれたので、口を封じようとした」。
- 減点は、冷めた湯呑みと熱い湯呑み、右と左、お盆の向きという三つの状態を頭の中で組み合わせる必要があることです。解決編を読んでも、図にしないと追いにくい読者がいます。

# 8. トリックの面白さ: 4

- 「義母が教えた失礼のない置き方が、息子を救った」という皮肉な絵が浮かびます。
- 「うちのお盆の癖で毒が入れ替わった」と人に話したくなります。
- ただし、毒入りの湯呑みの取り違えは古い型です。新しさは、取り違えの原因が家庭内の礼儀作法にあることだけです。

# 9. 核の着想

義母に教わったお盆の向きの癖が、息子を毒殺しようとした義父の湯呑みを入れ替え、義父自身に毒を飲ませた。一文で言えます。

# 10. 読者が覚えておく必要のある固有の情報: 15個

1. お盆の欠けた角は自分のほうに向けて置く決まりと、語り手の癖
2. ひき逃げは十日前で、車は見つかっていない
3. 義父のトラックの前がへこみ、遠い修理工場に出した
4. 夫がトラックの前に長くしゃがみこんでいた
5. 義父が同じ柄の湯呑みを二つ買ってきた
6. 夫は「今夜、親父と話す」と言った
7. 夫は猫舌
8. 義父は一つに先に注いで冷まし、もう一つはあとから注いだ
9. 義父が指で叩いた右が、夫の湯呑み
10. 義父が席を外した間に猫が花瓶を倒し、語り手がお盆を持ち上げ、欠けた角を向こうから手前に直した
11. 夫は風呂に入っていて座敷にいなかった
12. 義父が右の湯呑みを夫に渡し、夫が「熱っ」と言った
13. 義父は左を飲み、湯呑みの中を見つめた
14. 農薬は義父の湯呑みだけから出て、瓶には義父の指紋しかなく、夫の湯呑みは空だった
15. 一週間後に夫が警察署へ行った

解くための核は9個前後で、短編としては多めです。特に8、9、10、12は、順番と左右を同時に覚えておく必要があります。

# 11. 読みやすさ

- **分かりにくい描写**
  - 「迎え火の時間か」という義父の台詞と、本家からの電話の関係。電話の用件が読者に伝わりません。
  - 「向こう」と「手前」と「右」が、誰から見た向きかの説明がありません。
  - 湯呑みの注ぐ順序が一文に詰め込まれ、冷めた側と熱い側の対応を追いにくいです。
- **注意点**
  - タイトルの「お盆」は行事と道具の二重の意味で、巧みですが、「お盆の入り」と「お盆にのせた」が近いので、読み流すと混ざります。
- **馴染みのない語**
  - 「盆花」「迎え火」は、都市部の読者には説明が要ります。「朱塗り」は伝わります。
- **人名**
  - 登場人物は少なく、名前も覚えやすいです。「夫」「義父」「語り手」の呼び分けも明快です。

# 12. 物語としての力: 4

- 語りの抑えた調子、義母の遺したお盆、「話は、明日にしよう」という義父の台詞が効いています。結びの「義母に教わった癖が、夫を助けて、義父を死なせた」は余韻があります。
- 弱いのは次の2点です。
  - 義父が息子を殺そうとする動機の重さに、前半の描写が追いついていません。「ふさぎこんでいた」と「機嫌がいい」の落差に、決意の跡が見えません。
  - 語り手は出来事の傍観者で、自分で選んでいません。お盆を直したのも無意識で、黙っている選択も事後の話です。

# 13. 改善案

1. **お盆の幾何を確定する。**
   - お盆を丸くして縁の一か所が欠けた形にし、語り手を義父の向かいに座らせ、湯呑みをのせたまま持ち上げたと書きます。
   - 左右は「義父から見て右」と一度だけ明示します。これで回転と入れ替わりが一意に決まります。
   - 欠けの向きは、義父がお盆を置く場面で「欠けは向こう」と先に見せます。語り手の直す場面は「お盆を元の位置に戻した」だけに縮め、読者が二点を自分で結べるようにします。ヒントも減ります。
2. **義父の反応の順序を直す。**
   - 義父が自分の湯呑みをひと口飲み、ぬるいと気づいたところで、夫が「熱っ」と言います。
   - 気づいたうえで黙った、という解決編の説明と一致し、「そうか」という平然とした台詞も不要になります。
3. **作中の人物にも引っかかりを持たせ、動機を前半で効かせる。**
   - 刑事に「お父さんは熱いお茶が好きでしたか」と聞かせ、語り手が「はい」と答える場面を入れます。冷めた茶を飲んだのは変だ、という疑問が作中に生まれます。
   - 動機は、物置の戸が開いていた、義父が夜遅くまで物置にいた、といった短い描写を前半に置いて予告します。
   - ヒントは、第5項の削る描写と差し引きで増やしすぎない範囲に収めます。

なお、取り違えの手がかりをお盆の記述だけに頼らず、語り手が気づくきっかけを一つ増やすのもよいです。「熱っ」の場面で、お盆の欠けが自分の側にあるのを目にする一文などです。
