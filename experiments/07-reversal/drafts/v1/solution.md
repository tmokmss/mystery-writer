# お盆　解決編

義父は、夫を殺そうとしていた。

十日前に高校生をはねて逃げたのは、義父の軽トラックだった。夫は、戻ってきたトラックの前にしゃがみこんだとき、それに気づいたのだと思う。「今夜、親父と話す」というのは、一緒に警察へ行こう、という話だった。

義父はそれを察していた。だから、珍しく自分で茶を淹れた。夫の湯呑みにだけ、物置の農薬を入れた。同じ柄の湯呑みを二つ買ってきたのは、どちらが自分のものか、夫に見分けさせないためだ。どちらに毒が入っているかは、置いた場所で覚えていた。右が夫の分。だから「健一のは、こっちな」と言った。

でも、お盆は回っていた。

ミケが花瓶を倒して、私はお盆を持ち上げた。置き直すとき、欠けた角を手前に向けた。義父が置いたとき、欠けは向こうを向いていた。お盆は半回りして、右と左の湯呑みが入れ替わった。

戻ってきた義父は、右の湯呑みを夫に渡した。それは、義父が自分のために、あとから注いだほうだった。だから熱かった。夫が「熱っ」と言ったのは、冷ましてあった湯呑みが夫の手に渡らなかったからだ。

義父が飲んだのは、先に注いで冷ましてあった、夫の分だった。

ひと口飲んで、ぬるいと気づいたのだと思う。義父は湯呑みの中をしばらく見つめて、「話は、明日にしよう」と言った。そして誰にも何も言わずに、縁側で迎え火を見ていた。助けを呼べば、自分が何をしようとしたかが知れてしまう。義父は、黙っているほうを選んだ。

一週間後、夫が一人で警察署へ行ったのは、軽トラックのことを話すためだった。夫は、湯呑みのことには気づいていない。自分が殺されかけたことも、知らないままだ。

義母に教わった癖が、夫を助けて、義父を死なせた。私はそのことを、誰にも話していない。

あのお盆は、今も台所にある。置くたびに、私は欠けた角を手前に向ける。
