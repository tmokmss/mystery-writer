# 総評

短くまとまった、後味のいい作品です。義母に教わった盆の置き方という日常の決まりごとが、毒入りの湯呑みを入れ替え、最後に義父が自分で毒を飲みます。この皮肉な構図はよくできています。

弱点は三つです。

- 解決の中心になる「盆が半回りして湯呑みが入れ替わった」という事実の根拠が、問題編にありません。義父が盆を置いたときの欠けの向きと、語り手が座った位置が書かれていません。公正さに関わるので、直すべきです。
- 作中の警察は自殺で納得しており、作中には謎がありません。謎は「読者への挑戦」の一文がつくっています。しかもその一文が、最大のネタばらしになっています。
- 手がかりが濃すぎます。慣れた読者は、二章で猫が花瓶を倒し、語り手が盆を置き直した場面で解決が見えます。

# 1. 抜け穴

**直すべきもの**

- **盆の元の向きと座る位置が問題編にない。** 解決編が言う「義父が置いたとき、欠けは向こうを向いていた」は、問題編のどこにも出てきません。
  - 語り手が欠けを手前に向けても、元から手前なら盆は回りません。90度しか回らなければ、湯呑みも入れ替わりません。
  - 湯呑みを分けた軸は縁側と床の間ですが、問題編に床の間は出てきません。語り手がその軸のどちら側に座っていたかも書かれていません。
  - 入れ替わりの根拠が解決編の宣言だけになっています。読者が自力で確かめられる形にする必要があります。
- **湯呑みの温度差に説得力が足りない。** 一つ目を注いで冷まし、二つ目を注いでから、電話と夫の入浴の時間が過ぎます。その後で夫が「熱っ」と言うには、時間が長すぎます。
  - 解決編が頼る「湯気の違い」も、問題編にありません。二つ目の湯呑みに湯気が立つ描写を足すか、電話を短くするのが必要です。

**直さなくてよいもの**

- 一つ目に注いだ湯呑みが夫の分だという点は、猫舌の規則と「縁側のほう」の発言から読者が導けます。基準を満たしています。
- 毒を入れた瞬間が書かれていない点も、挑戦文が殺意を前提にしているので問題ありません。
- 義父の計画が杜撰です。茶を淹れて配ったのが自分なので、夫が死ねばまず疑われます。夫の湯呑みを証人になる語り手の前で指さすのも不用心です。ただ、追い詰められた人物としては通ります。
- 一口の農薬で死ぬか、義父が助けを呼ばずに沈黙を選んだ心理が自然か、という点は物語の側の選択です。
- 語り手が意図して盆を回した可能性は、「私は知らなかった」という語りを受け入れれば消えます。
- 手渡すときに湯呑みの熱さで気づく可能性があります。暗さと動揺で流せる範囲です。

# 2. 作中の謎の成立

作中では謎になっていません。警察は「妻を亡くして塞ぎこんだ義父の自殺」で納得しています。新しい湯呑みが「最後に息子と飲みたかった」と読まれる点も、自殺説を補強しています。作中の誰も疑問を持たないので、謎は読者への挑戦文がつくっていることになります。

この作品の読者は騙されていません。作者から「自殺ではない」と告げられて推理を始めるだけです。

偶然への依存も大きいです。猫が花瓶を倒し、電話が鳴り、義父が席を外している間に語り手が盆に触る。この三つが重なって初めて入れ替わりが起きます。運命譚として許せる範囲ですが、見た目が偶然の積み重ねである点は意識すべきです。

作中に疑問を置く方法は、改善案の3で述べます。

# 3. 公正さ: 3

犯人（義父）の登場は早く、猫舌の規則、欠けの規則、湯呑みの先注ぎ、「縁側のほう」という発言、熱っ、そうか、農薬の所在は、問題編に出ています。

一方で、決定的な手がかりが問題編に欠けています。

- 義父が盆を置いたときの欠けの向き。
- 語り手が座った位置。
- 二つ目の湯呑みの湯気。

解決編が宣言する半回りは、読者が検証できません。これが満点にならない唯一かつ最大の理由で、直せば4から4.5になります。

# 4. 意外さ: 3

一般の読者が問題編だけで犯人と方法に届く割合は、約60%と予想します。動機のひき逃げまで含めると、半分強です。

気づく箇所は次のとおりです。

- 二章の前半、へこんだトラックの場面で、ひき逃げと義父が結びつきます。
- 挑戦文の「死ぬつもりで茶を淹れたのではない」で、誰かを殺すつもりだったと分かります。
- 二章の中ほど、猫が花瓶を倒して語り手が「欠けを手前にして置き直した」場面で、一章の欠けの規則とつながります。慣れた読者は、ここで方法まで読みます。

最後の「そうか」を読む前に、多くの読者は方法を確定させています。

# 5. ヒントの量

多すぎます。削ってよいのは次の描写です。

- **欠けの規則の説明。** 一章の「欠けをお客さんに向けたら、失礼でしょう」という台詞は、規則が後で効くことを強調しすぎています。規則の一文だけを残し、台詞は削ってよいです。
- **「縁側のほう」の重複。** 「縁側に近いほうの湯呑みを指でとんとんと叩いた」という地の文と、台詞「縁側のほう」の両方があります。地の文を削ります。
- **語り手の証言。** 三章の「私がお盆にさわったのは、花瓶の水を拭いたときだけだ」は、盆に触ったことを自分で指さしています。「私は台所にいた」程度に弱めます。
- **トラックの手がかり。**
  - 「町から遠い修理工場」と「戻ってきたばかり」はどちらも、ひき逃げを示します。片方に絞ります。
  - 義父が語る「イノシシ」の説明と、夫がしゃがみこむ描写も、片方で十分です。
- **猫と盆の距離。** 「縁側のほう」の発言、電話、猫、盆の置き直しが数行の中に並んでいます。その間に別の動作を挟み、因果が見えにくくなるようにします。

# 6. 読み返したときの納得度: 4

読み返すと、納得できる箇所が多くあります。

- 一章の猫舌と欠けの規則。
- 同じ柄の湯呑み。
- 「健一のは縁側のほう」。
- 「熱っ」。
- 義父の「そうか」。
- 義父の「機嫌がいい」という隣人の言葉。

どれも伏線として回収されています。

減点の理由は、盆の元の向きという最重要の手がかりが問題編にないため、読み返しても確認できないことです。

# 7. 方法と動機の分かりやすさ: 4

一言で説明できます。

- **方法:** 義父は夫用の湯呑みに毒を入れた。ところが語り手が盆を置き直し、湯呑みが入れ替わって、義父自身が飲んだ。
- **動機:** ひき逃げを夫に警察へ話されるのを止めたかった。

動機は一言で済みますが、方法は盆の半回りの位置関係が曖昧なため、「入れ替わった」と受け取るにとどまります。位置関係を書けば5になります。

# 8. トリックの面白さ: 3

絵としては浮かびます。丸い盆が半回りして、二つの湯呑みが入れ替わる図です。「毒入りの杯を取り違えて、自分で飲む」という型は、ミステリーではよく見る定番です。

新しいのは、入れ替えた原因が義母の遺した盆の置き方だという点です。人に話すとしたら「義母の躾が息子を救った話」として話すでしょう。トリックの仕組みより、この点が語りたくなる部分です。

# 9. 核の着想

「義母に教わった『欠けを自分に向ける』盆の置き方が、義父が息子に盛った毒の湯呑みを入れ替え、義父自身に飲ませた」と言えます。

# 10. 読者が覚えておく固有の情報

問題編で数えると全部で17個です。解決に必須なのは次の12個です。

1. 夫は猫舌で、義父は熱い茶しか飲まない。
2. 丸い朱塗りの盆は縁が欠けていて、欠けは自分のほうに向けて置く。
3. 十日前にひき逃げがあり、車は見つかっていない。
4. 義父の軽トラックの前がへこみ、修理から戻った。
5. 夫が「今夜、親父と話す」と言った。
6. 同じ柄の湯呑みを二つ買ってきた。
7. 義父が一つ目を注ぎ、間を置いて二つ目を注いだ。
8. 「健一のは縁側のほう」と義父が言った。
9. 電話で義父が席を外し、夫は風呂に入っていた。
10. 猫が花瓶を倒し、語り手が盆を持ち上げて、欠けを手前に置き直した。
11. 夫が「熱っ」と言い、義父が「そうか」と言った。
12. 農薬は義父の湯呑みだけにあり、物置の瓶には義父の指紋しかなかった。

残りの5個は、補助か目くらましです。

- お盆の入りの夕方であること。
- 座敷の明かりを落としていたこと。
- 隣のおばさんの訪問と、茶を淹れる前に帰ったこと。
- 財産をめぐる噂。
- 夫が一週間後に警察署へ行ったこと。

12個は短編としては適正な範囲ですが、10番の「欠けの向きの元」が足りていません。

# 11. 読みやすさ

- **馴染みのない語。** 麻幹、迎え火、盆花、本家、朱塗りがあります。麻幹は「麻の茎」などの言い換えが要ります。
- **解決編で急に出る語。** 床の間は問題編に出てきません。座敷の中に、縁側と床の間という二つの位置を、問題編であらかじめ示す必要があります。
- **「お盆」の二重の意味。** 題名と、盆の入りの季節と、湯呑みを載せる道具の三つが同じ語です。「お盆の入り」と「朱塗りのお盆」が同じ段落に並んでいて、読者が混乱します。道具のほうは「盆」や「丸盆」にします。
- **曖昧な指示語。** 「欠けを手前にして」の手前が誰から見ての手前か分かりにくく、「向こう」も同様です。座る位置を書けば解消します。
- **人名。** 登場人物は健一、義父、義母、ミケだけで、覚えにくい名前はありません。

# 12. 物語としての力: 4

義母の教えから義父の沈黙までの一本の流れがきれいです。「義母が帰ってきて息子を守ったのかもしれない」という結びの余韻も、盆の季節に合っています。

弱いのは二点です。

- 語り手の「と思う」という推量が多く、断定がありません。
- 義父が殺意を持った理由はひき逃げの隠蔽という実利だけで、義父が人間として描かれる場面が少ないです。トマトを黙って置く場面は、いい伏線になりそうです。

# 13. 改善案

1. **盆の向きと座る位置を問題編に自然に書き足す。** 義父が盆を座卓に置いた場面で、欠けが床の間のほうを向いていたことを書きます。語り手の座る位置も、縁側を背にして座ると書けば、置き直しで半回りすることが読者に見えます。二つ目を注ぐ場面には、湯気を一言添えます。これで、手がかりの効きが公正さの要件を満たします。
2. **「5. ヒントの量」で挙げた描写を削り、猫と盆の場面を前後の描写から切り離す。** 特に、「縁側のほう」の地の文、語り手の「盆にさわったのは…だけ」、トラックの修理工場とイノシシの重複を削ります。猫の場面の前に、迎え火か夫の風呂の描写を挟み、因果が見えにくくします。
3. **作中に疑問を置き、挑戦文を弱める。** 三章で、語り手が一人だけ引っかかる点を書きます。たとえば「熱いのしか飲まない義父が、ぬるい茶に何も言わなかった」です。挑戦文の「死ぬつもりで淹れたのではない」を、「あの夜、本当は何が起きたのか」に差し替えます。作中に謎ができ、挑戦文のネタばらしもなくなります。そのぶん意外さが上がります。
