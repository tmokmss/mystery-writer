# お盆　解決編

義父は、夫を殺そうとしていた。

十日前に高校生をはねて逃げたのは、義父の軽トラックだった。夫は、戻ってきたトラックの前にしゃがみこんだとき、それに気づいたのだと思う。「今夜、親父と話す」というのは、一緒に警察へ行こう、という話だった。

義父はそれを察していた。だから、珍しく自分で茶を淹れた。先に注いで冷ましておいた湯呑みが、猫舌の夫の分だ。その湯呑みに、物置の農薬を入れた。同じ柄の湯呑みを二つ買ってきたのは、どちらが自分のものか、夫に見分けさせないためだ。どちらに毒が入っているかは、置いた場所で覚えていた。縁側のほうが夫の分。だから「健一のは、こっちな。縁側のほう」と言った。

でも、お盆は回っていた。

ミケが花瓶を倒して、私はお盆を持ち上げた。義父が置いたとき、欠けは向こうを向いていた。私は欠けを手前にして置き直した。丸いお盆は半回りして、縁側のほうと床の間のほうの湯呑みが入れ替わった。暗い座敷で、義父はお盆の欠けにも、湯気の違いにも気づかなかった。

戻ってきた義父は、縁側のほうの湯呑みを夫に渡した。それは、義父が自分のために、あとから注いだほうだった。だから夫は「熱っ」と言った。

義父が飲んだのは、先に注いで冷ましてあった、夫の分だった。

ひと口目がぬるかったところへ、夫の「熱っ」が重なって、義父は気づいた。「そうか」と言って、湯呑みの中を見つめた。そして誰にも何も言わずに、縁側で消えかけた迎え火を見ていた。助けを呼べば、自分が何をしようとしたかが知れてしまう。義父は、黙っているほうを選んだ。死ぬつもりで淹れた茶ではなかったけれど、最後には、それを受け入れたのだと思う。

一週間後、夫が一人で警察署へ行ったのは、軽トラックのことを話すためだった。夫は、湯呑みのことには気づいていない。自分が殺されかけたことも、知らないままだ。

義母に教わったお盆の置き方が、夫を助けて、義父を死なせた。お盆の入りの夜、義母が帰ってきて息子を守ったのかもしれない、と思うこともある。私はそのことを、誰にも話していない。

あの丸いお盆は、今も台所にある。置くたびに、私は欠けを手前に向ける。
