# お盆　解決編

義父は、夫を殺そうとしていた。

十日前に高校生をはねて逃げたのは、義父の軽トラックだった。修理に出すと言いながら物置の陰に置いたままのトラックを、夫は何度も見て、それに気づいたのだと思う。「今夜、親父と話す」というのは、一緒に警察へ行こう、という話だった。

義父はそれを察していた。だから、珍しく自分で茶を淹れた。先に注いで冷ましておいた湯呑みが、猫舌の夫の分だ。その湯呑みに、物置の農薬を入れた。どちらに毒が入っているかは、置いた場所で覚えていた。縁側のほうが夫の分。だから「健一のは、こっちな。縁側のほう」と言った。

夫が何日もトラックを見ていることに、義父は気づいていたのだろう。夫が倒れたら、義父は「町で金に困って思いつめていた」と言うつもりだったのだろう。隣のおばさんに「健一が金に困っている」と心配してみせたのは、義父だった。同じ柄の湯呑みを二つ買ってきたのも、仲直りのしるしに見せるためだ。おばさんの目には、機嫌のいい父親に映った。

でも、お盆は回っていた。

ミケが花瓶を倒して、私はお盆を持ち上げた。義父が置いたとき、欠けは向こうを向いていた。私は義母に教わったとおり、欠けを手前にして置き直した。丸いお盆は半回りして、縁側のほうと床の間のほうの湯呑みが入れ替わった。暗い座敷で、義父はそれに気づかなかった。

戻ってきた義父は、縁側のほうの湯呑みを夫に渡した。それは、義父が自分のために、あとから注いだほうだった。だから夫は「熱っ」と言った。

義父が飲んだのは、先に注いで冷ましてあった、夫の分だった。熱いのしか飲まない義父の口に、ぬるい茶が入った。そこへ夫の「熱っ」が重なって、義父は気づいた。「そうか」と言って、湯呑みの中を見つめた。

それから義父は、誰にも何も言わずに、縁側で消えかけた迎え火を見ていた。助けを呼べば、自分が何をしようとしたかが知れてしまう。義父は、黙っているほうを選んだ。死ぬつもりで淹れた茶ではなかったけれど、最後には、それを受け入れたのだと思う。

一週間後、夫が一人で警察署へ行ったのは、軽トラックのことを話すためだった。夫は、湯呑みのことには気づいていない。自分が殺されかけたことも、知らないままだ。

義母に教わったお盆の置き方が、夫を助けて、義父を死なせた。お盆の入りの夜、義母が帰ってきて息子を守ったのかもしれない、と思うこともある。私はそのことを、誰にも話していない。

あの丸いお盆は、今も台所にある。置くたびに、私は欠けを手前に向ける。
