**手順2(解決編を読んだ後)**

明かされた事実ごとの評価:

| 事実 | 評価 | 理由 |
|---|---|---|
| 義父は夫を殺そうとしていた | 予想どおり | 手順1で当てた。ただし、義父が犯人と見せかけて被害者を自殺に偽装する流れは、読みながら確信が持てなかった。 |
| ひき逃げの車は義父の軽トラックだった | 少し意外 | 手順1では「犯人は健一で、トラックはその跡」と読んでいた。実際は義父が運転していて、入れ替わりの構図が逆だった。 |
| 「今夜、親父と話す」は、一緒に警察へ行こうという話だった | 少し意外 | 夫が加害者側だと思っていたので、話の中身を読み違えていた。 |
| 先に注いで冷ました湯呑みが夫用で、毒はそこに入っていた | 予想どおり | 手がかりが多く、読んでいてほぼ見当がついた。 |
| 義父の「縁側のほうが夫」の念押しは、毒入りの位置を覚えておくためだった | 予想どおり | 「とんとんと叩く」「こっちな」が不自然に強調されていたので気づいた。 |
| 夫の金の悩みを隣人に話したのは、自殺に見せかける下地だった | 少し意外 | 「金に困って思いつめた」という偽装の筋書きまでは予想していなかった。 |
| 同じ柄の湯呑みを二つ買ったのは、仲直りに見せかけるため | 少し意外 | 「最後の茶」という刑事の解釈の裏に、偽装の目的があった。 |
| お盆が半回りして、二つの湯呑みが入れ替わった | 予想どおり | 欠けの向きを直す描写がそのまま伏線だった。 |
| 夫の「熱っ」と義父のぬるい茶が重なって、義父は気づいた | 予想どおり | 猫舌と熱いお茶の好みの対比が最初に出ていたので、すぐ分かった。 |
| 義父は助けを呼ばず、黙って受け入れた | 少し意外 | 「そうか」は気づいた合図と読んだが、助けを呼ばない理由までは考えていなかった。自分の企みが知れるのを避けたという説明に納得した。 |
| 夫は湯呑みのことに気づいておらず、殺されかけたことを知らない | 少し意外 | 夫が全部を知っていて自首したと思い込んでいた。 |
| 語り手が真相を知りながら、誰にも話していない | 少し意外 | 語り手が事情を分かっているという構造が最後に効いた。 |

一番「おー」となったところ:
- 無し。強いて挙げれば、最後の「義母に教わったお盆の置き方が、夫を助けて、義父を死なせた」の一文。手がかりの回収としては予想どおりだが、余韻はあった。

作者が一番驚かせたかったと思う真相で、実際に一番驚いたか:
- 作者が驚かせたかったのは、「ひき逃げをしたのが義父で、毒は息子に向けたものだった」という構図の反転だと思う。ここは半分しか驚かなかった。毒が息子向けだった点は当てていた。ひき逃げの犯人を取り違えたのは、少し意外だった程度で、「おー」とまではならなかった。

引っかかった文や、読みにくかった文:
- 「義父は新しい湯呑みを二つ、お盆にのせて、一つに茶を注いだ。しばらく置いてから、もう一つに注いだ。」
  - 注ぐ順番が、後の謎解きの要になる。そのため、ここだけ手がかりを出しすぎに見えた。ここで「先に注いだほうが冷ます分」と気づいてしまう。
- 「欠けが向こうを向いていたので、手前にしてお盆を置き直した。」
  - 湯呑みが入れ替わるという肝心の因果が、本文ではあっさり流される。解決編を読むまで気づかなかった読者には、ここが唯一の足がかりになる。
- 「奥さんを亡くしてから、ずっとふさぎこんでいたんでしょう、と刑事は言った。新しい湯呑みも、最後に息子さんとお茶を飲みたかったのかもしれませんね。」
  - 刑事が結論を急ぎすぎていて、不自然さを感じた。
- 解決編の「夫が何日もトラックを見ていることに、義父は気づいていたのだろう。」
  - 「だろう」「と思う」の推測表現が続く。語り手が推測を述べているのは分かるが、どこまでが確定した事実なのかが読み取りにくい。
