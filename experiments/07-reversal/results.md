# 稿ごとの結果

解答役は、○が真相（義父が息子に盛った毒を、お盆が回ったせいで自分で飲んだ）に届いた答え、×が届かなかった答え。括弧内は確信度。評価役の点は「公正さ-意外さ-読み返したときの納得度-方法と動機の分かりやすさ-トリックの面白さ-物語としての力」（5点満点）で、評価役が予想した「一般の読者が真相に届く割合／方法（お盆の回転）まで届く割合」を添えた。

同じ役を同じ稿に2回回した場合は、両方を「／」で区切って書いた（保存した回答は2回目）。

## 稿ごとの記録

### v1

- 手がかりは、義母に教わった「お盆の欠けは自分のほうに向ける」作法、猫舌の夫のために先に注いで冷ました湯呑み、義父の「健一のは、こっちな」（右）、花瓶を拭いて欠けを手前に向けて置き直したこと、夫の「熱っ」、湯呑みを見つめる義父。
- 評価役の指摘:
  - ひき逃げのニュースと軽トラのへこみが続けて書かれていて、すぐ結びつく。
  - 夫の「熱っ」を聞いたあとで義父が飲むのは、毒を入れた本人として不自然。
  - 「右」が誰から見た右か分からない。お盆が四角なら、欠けを手前に向けるのは90度の回転でもありうる。
  - 義父が湯気で見分けなかった理由がない。
  - 挑戦文の「自分で命を絶ったのではない」と、義父が気づいて黙って死んだことが食い違う。

### v2

- 軽トラのへこみを二章に移した。
- 義父が湯呑みを渡すのと同時に自分も飲むことにした。
- お盆を丸くし、湯呑みを「縁側のほう」で指させた。座敷の明かりを迎え火のために落とした。
- お盆の作法を、迎え火の焚き方などと並ぶ義母の教えの一つにした。
- 挑戦文を「死ぬつもりで茶を淹れたのではない」にした。
- 評価役の指摘:
  - 義父が置いたとき欠けが向こうを向いていた、を削ったので、半回転を確かめられない。
  - 「熱っ」が義父の声とも読める。
  - 自分の淹れた茶で息子が死ねば、まず義父が疑われる。計画が粗い。
  - 挑戦文が答えを言いすぎている。

### v3

- 「欠けが向こうを向いていたので」を戻した。
- 二人が同時に口をつけ、夫が「熱っ」と言う順にした。
- 隣のおばさんに「健一さん、町でお金に困ってるんだって？　おじいちゃんが心配してたわよ」と言わせた。解決編で、息子の死を自殺に見せるために義父が流した噂だと明かす。
- 挑戦文を「あの夜、本当は何が起きたのか」にした。
- 評価役の指摘:
  - 「床の間のほう」が解決編で初めて出てくる。座敷の配置が分からない。
  - 修理から戻ったばかりのトラックが、へこんだままになっている。
  - 義父が湯呑みを買い、噂を流したのは、息子がトラックに気づく前に読める。
  - 「私には初耳だった」が、噂が嘘だと示しすぎている。

### v4

- 義父に「床の間のほうが、わしのだ」と言わせた。
- トラックは「修理に出すと言いながら、もう十日もそのまま」にし、夫はこの三日ほど何度もトラックの前にしゃがみこんでいたことにした。
- 「私には初耳だった」を削り、湯呑みを押さえながらお盆を持ち上げたことにした。
- 解決編の、根拠のない「農薬が効くのは夜中になる」と、本文と合わない「義父のついた嘘は、そのまま義父の死の説明になった」を削った。
- 解答役と評価役には回していない。
