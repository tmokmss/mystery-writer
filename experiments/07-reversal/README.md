# 07 前提がひっくり返る短編「お盆」

[実験06](../06-yellow-umbrella/README.md)の「黄色い傘」への人間の感想を受けて、意外さを先に設計した短編を書いた。評価の仕組みは06と同じで、評価役にはOpus・Sonnet・Codexの三つを使った（Codexは`scripts/judge_codex.sh`）。4稿まで直した。

06への人間の感想は次のとおり。
- 「まー確かに　構成さ・納得・方法・動機は5だな」「でも、実際意外差がなくて余りおーとはならないな」「意外さは結構重要なんではないか？」
- Codexにも評価役をさせてほしい、同じ評価軸で新しい話を作ってほしい。

## 目指す方向

- 06の驚きは「犯人は母」の一点だけで、母を疑っていた読者には確認にしかならなかった。07では、読者が疑わずに受け取る前提「死んだ人が被害者だ」をひっくり返す筋にした。犯人は誰かは、その結果として決まる。
- 05で指摘された「作中の警察から見れば謎でない」を避けるため、作中の人物も同じ誤解をする形にした。警察は自殺と判断し、近所は息子を疑う。
- 毒の杯の取り違えという型は古くからある（記憶から書いている）。取り違えを起こすものを、亡き義母に教わった「お盆の欠けは自分のほうに向ける」作法にした。題の「お盆」は、行事と台所のお盆の二つを指す。

## 結論

- **核の着想:** 義父は、ひき逃げに気づいた息子を毒殺しようとした。ところが嫁がお盆の欠けを手前に向け直したので、丸いお盆が半回転して湯呑みが入れ替わり、義父が自分の毒を飲んだ。気づいた義父は、企みを隠すために黙って死んだ。
- **意外さ:**
  - Opusの評価役が、v2とv3で意外さに4を付けた。これまでの実験では2〜3だった。v3の1回目は5-4-5-5-5-5で、これまでで一番高い点だった。
  - 少しずつ読ませた読者役は、どの稿でも最後まで夫か語り手を疑い、義父に行き着かなかった。06のv1は事件の日の章で母を当てていた。
  - じっくり解く解答役は、Sonnet・Opus・Codexが全稿で真相を当てた。Haikuは、v1とv3でそれぞれ2回中1回外した。
- **トリックの面白さと物語としての力:** OpusとSonnetの評価役がどちらにも5を付けた回があった。06までは4以下だった。
- **評価役の揺れ:** 同じ評価役に同じ稿を2回回すと、各項目が1〜2点揺れた。v3のOpusは1回目が5-4-5-5-5-5、2回目が4-3-4-5-4-4だった。Codexの評価役はどの稿でも公正さと納得度をClaudeより低めに付け、意外さは2〜3だった。
- **評価役の指摘で直した主な穴:**
  - お盆が四角なら、欠けを手前に向けるのは90度の回転でもありうる（v1）。丸いお盆にした。
  - 夫の「熱っ」を聞いたあとで、毒を入れた本人の義父が飲むのは不自然（v1）。二人が同時に口をつける順にした。
  - 義父が置いたときの欠けの向きを削ってしまい、半回転を確かめられなくなった（v2）。戻した。
  - 自分の淹れた茶で息子が死ねば、まず義父が疑われる（v2）。息子が金に困っているという噂を、義父が前もって流していたことにした。
  - 修理から戻ったトラックがへこんだまま（v3）。修理に出すと言いながら置いたままにした。
- **人間の読者の感想（v4）:**
  - 「十日前に高校生をはねて逃げたのは、義父の軽トラックだった　ここは意外だったけど、それ以外は予想できたなあ」
  - 「評価役はどこが意外だったのかも教えてくれてる？点数だけじゃなく定性評価もさせよう　ちゃんと肝心の部分で意外さを出したい」
  - 「今の文体は〜したが連なってたり、短文の連続だったりで、余り好きじゃないかも」
- **評価役に意外さの内訳を聞いた（v4）:**
  - 評価役の質問を `scripts/judge_prompt.md` にまとめ、Claudeの評価役とCodexの評価役が同じものを読むようにした。解決編で明かされる事実ごとに、問題編のどこで予想できるか、驚きの強さを答えさせる項目と、文体の項目を足した。
  - 評価役は5回（Opus2回・Sonnet2回・Codex1回）とも、核の仕掛け（お盆の回転）の驚きを2〜3とし、核で一番大きな驚きは出ていないと判定した。一番驚くのは「優しい義父が息子を殺そうとしていた」「義父は気づいて黙って死んだ」で、驚きは4。人間が核を予想できたことと合う。
  - ひき逃げの犯人が義父だったことは、評価役は5回とも驚き1〜3とし、一番驚かないところと見た。人間にとっては唯一意外だったところで、評価役と逆になった。
- **読者役（v4）:** `scripts/reader_prompt.md` で、問題編を読んで予想を書かせてから解決編を読ませ、明かされた事実ごとに意外だったかを答えさせた（Haiku・Sonnet、各2回）。お盆の回転は4回中3回が「予想どおり」で、ひき逃げの犯人が義父だったことは4回中2回が意外と答えた。意外と答えた2回は、問題編の時点でひき逃げを夫の仕業と読んでいた。ひき逃げの件では、評価役より読者役のほうが人間に近かった。
- **文体:** 評価役はそろって「〜た。」の連続を本文から引いて指摘した。例は、三章冒頭の四文と、花瓶の段落の五文。

## ファイル

- `drafts/v1`〜`v4`: 各稿の問題編・解決編と、解答役・評価役の回答全文（`answers/`）。v4は、v3の評価の指摘を直した版で、解答役には回しておらず、評価役と読者役は意外さの内訳を聞く新しい質問で回した（`reader_*.md` が読者役）。
- 稿ごとの結果は [results.md](results.md)。
