# 09 Fableに書かせた「甕覗き」

書き手をFable（`claude-fable-5-2`）に替えて新作を書かせた。渡したのは、[実験08](../08-three-styles/README.md)のあとに作った書く手順（`scripts/writer_guide.md`: 人物ごとの「知っていること・望んでいること・言動の理由」の表を先に作る、出来事を要約せず場面で書く）、調査の報告（`research/`）、07と08への人間の感想。文体の方向は指定していない。評価役（Opus・Codex、`scripts/judge_prompt.md`）と読者役（Haiku・Sonnet、`scripts/reader_prompt.md`）に読ませ、指摘をまとめて同じFableに渡して2稿まで直させた。

## 筋

- 昭和三十三年の夏、四国の紺屋にあずけられた十歳の「私」の回想。この家では女は藍甕に触れてはならない。送り火の夕方、祖父が甕に頭を入れたまま溺れて見つかる。疑いは、廃業をめぐって祖父と口論した伯父と、祖父に打たれた叔母、叔母と目を合わせる職人に向く。警察は事故として処理する。
- 真相: 祖母が、明日帰る孫に持たせる手ぬぐいを、生まれて初めて甕で染めていた。寺へ行ったはずの祖父に見つかり、落ちた布を拾おうと甕を覗きこんだ祖父の首を、とっさに押さえた。直後に転んだ「私」の膝に祖母が巻いたのは、まだ空気に触れきっていない若草色の手ぬぐいだった。藍は甕から上げると緑で、空気に触れて青くなる。
- 核は、優しく傷をしばってくれた手ぬぐいの色が、祖母がその瞬間まで甕場にいた証だったこと。手がかりは一章の糸の実演（上げたては緑で、息を三つするうちに青くなる）と、冒頭で抽斗から出した薄い水色の手ぬぐい。問題編に時刻は一つも出ない。

## 結論

- **核の驚き:** v2では評価役の二つとも、核で一番大きな驚きが出ていると判定した。Opusは手ぬぐいの驚きを5、犯人が祖母であることの驚きを3とした。v1では、Codexが「祖母の贈り物が祖母を指す、は二章で予想しやすい」として核の驚きは出ていないと判定していた。v2で、祖父が甕の底で探していたもの（刑事の「何ぞ落としたもんを拾いよったように見える。けんど、甕をさらえても何も出ん」）が「私」の膝に巻かれていた、という反転が加わった。
- **読者役:** 4本とも問題編の時点で祖母を犯人と見た。それでも、手ぬぐいの色の仕掛けでは4本とも「とても意外」と答えた。v2のSonnetは、作者が一番驚かせたい真相で一番驚いたと答えた。犯人当てとしては易しく、驚きは「誰が」より「あの布は何だったか」に出ている。
- **文体:** 現在形の描写と台詞を過去形の間にはさむ書き方になり、評価役の二つとも「〜た。」の単調な連続はほとんどないと判定した。要約として挙がったのは、三章後半の後日談（伯父が署に留めおかれた、甕を割った）だけ。Opusはv1・v2とも物語としての力を5とした。
- **人物の行動の筋:** 評価役の16番の項目で、作者の都合でしか説明できない言動として挙がったのは、v1では次の三つで、v2で直した。
  - 祖父が寺をやめた理由がない
  - 祖母の染まったはずの手を誰も見ていない
  - 甕から出た手が「井戸水のように冷たい」（藍甕はぬるい）

  v2で残った指摘は軽いもので、次の二つ。
  - 祖母が証拠の布を孫に巻いた（衝動として書かれている）
  - 伯父が子どもを甕場へ使いに出した
- **v2で直したこと:**
  - 祖母の名「とき」を問題編で出した。v1では読者役の二人とも、結びの「祖母のときだ」を「祖母だと確信したとき」と読んだ。
  - 手の温度を「ぬるい」にそろえ、手の色が見えない理由（暗い地面、団子の皿を前掛けでくるむ）を置いた。
  - 祖父の右腕がつけ根まで甕に入っていたことと、刑事の台詞を足し、方法の絵を問題編で支えた。
  - 祖母を怪しませる地の文（「台所にいるはずの人が」「早口」「訊かれもしないのに」）を削った。
  - 解決編の推理を、千秋が甕に落とした布を拾う格好を見る場面に寄せた。
- **v2で残った指摘:**
  - 甕がぬるいことが問題編に出ていない。
  - 残した甕の位置（甕場か納屋か）が食い違う。
  - 源次さんの「うちにも小さいんを一つ飼うとる」が「この家にも」と読める。
  - 首を押さえてから祖父が動かなくなるまでの絵が抜けている。
  - 解決編が祖母の内心の再構成を断定しすぎる。
