# 甕覗き　解決編

小夜叔母は、川下の町で四十年、藍染めの工房をやっていた。葬式のあと、従妹の千秋が私をその工房へ連れていく。土間に甕が三つ埋まっていて、戸をあける前からあの匂いがした。

「母の送りに、一枚染めていってください。兄さん、やったことないでしょう」

千秋は青い手で、白い手ぬぐいを私に持たせる。言われるまま、私はしゃがんで、手ぬぐいごと腕を甕に沈めた。ぬるい。人の肌より少し低いくらいの、生きもののぬるさだ。数をかぞえて、引きあげる。

上がってきた布は、青くなかった。

出たばかりの若草の、まだやわらかい葉の色をして、私の手の中でぽたぽたと雫を落としている。濡れた腕が、ひりひりとしみる。

この色を、私は膝に巻かれたことがある。このぬるさの手に、足首をつかまれたことがある。

「広げて。風にあてて」

千秋の声が遠い。私は広げなかった。握ったままの布は、指のあいだから見えているところだけが、息を三つするうちに端から色を変え、六十年あまり抽斗に入っていたのと同じ、薄い水色になっていく。

藍は息をして青うなるんじゃ、という源次さんの声が、耳の奥でする。十歳の私が見たのは糸で、祖母が巻いてくれたのは手ぬぐいで、その二つを並べてみる頭が、あの夏の私にはなかった。祖母は緑の手ぬぐいなど持っていない。持っていたのは、甕から上げて、まだ息をしていない布だ。

「おばあちゃんが、よう言いよったんです」

千秋が、私の手から布を取って竿にかける。

「うちが生まれて初めて染めた一枚は、東京の孫が持っとる、て。兄さんのことでしょう。いつ染めたんか、母も知らんままでした。おじいさんが亡うなって、納屋の甕を始めてからやろう、と言うてましたけど」

それより前だ、とは言わなかった。あくる日には、私が東京へ帰る。祖母は、何ぞ持たせてやらんとな、と言っていた。仕事は休みで、甕場には誰もいない。祖父は寺へ行くと言い、祖母はその羽織を自分の手で衣桁にかけている。四十年のあいだ干すだけだった人が、孫に持たせる手ぬぐいを一枚、自分で甕にくぐらせるのに、あれほどの日はなかったろう。羽織が衣桁に残ったままなのを、台所の裏口から出た祖母は見ていない。

「千秋さん。染めている最中に、布を甕へ落としたら、どうする」

「拾いますよ。こうやって」

千秋は甕のふちに膝をつき、右の腕をつけ根まで沈めて、底を探ってみせた。顔が、黒い水の面すれすれまで下がる。

私は、その格好を知っていた。

櫂は壁に掛かったままだった、と刑事は言った。何ぞ落としたもんを拾いよったように見える、けんど甕をさらえても何も出ん、と。出るはずがない。祖父が拾おうとしていたものは、そのとき私の膝に巻かれて、門口で送り火を見あげていた。

腹を立てて甕場へ入った祖父は、甕に手を入れている祖母を見つけたのだ。小夜叔母にしたように、手首をつかんだだろう。布は甕に落ちる。女の布が入ったままでは藍が死ぬ、と信じている人だから、すぐに膝をついて、見えない目を水の面まで近づけ、腕を沈めた。嫁に来た年に爪を軽石でこすられ、それを四十年、笑い話にしてきた人の前に、その首があった。

考えてしたことではなかったと思う。初めての一枚を、また取りあげられる。祖母の両手は、そう思うより先に、祖父の首を押さえていた。祖父が動かなくなってから、祖母は自分で布を拾い、戸を閉めて、そこへ私が走ってきた。

私の膝を巻いたときも、祖母は何も考えていなかったのだろう。血を見て、手に布があって、その布は初めから私にやるはずのものだった。それから我に返り、私を母屋へ向かせて、じいちゃんはいま甕を覗きよる、と言った。嘘ではなかった。

我に返った祖母がしたことは、二つある。

団子の皿を、祖母は前掛けの端でくるんで持って出てきた。ゆでたてで熱いからだろうと、十歳の私は気にもとめていない。あの前掛けの下の手は、台所でいくら洗っても、もう白くはなかったはずだ。そして伯父が叫んだとき、祖母は私の横をすりぬけ、敷居をまたいで、両腕を肘まで甕に突っこむ。そうしてしまえば、それは亭主にすがった女の手になる。お婆さんまで肘まで浸かっとる、と刑事は言った。

「母はね、あの晩のことを死ぬまで悔やんでました」と千秋が言う。「源次さんの家の小さい甕で、隠れて習いよったんです。おじいさんが甕で亡うなった晩に、甕に触っとりましたとは言えんで、川におったと嘘をついた。源次さんも黙ってくれた。ほんまのことを言うとったら、清一伯父さんばっかりが疑われんですんだかもしれんのに、て」

伯父は町を出て、よその染工場で勤めあげて死んだ。祖母は刑事に、清一はそんなことのできる子と違います、と答えている。本心だったろう。それでも、すぐ行くと返事がありました、という一言だけは取りさげなかった。あの一言は、祖母が甕場で祖父と二人きりだったことを消し、祖父を、祖母が戸口を離れたあとまで生かしておいた。そのあとで甕場へ入っていったのは、伯父ひとりだ。

亭主の甕を守りよるんやと、みな言うてくれる。納屋で青い腕を上げてみせた祖母は、そう言って笑った。自分では一度も、そうだとは言わなかった。

竿の手ぬぐいは、もうすっかり乾いた色をしている。

「甕覗きだね」

「よう知ってますね」

「教わったんだ。干し場で」

善蔵を殺したのは、その妻のとき、私の祖母だ。

帰りの列車で、私は鞄から古いほうの手ぬぐいを出し、新しいのと重ねてみた。同じ色をしている。古いほうの隅には私の血があり、膝にはいまも、あの敷石の角の痕が白く残っている。祖母が生まれて初めて染めた布は、私の傷をしばるのに使われた。あのぬるい手が震えていたかどうかを、思い出そうとしたが、どうしても思い出せなかった。
