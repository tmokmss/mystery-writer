# 白いタイル

「笛木さん、このお皿、作ったご本人としては、あと何回で割れると思います？」

　野々村さんは笑って聞いた。私も昨日までは、笑って答えられた。そろそろ一枚くらい割れてくれた方が、私としては気が楽だ。

　保坂が新品の箱を開ける。野々村さんは下から二枚目を抜き、腰の高さで手を開いた。足元には、白いタイルを敷いた畳一枚ほどの台がある。皿は縁からそこに落ちた。くるくる回って収まった皿を私が拾い、野々村さんの指に縁を一周してもらう。傷はない。飲食店向けの展示会で、昨日から三十人ばかりが同じことをした。

「じゃ、こっちも見てくれますか」

　野々村さんが弁当包みを開くと、同じ皿が真っ二つになっていた。

「昨日お借りしたうちの一枚です。今朝、うちの店で一度落としたら、これ」

　厚く丸めた縁も、裏の小さなそら豆の絵も、確かに私の皿だった。

　私と保坂が二人で会社を始めて一年になる。この皿でいちばん苦労したのは、洗い場で皿同士をぶつけても縁が欠けにくく、それでいて、五枚重ねて片手で持てる厚さにすることだった。野々村さんは定食屋を八軒回って仕入れをしている。昨日「これなら流し台から手が滑っても安心だ」と言われて、私はうれしくて、見本を二枚包んで渡した。

「一枚も割れませんとは言えません」と私は言った。

「ええ、陶器ですもんね。でもそれなら、お店より、ここでとっくに割れてそうなもんでしょう」

　私も同じことを考えていた。昨日などは、両手で頭の上まで持ち上げた男の人がいた。割れたっていいですよ、と声を掛けたのは私だ。私の方が目をつぶった。

「会場だけ特別いいのを持ってきた、なんてことはありませんよ。同じ工場で一緒に焼いてます」

　保坂の言うとおりだった。まだ一度しか工場に注文できていないのだ。保坂は先月から何度も工場に頭を下げて、次に焼いてもらう日を延ばしている。八軒分の注文が決まれば、ようやく窯を押さえられる。

「もう一枚の方も、お持ちですか」

　野々村さんは布袋から無傷の皿を出した。「今日は二枚とも返そうと思って」

「一度、ここで試していただけませんか。お店で落ちたときの高さで。落とした方に、どんな具合だったか聞けるといいんですが」

「私ですよ。開店前に店長の所へ持っていってね。まあ見ててって言って、こう」

　指が開いた。さっきよりずっと低い。皿は一度縁で立ち、裏返って、野々村さんの足元で止まった。彼女は裏のそら豆を見下ろしていた。

「今朝も、この絵が上を向いてた。半分ずつに分かれてね。あのときの店長の顔ったら」

　昨日の私と同じことを、今朝、この人は店でやったのだ。私があんなにうれしそうな顔をしたからだろう。手元の半月を二つ合わせると、そら豆が一粒に戻った。

「見本をもう何枚かお貸ししましょうか」と保坂が言った。

「私が八軒回って、割って歩くんですか」

　保坂は開けかけた箱を閉じた。野々村さんの布袋には、二つ折りの注文書が入っていた。店ごとに必要な枚数が、鉛筆で細かく入れてある。

「軽いのは、みんな気に入ってるんですよ。けど、昨日の話をどう訂正すればいいか分からない。笛木さん、ここだと、どうしてこんなにもつんですか」

　皿を借りたかったのは、その質問に答えるためだった。ところが店へ持っていった皿まで、ここでは無傷で転がっている。

　昼休みを知らせる放送が入り、野々村さんはいったん通路のベンチに腰を下ろした。昼のうちには帰らないと、と時計を指している。

　実演台の隅に小さな白い三角が光っていた。弁当包みからこぼれた欠片だ。拾いにかがむと、白いタイルの目地に、茶色い油の染みが見えた。母がまだ定食屋をやっていた頃、流しの下をいくら磨いても、ああいう汚れだけは落ちなかった。保坂が会場を手配してくれて、昨日初めてここに立ったときも、うちの台所によく似た所に皿が戻ってきたのが、私は何よりうれしかった。

　指に付いた白い粉を払って、もう一片ないかと台の反対側へ回った。こちらの目地にも、そっくりな茶色の染みがあった。先が二つに割れて、魚の尾みたいに曲がっているところまで。
