# 読者回答（問題編のみ読んだ時点）

## 1. 起きたことの説明（自分の言葉）

笛木（皿を作る会社の一人）が、定食屋の仕入れ担当の野々村に見本の皿を渡した。野々村の店で皿を落としたら割れた。展示会の白いタイルの台で同じ皿を落としても、割れない。野々村は割れた皿と無傷の皿を持ってきて、台の上で落としてみる。笛木は「なぜ店では割れて、ここでは割れないのか」を知りたがっている。

思い浮かべられなかった所:
- 割れた皿が「店で落とした」ものなのか、「ここで落とした」ものなのか、一度では追えなかった。
- 「私ですよ。開店前に店長の所へ持っていってね」の「私」が野々村なのか、別の人なのか、はっきりしなかった。
- 「店へ持っていった皿まで、ここでは無傷で転がっている」の「皿」が、どの一枚を指すのか分からなかった。
- 白いタイルの台が皿の割れ方にどう関わるのか、本文には仕組みが書かれていないので想像できなかった。

## 2. 何が起きたと思うか

- 方法: 店の床と展示台で、落ちたときの受け止められ方が違うのではないか。台が衝撃を和らげているのかもしれない。
- 犯人: この話が誰かの仕業を探す形なのかは、問題編の時点では分からない。もし細工があるとすれば、皿を入れ替えた人か、箱を開けた保坂のどちらか。確信はない。
- 動機: 分からない。

## 3. 途中で怪しいと思った描写（本文から）

- 「保坂は開けかけた箱を閉じた。」
- 「野々村さんの布袋には、二つ折りの注文書が入っていた。店ごとに必要な枚数が、鉛筆で細かく入れてある。」
- 「もう一枚の方も、お持ちですか」「野々村さんは布袋から無傷の皿を出した。」
- 「昼のうちには帰らないと、と時計を指している。」
- 「白いタイルの目地に、茶色い油の染みが見えた。」「流しの下をいくら磨いても、ああいう汚れだけは落ちなかった。」
- 「私の方が目をつぶった。」

## 4. 続きを読みたさ（1〜5）

- 冒頭から皿が割れた場面まで: 4。皿が割れるのに、展示台では割れないという謎に引き込まれた。
- 「保坂は開けかけた箱を閉じた。」あたり: 3。話が少し止まって見え、野々村の注文書の話が何につながるのか分からなかった。ここで読むのをやめるほどではなかった。
- 油の染みの段落: 4。母の店の流しの話で、場面に生活の手触りが出た。

## 5. 犯人予想（問題編を読み終えた時点）

- 犯人: 野々村（約30%）
- 理由: 割れた皿を持ち込んだのは彼女だけで、店で落としたという話も彼女の証言しかない。「私ですよ」「店長の所へ持っていって」と行動が語られるのも彼女だけ。ただし、出来事の中身というより、書き方（彼女の行動が多く書かれている）から疑った面が強い。
- 残りは、特定の誰かではなく、台の仕組みや店の環境のせいだと考えている（約70%）。

## 手順2（解決編を読んだ後）

### 明かされた事実と驚きの度合い

1. 台のタイルは本物ではなく、灰色のスポンジにタイルの写真を印刷したシートを貼ったもの。 → 少し意外。台が衝撃を和らげているという予想は当たったが、本物のタイルではなく写真だとは思わなかった。
2. 保坂が設営の日に本物のタイルを敷き、三枚落として二枚割れたので、スポンジに替えた。 → とても意外（おー）。保坂が割れた事実を隠して、皿が割れない台に替えていたという流れで、ここで話が一本につながった。
3. 保坂は笛木に床を替えると言わず、替えた。 → 少し意外。売り込みの苦労は納得できるが、割れた理由を笛木に相談せずに直すのは、予想していなかった。
4. 笛木が「落としてみてください」と勧めたので、野々村が店長の前で手を離した。 → 予想どおり。店で割れた流れの説明として妥当。
5. 店で割れた理由は、解決編で一言も書かれていない。読者が推測するしかない。 → 少し意外。店の床が硬いという前提は読み取れるが、明言はない。

### 一番「おー」となった所

保坂が設営の日に本物のタイルで皿を二枚割っていた、という一行。問題編の「油の染み」が、台の写真シートの目地と合う伏線として効いてきた点も、あとから振り返って「おー」だった。

### 問題編の手がかりの扱い（解決編で使われたもの）

- 白いタイルの目地の油の染み: 問題編で「母の店の流し」の話として読み、気にとめた。解決編では台が写真シートだと分かる手がかりになった。読んだときは、ただの生活の描写と受け取っていた。
- 三十人ばかりが同じことをした: 読んだ覚えあり。客が皆、台で落としていたことが、台の作り物だと気づく前提になっていた。気にとめていなかった。
- 保坂が新品の箱を開け、開けかけた箱を閉じた: 読んだ覚えあり。気にとめていたが、解決編の真相とは関係がなかった。
- 昼休みの放送と時計: 読んだ覚えあり。気にとめていなかった。解決編では、野々村がベンチで注文書を広げる場面に使われた。

### 作者が一番驚かせたかったと思う真相と、実際の驚き

作者が驚かせたかったのは、台が作り物で、しかも保坂が売るために割れた事実を隠していた、という点だと思う。実際に一番驚いたのは、保坂が本物のタイルで割っていたこと。ただ、問題編で「保坂」を犯人候補に挙げておきながら、野々村を30%と高く見積もったのは外れた。野々村は割れた皿を持ってきただけで、何も隠していなかった。

### 読んでいて引っかかった文・読みにくかった文

- 「指に付いた白い粉を払って、もう一片ないかと台の反対側へ回った。」: 「もう一片」が何の欠片か、直前に説明がなく、一度では読めなかった。
- 「頭の上から落としたあの一枚も、これで受け止めたのだ。」: 「あの一枚」がどの場面か、すぐには思い出せなかった。
- 「私が落としてみてって勧めたから、野々村さん、店長さんの前でも安心して手を離したんだよ。」: 話し手が笛木なのか、直前の保坂なのか、一読では判断しにくかった。
- 「保坂が実演を始めた理由」の段落は、保坂が「笛木に言えば止められる」と思っていた、という経緯が一文で分かりにくかった。

### 結末

「白いタイルを裏返して、保坂が謝る」で終わる。話としては、ここで終わってよいと思った。笛木の反応がないまま終わるが、それで十分だと感じた。

### 回想・台詞の中で語られる、物語の前の行動（一つずつ）

1. 保坂が、設営の日に本物のタイルを敷き、三枚落として二枚割れた（解決編）。 → 自分ならそうするか: 本物を敷くのは自然。ただ、割れた時点で止めるのが普通なので、ここは納得しにくい。
2. 保坂が、何軒もの店に「軽い皿」と売り込み、見積もりを渡したが、返事がなかった（解決編）。 → 納得できる。営業ではよくある話。
3. 保坂が、床を替えるなら笛木に言わず、タイルをスポンジに替えた（解決編）。 → 変。割れた皿の仕事を、共同経営者に相談せず一人で直すのは、暮らしの感覚では考えにくい。しかも時期は書かれていない。
4. 保坂が、目の前で落とす実演を始め、人が足を止めた（解決編）。 → 納得できる。売るための見せ方として自然。
5. 笛木が、昨日、野々村に見本の皿を二枚包んで渡した（問題編）。 → 納得できる。
6. 笛木が、客に「落としてみてください」と勧めた（問題編と解決編）。 → 納得できる。見せ方としてよくあることだと思う。
7. 野々村が、開店前に店長の前で皿を落として見せた（問題編）。 → 少し変。店長に見せるために、わざわざ店で落とすのは、暮らしの感覚では少し不自然。

### 犯人予想との照合

- 問題編の時点の予想（野々村30%）は外れた。
- 真の行為者は保坂だった。問題編で保坂の「箱を開けた」描写は読んだが、そこで保坂を強く疑わなかった。台の仕組みを考えるなら、保坂を先に疑うべきだった。
