# 読者役Sonnet 回答

## 手順1（問題編だけを読んだ時点）

### 何が起きたか（自分の言葉で）
陶器の皿を作った笛木さんと相棒の保坂が、飲食店向けの展示会で、白いタイルを敷いた台に皿を落として丈夫さを見せている。客の野々村さん（定食屋八店舗の仕入れ担当）は昨日見本を二枚借りて帰り、今朝、店で一枚を落としたら真っ二つに割れたと言って持ってきた。展示会場では三十人が落としても割れないのに、なぜ店では割れたのか、と問う。野々村さんは残りの一枚を実演台の前で落として見せ、こちらは割れない。昼休みに、笛木さんが台の隅で白い三角の欠片を見つけ、それが弁当包みからこぼれたもので、目地の茶色い染みが台のタイルと同じ、という所で終わる。
分かりにくかった点は、白い三角の欠片が皿のものなのかタイルのものなのかがはっきりせず、最後の染みの意味をうまくつかめなかったこと。

### 何が起きたと思うか
- 犯人: 野々村さん。
- 方法: 割れた皿は店で落として割れたのではなく、別の場所（たとえば硬い床）で割って持ってきたか、展示台のタイルのほうに細工がある。最後の欠片は、野々村さんが持参した別のタイルの破片で、台の上でそれを使って何かしている可能性。または、皿が割れない理由は実は台のタイルのほうが特殊（柔らかい下地など）で、それを野々村さんが見抜いている。
- 動機: 値引きをさせたいか、八軒分の注文を有利な条件に持ち込みたい。

### 怪しい・後で使われそうな描写
- 「目地に魚の尾のように先が二つに割れた茶色い染みが見えた」（前半と最後の二回出てくる。同じ染みが別の場所にある）
- 「野々村さんは下から二枚目を抜き」（箱の下から二枚目を選んだ描写）
- 「腰の高さで手を開いた」「足元には、白いタイルを敷いた畳一枚ほどの台」
- 「弁当包みを開くと、同じ皿が真っ二つになっていた」（弁当包みから出てくる）
- 「今朝、うちの店で一度落としたら」「開店前に店長の所へ持っていって」
- 「半分ずつに分かれてね」「裏のそら豆を見下ろしていた」「この絵が上を向いてた」
- 「布袋から無傷の皿を出した」「今日は二枚とも返そうと思って」
- 「野々村さんの布袋には、二つ折りの注文書が入っていた」（鉛筆で細かい枚数）
- 「昼のうちには帰らないと、と時計を指している」
- 「小さな白い三角が光っていた。弁当包みからこぼれた欠片だ」
- 「私の方が目をつぶった」（笛木が落とされるのを見られない）
- 「母がまだ定食屋をやっていた頃、流しの下をいくら磨いても…」
- 「まだ一度しか工場に注文できていないのだ」

### 章ごとの続きを読みたい気持ち（一章のみ）
- 評価: 4。冒頭の「あと何回で割れると思います？」と、弁当包みから割れた皿が出る所で上がった。
- 下がった所: 保坂が見本を貸そうと言い、箱を閉じる辺りは、状況説明が続いて少し流れが止まった。
- 途中でやめたか: やめない。短いので最後まで読む。

### 犯人予想（章を読み終えた時点）
- 野々村さん 50%。理由は出来事の中身（割れた皿を弁当包みに入れて持ってくるのが妙、最後に欠片がこぼれる）と、書き方（この人の動作の描写が多い）の両方。
- 保坂 10%。工場の話や日取りの話が出るが、それ以上の根拠はない。書き方の面が強い。
- 笛木 0〜5%。語り手なので。
- 残りは、誰かが悪いわけではなく単なる偶然や仕組みの問題（台のタイルのほうが割れにくい）という線が40%。

## 手順2（解決編を読んだあと）
（以下は解決編を読んでから書き足す）

### 解決編で明かされた事実
1. 実演台の白いタイルは、タイルの写真を印刷したシートを貼った灰色のスポンジだった。魚の尾の染みが二か所で同じ形なのは、同じ写真の繰り返しだったから。 → とても意外（おー、となった）。同じ染みが二回出てくるのは気にとめたが、床そのものが偽物だとは思わなかった。野々村さんを疑っていたので、皿ではなく台のほうに細工があるという案は頭の隅にあった程度。
2. 親指を当てると汚れも目地もへこむ、という確かめ方。 → 少し意外。手触りで分かる、という手がかりの出し方が分かりやすかった。
3. 設営の日、本物のタイルで三枚落としたら二枚割れた。 → 少し意外。展示会で一枚も割れないことを笛木が不思議がっていた理由がここで通る。
4. 保坂がそれを笛木に黙ってスポンジに替えた。動機は、売り込みが空振りに終わっていたから。 → 少し意外。保坂を疑う線はほぼ消していたが、事情は納得できる。
5. 欠片は割れた皿の縁にぴたりとはまる、皿のかけらだった。 → 予想どおり。欠片が出てくる時点で、割れた皿の一部とは思った。
6. 野々村さんは何も企んでいなかった。 → 少し意外。最初に疑った人物が白だった。
7. 保坂が自分から野々村さんに謝る。 → 予想どおり。

### 一番「おー」となったところ
台の端をつまむとタイルが一列ぺろりとめくれ、スポンジに写真を印刷したシートが貼ってあったと分かる所。「三十人もの客に自分で皿を選んでもらって、私はずいぶん正直な売り方をしているつもりでいた」と、笛木の自信が逆に刺さる所も良かった。

### 解決編の手がかりと、問題編での記憶
- 魚の尾のような染みが二か所に同じ形である: 覚えている。気にとめたが、床の偽物とは結びつけなかった（染みが皿の接点にあるのは母の台所の話と思った）。
- 「割れたっていいですよ、と声を掛けたのは私だ。私の方が目をつぶった」: 覚えているが、気にとめていない。
- 「皿は縁からそこに落ちた。皿はくるくる回って台の手前で止まった」: 覚えている。普通の高さなら何度か跳ねそうだが、くるくる回っただけで止まるのは確かに違和感があった。ただ見逃した。
- 「保坂が新品の箱を開ける」「会場を手配してくれた」: 覚えているが、保坂が床にも手を入れる人とは思わなかった。
- 工場に一度しか注文できていない、八軒の注文が決まれば日取りの相談ができる、という保坂の事情: 覚えている。動機の手がかりとして効いている。気にとめたのは、保坂の焦りというより笛木の状況説明としてだった。
- 「昨日などは、両手で頭の上まで持ち上げた男の人がいた」: 解決編で再度出るので覚えているが、問題編ではただの印象づけとして流した。
- 野々村さんが皿を足元に落とす場面「皿は一度縁で立ち、裏返って」: 覚えているが、手がかりとは思わなかった。

### 作者が一番驚かせたかった真相と、実際の驚き
台がスポンジの偽物だったこと。実際に一番驚いたのもそこ。ただ、問題編で「ここだと、どうしてこんなにもつんですか」と問いが明確に出ているので、台の仕組みを疑う読者は多いと思う。私は犯人探しに気を取られて、少し遅れて気づいた。

### 引っかかった文・読みにくかった文
- 「皿を野々村さんに渡し、指で縁を一周してもらう。傷はない。飲食店向けの展示会で、昨日から三十人ばかりが同じことをした。」: 実演の流れの中で、誰が何をしたかが一度では取りにくかった。
- 「昨日は私が、お客さんに『落としてみてください』と勧めた。それを今朝、野々村さんは店長さんに見せようとしたのだ。」: 野々村さんが店長に何をしたのかが少し回りくどい。
- 「昨日包んだ二枚のうち、店で割れた一枚は私の手元にある。今ここで落とした方は野々村さんの足元に傷一つなく転がっている。」: 状況の整理としては良いが、枚数の数え直しになって少し頭を使った。
- 「保坂は台の縁に手を掛けたまま、ベンチに目をやった。」の前後の流れ: 弁当の数を取る声と保坂の動作の関係が分かりにくい。
- 問題編の最後の段落（母の定食屋の記憶）: 何のための描写かが問題編の時点では分からなかった。

### 「もう終わってよい」と思ったのに続いた所
保坂が謝る最後の台詞まで読んで、終わり方としては自然。強いて言えば、「私は二つに割れた皿と小さな欠片を弁当包みに戻した」あたりからの移動の描写は少し事務的だが、間延びはしていない。終わりは「申し訳ありませんでした」で良い。

### 物語が始まる前の人物の行動と、自分ならどうするか
1. 笛木が二人で会社を始め、皿を厚く、洗い場でも割れにくい設計にした。 → する。目的がはっきりしている。
2. 保坂が会場を手配した。 → する。
3. 保坂が設営の日に本物のタイルで三枚落とし、二枚割れた。 → する。確認は自然。
4. 保坂が笛木に黙って、台をスポンジに替えた。 → しない。自分ならまず相棒に言う。ただ、笛木が実演自体をやめようと言うだろうという保坂の言い分は、本文を読むと納得はできる。それでも割れる皿を「割れにくい」と見せる偽装は、飲食店に売る以上、後で必ず分かるので、普通は避ける。
5. 保坂が何軒も売り込んで回ったが、見積もりを渡してもそれきりだった。 → する。
6. 笛木が昨日、野々村さんに見本を二枚包んで渡した。 → する。
7. 笛木が客に「割れたっていいですよ、落としてみてください」と勧めた。 → する。実演を勧めるのは自然。
8. 野々村さんが今朝、開店前に店長の前で皿を落として見せた。 → 少し変。昨日会場で見ただけの皿を、店長の前でいきなり落とすのは度胸がいる。ただ、割れないと信じていたから、という本文の理由づけで納得はできる。
9. 野々村さんが割れた皿を弁当包みに入れ、残りの一枚と一緒に持ってきた。 → する。返すつもりなら自然。
10. 工場に一度だけ注文し、次の注文を先月から聞かれている。 → する。
