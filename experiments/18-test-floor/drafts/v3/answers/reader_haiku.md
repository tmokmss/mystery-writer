# 読者役 Haiku の回答（白いタイル）

## 手順1（問題編だけを読んだ時点）

### 何が起きたか（自分の言葉で）

笛木は皿の製作者で、保坂と会社を二人でやっている。野々村は定食屋八店舗の仕入れを任されている人で、昨日笛木から見本の皿を二枚借りた。今朝、野々村の店で借りた皿の一枚が真っ二つに割れた。野々村は割れた皿と、無傷の皿をもう一枚持って展示会場に来ている。会場の白いタイルの台で皿を落としてもらう試し方をしているが、ここでは誰が落としても割れていない。野々村は「店で落とした」と言うが、その落とし方は細かくは描かれていない。笛木は、この皿がなぜ店で割れてここで割れないのかを説明できずにいる。

思い浮かべにくかったのは次の二点。
- 店で落ちたときの高さと状況。「開店前に店長の所へ持っていって、まあ見ててって言って、こう」とあるが、どこから、どの向きで落ちたのかが掴めない。
- 皿の裏の「そら豆の絵」が上を向いて割れたという話。割れ方と絵の位置が結びつかなかった。

### 何が起きたと思うか

犯人は笛木だと思う。皿を作ったのは笛木で、店に渡した皿の出どころを知っているのは笛木だけに見える。割れたのは店の皿で、展示会で試した皿とは別物ではないか、と疑った。ただ、確かな根拠は読んでいない。動機は、店の注文を取り戻すため、あるいは失敗を隠すため、などが頭に浮かんだが、どれも決め手はない。

### 怪しいと思った描写（本文から）

- 「保坂の言うとおりだった。まだ一度しか工場に注文できていないのだ。」（工場の話が唐突に出てくる。量産の状態が分からない。）
- 「ここでまだ一枚も割れていない方が、私には不思議だった。」（笛木自身も不思議に思っている点。）
- 「割れたっていいですよ、と声を掛けたのは私だ。私の方が目をつぶった。」（笛木が割れることを内心で望んでいたのか、怖がっていたのか、読み取れない。）
- 「昨日初めてここに立ったときも、うちの台所によく似た所に皿が戻ってきたのが、私は何よりうれしかった。」（笛木の母の定食屋の話が、最後の方で急に出てくる。ここで笛木の過去が気になった。）
- 「目地に魚の尾のように先が二つに割れた茶色い染みが見えた」（同じ染みが二回出てくる。一回目は皿が落ちた台の目地、二回目は床に落ちた欠片のそばにある。同じ物なのかが引っかかった。）

### 章ごとの続きを読みたい気持ち（この作品は章の区切りがないので、区切りごとに付けた）

- 冒頭から「割れた皿を見せられる所」まで: 4。野々村の立場と、皿の出どころがじわじわ分かってくる。
- 「私ですよ。開店前に店長の所へ…」まで: 4。落とした本人が出てきて、話が動く。
- 「昼休みを知らせる放送」以降: 3。ここまでで何が問題か分かったので、ペースが落ちた感じがした。
- 最後の段落（母の定食屋の話）: 4。急に過去が出てきたので、次に何が出るかは気になった。

普段の読書なら、最後の段落の前でやめていたと思う。「流しの下をいくら磨いても」の所まで読んで、これは何かの伏線だと思ったので、その後まで読んだ。

### 犯人の見当（区切りごと）

- 冒頭から割れた皿を見せられる所まで: 犯人は分からない。笛木が怪しいという程度。確かさ 20%。疑った理由は、書き方（笛木の内心が多く語られている、「割れたっていいですよ」の一文が意味ありげ）。
- 「私ですよ」の所まで: 笛木が怪しい。確かさ 35%。落とした野々村が、店で自分が落としたと言っている。そう言わせる理由が、野々村の側にあるかもしれないと思った。
- 最後まで（ここでは問題編の終わりまで）: 笛木。確かさ 40%。理由は、出来事の中身として、皿の出どころを笛木だけが知っているように見えるから。書き方の理由ではない。

### 問題編の時点で一番「怪しい」と思ったもの

母の定食屋の話と、「まだ一度しか工場に注文できていないのだ」の一文。どちらも笛木の事情に関わる気がして、後で使われると感じた。

## 手順2（解決編を読んだあと）

### 解決編で明かされた事実

1. 台の白いタイルは本物ではなく、灰色のスポンジに白いタイルの写真を印刷したシートだった。 → とても意外。台の上で皿が割れない理由を皿の厚さや作りに求めていたので、足元の作り物にはまったく思い至らなかった。
2. 皿の目地の「魚の尾」の染みは、指で押すとへこむ（印刷された絵）ものだった。 → とても意外。問題編で同じ染みが二回出てきたのに、本物の汚れだと思って読み流していた。
3. 設営の日に保坂が本物のタイルで三枚落とし、二枚割れていた。 → 少し意外。割れた経緯はありそうだが、割れた後に床を替えたとは思わなかった。
4. 床を替えたのは保坂が一人で決めたことで、笛木には相談しなかった。 → 少し意外。保坂が笛木に言えば止められると考えて黙っていた、という理由が付いたので納得はした。
5. 本物のタイルで試すと皿が割れたので、保坂が床をスポンジに替えた。 → 予想どおり。店で割れて展示で割れないのは床の違いだろうと、途中から考えていた。ただ、床を替えた理由が本文に書かれている所までは予想していなかった。

### 一番「おー」となったのはどこか

「指の腹の形にへこんだ」の一文。魚の尾の染みが印刷で、タイルの下が灰色のスポンジだと分かった所。問題編の二回の染みが急に一本につながった。

### 問題編で読んだ手がかりの覚え（問題編を読み返さずに答える）

- 白いタイルの台（畳一枚ほど）: 覚えあり。台だとは読んだが、材質は気にとめなかった。
- 目地の魚の尾の染み（二回）: 覚えあり。同じ物か気になって書いたが、本物だと思った。
- 割れたっていいですよ、と声を掛けたのは私。私の方が目をつぶった: 覚えあり。笛木の不安の描写だと思って気にとめた。
- 昨日の男の人が両手で頭の上まで持ち上げた: 覚えあり。割れなかったことの不思議さに使われていると思った。
- 欠片（弁当包みからこぼれた白い三角）: 覚えあり。割れた皿の欠片として読んだ。
- 保坂の一度しか工場に注文できていない: 覚えあり。解決編では使われなかった（気にとめたが、関係は無かった）。

### 作者が一番驚かせたかった真相で、実際に一番驚いたか

真相は保坂が床を偽って展示の皿を割れにくく見せていた、という所だと思う。実際には、笛木が犯人かもしれないと疑っていたので、保坂が床を替えたと知ったときは驚いた。ただ、保坂を疑っていたわけではなく、驚いたのは「床の偽装」という発想のほうだった。一番驚いたかといえば、十分に驚いた。

### 読んでいて引っかかった文

- 「手を離すと白いタイルがゆっくり平らになる。」: 何が平らになるのか一度では掴めなかった。スポンジが沈んだのだと分かるまで読み直した。
- 「三十人もの客に自分で皿を選んでもらって、私はずいぶん正直な売り方をしているつもりでいた。」: 正直という言葉が、何を指しているのか掴みにくかった。
- 「床を替えるなんて笛木に言えば、皿を落とす実演はやめようって言うだろ。」: 実演をやめる理由と、床を替える理由のつながりが、一度では読めなかった。

### 結末で「もう終わってよい」と思った所

無し。「申し訳ありませんでした」で終わるのが自然で、その後の余韻に不要な続きは無かった。

### 回想・台詞の中の、物語が始まる前の人物の行動

1. 保坂が設営の日に本物のタイルを敷き、三枚落として二枚割れた。（誰が・いつ・何をしたか: 保坂、設営の日、本物の床で試し落とし）
   - 自分ならどうか: 割れたら困るので、試すこと自体は自然。ただ、その床で割れた事実を見て、すぐ床を変える判断をするのは理解できる。納得できる。
2. 保坂が何軒も売り込みに回り、見積もりを渡したが返事がなかった。（誰が・いつ・何をしたか: 保坂、設営前、売り込み）
   - 自分ならどうか: 営業としては普通。納得できる。
3. 保坂が本物の床をスポンジのシートに替えた。（誰が・設営の後・床を偽装）
   - 自分ならどうか: 変だと思う。共同経営者の笛木に言わず、皿の性能を偽るために床を替えることは、暮らしの感覚では考えにくい。本文の「笛木に言えば止められるから」という理由は、止められると分かっているからこそ黙ってやった、ということで、納得しにくい。
4. 笛木が昨日、野々村に「落としてみてください」と勧めた。（誰が・昨日・落とすよう勧めた）
   - 自分ならどうか: 展示会の実演として普通。納得できる。
5. 保坂が、野々村さんの前に裏返したタイルを置いた。（誰が・今・床を見せた）
   - 自分ならどうか: 謝る場面として自然。

### 手順2の終わりに

一番引っかかったのは、保坂が笛木に相談せず床を替えた所。理由は「言えば止められるから」で、それで偽装を一人で決めるのは、暮らしの感覚では納得しにくい。
