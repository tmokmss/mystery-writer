# 18 Codex（Astra 6.2）の書いた「白いタイル」

[実験17](../17-paper-ballot/README.md)に続き、人間の依頼で書き手をCodex CLIのGPT-6.2-Astra（`gpt-6.2-astra`）にした。お題は人間が「スタートアップ」と決めた。書く手順（`scripts/writer_guide.md`）と前作の結論・人間の感想を読ませ、[先行研究の調査](../../research/AIによる物語生成の先行研究/report.md)から足した手順として、書く前に `ideas.md` に核の案を5つ出させ、ほかのAIが同じお題で思いつきにくい案を選ばせた。第2稿・第3稿は、同じCodexの会話を再開し、直す場面を挙げて、挙げていない場面は変えないよう指示した。

評価役（Opus・Codex）と読者役（Haiku・Sonnet）に読ませ、3稿まで直させた。評価役のCodexは、書き手とは別のモデル（GPT-6.2-Sol）である。

## 筋

- 舞台は飲食店向けの展示会。笛木と保坂が二人で始めて一年の食器会社が、軽くて縁の欠けにくい皿を出している。実演では、客が箱から自分で皿を選び、白いタイルの台へ落とす。二日で三十人ほどが試し、一枚も割れていない。
- 事件: 定食屋八店舗分の仕入れを任されている野々村さんが、前日に借りた見本二枚のうち一枚を真っ二つにして持ってくる。店長の前で一度落としただけで割れた。もう一枚を会場の台で同じように落とすと、傷も付かない。
- 手がかり: 冒頭で皿を拾ったとき、台の目地に魚の尾のような二股の油染みがある。問題編の終わりに、台の反対側でかけらを拾うと、同じ言葉で描かれた染みがある。笛木は母の定食屋の流しの下を思い出す。
- 真相: 二つの染みは曲がり具合まで同じだった。親指で押すと目地ごとへこむ。台はタイルの写真を印刷したシートを貼ったスポンジで、会場を手配した保坂が敷いた。設営の日に本物のタイルで三枚落として二枚割れたので替えた。笛木に言えば実演をやめると言われると思い、黙っていた。
- 一番驚かせる所: 硬い床だと思っていた台が指でへこみ、一列めくれる。笛木が母の店を思い出して懐かしんだ油染みまで印刷だった。
- 感情の決着: 笛木は「あの人に皿を包んだのは私だもの」と保坂と一緒にベンチへ行く。保坂は野々村さんの前にタイルを裏返して置き、自分がスポンジに替えたと謝る。そこで終わる。

## 結論

- **書く前に案を出させた:** Codexは5案（ほかに、旅行写真の古着レンタル、撮影用に小さい小道具を並べたベッドの見本、など）を出し、ほかのAIが思いつく見込みを2%と見積もった「白いタイル」を選んだ。見込みの数字は書き手の主観で、確かめようがない。
- **長さは前作と同じく短い:** 本文は問題編約1,700字、解決編約700字で、Codexの前作（問題編約1,200字、解決編約600字）と同じくらい、Fableの作品の4分の1から半分だった。
- **直しで、読者役が犯人を当てなくなった:** v1では読者役2人とも、問題編の時点で保坂を最有力に挙げた（Sonnet40%、Haikuは床の仕組みを40%、保坂15%）。v2ではSonnetが保坂25%、Haikuは野々村さんを30%とし、保坂は細工があるなら候補の一人と書くにとどまった。v3では2人とも保坂を挙げず、野々村さん50%と笛木40%を予想した。v3で効いたのは、評価役Opusの指摘で「保坂が会場を手配してくれて」を油染みの段落から会社紹介の段落へ移したことと、保坂の先回りの台詞「会場だけ特別いいのを持ってきた、なんてことはありませんよ」を野々村さんの問いへの答えにしたこと。読者役が犯人を外したのは、実験16・17の延べ12回では一度も無かった。
- **核の驚きは3稿とも読者役の一番だった:** 6回とも、一番「おー」となったのは床がへこむかめくれる場面か、本物のタイルで割れていたこと（v2のHaiku）だった。評価役のOpusはv1で「核で一番大きな驚きは出ていない」（意外さ2）とし、v3で「出ているが突き抜けてはいない」（意外さ3）に上げた。Codexは3稿とも、核の驚きが一番大きいと判定した。
- **手がかりの置き方で、評価役2つの意見が割れた:** v1は問題編の最後に、語り手が「反対側にもそっくりな染み」と言って終わった。Opusはこれで床が見抜かれると指摘した。v2で二つ目の染みを解決編へ移すと、Codexは比べる材料が問題編から消えたとして公正さを5から3に下げた。v3では、二つの染みを問題編の冒頭と終わりで同じ言葉で描き、「同じ」とは語り手に言わせず読者に比べさせた。Codexの公正さは5に戻り、Opusの意外さは2から3に上がった。
- **直す範囲を絞った指示は守られた:** v2・v3とも、前の稿との差分で、指示していない場面は書き換わっていなかった。
- **物語が始まる前の行動の確認:** 保坂が相棒の笛木に黙って床を替えたことを、読者役は6回とも、普通はしないか納得しにくいと挙げた。v2で保坂の告白に「床を替えるなんて笛木に言えば、皿を落とす実演はやめようって言うだろ」を足したが、v3でもHaikuは「納得しにくい」と書いた。
- **残った弱さ:** 皿がスポンジに落ちる音は、タイルに落ちる音より鈍いはずなのに誰も気づかない、とOpusがv1とv3で指摘した。v2で、野々村さんに店での音を言わせて手がかりに変える案を任意で渡したが、書き手は見送った。保坂の「見本をもう何枚かお貸ししましょうか」は、真相を知ると不自然だとOpusが指摘し、Codexは商談をつなごうとする人に見えるとして残してよいとした。残した。
- **表記:** 漢字の割合は問題編34.1%、解決編33.6%。常用漢字表にない字は0種。
- **評価のあとの直し:** v3の評価のあと、「布袋」を「布の袋」に（「ほてい」と読まれるおそれ）、「欠片」を「かけら」に（常用漢字表にない読み）直した（Opus）。再評価はしていない。

### 読み取れること

- **冒頭で状況の疑問を抱えさせた:** v3は台詞「このお皿、作ったご本人としては、あと何回で割れると思います？」から入り、実演の段落の最後でようやく「飲食店向けの展示会で」と場所が出る。二人の会社と野々村さんの立場は、真っ二つの皿が出たあとの段落で説明される。読者は「何の場面か」「誰か」を覚えたまま、皿が割れた謎を追うことになった。評価役のOpusはv3で「読者はこの段落を読み終えるまで、どこで何をしている場面かを組み立てられない」と書き、段落の頭に場所と保坂を置く案を出していたが、v3が最終稿だったので直さなかった。
- **Astraの特徴か:** Astraの2作（実験17・18）はどちらも、結果か台詞から入り、場面の前提を後の段落で説明した（実験17は「私の映画が八票取った。」から入り、投票の手順を後の回想で説明した）。Fableの実験15・16は「朝、聖剣がなくなっていた。」「宇宙から届いた信号の、最初の三分だけが消えていた。」と、何が起きたかを一文で言ってから場面に入っていた。2作ずつなので、書き手の癖かお題の違いかは分けられない。
- **手がかりの語:** 魚の尾の染みは、床のタイルの継ぎ目（目地）にある染みのつもりだった。人間は「目地」が分からず、割れた皿の断面の模様と読んだ。読者役のHaikuもv3で「皿の目地の『魚の尾』の染み」と書いていた。評価役のCodexは「目地」を、文脈で意味が取れる語とした。Opusは「核の手がかりに使う語なので、知らない読者はつまずく」と書いたが、これも最終稿の評価だった。
- **真相の大きさ:** 真相は展示会の実演台のごまかし一つで、スタートアップというお題ならではの事柄（資金、出資者、数字、共同創業者どうしの約束）に関わらなかった。評価役のOpusは3稿とも意外さ2〜3、トリックの面白さ3とし、「床が柔らかかったという種そのものは、一般の読者が聞いて『なるほど、そう来たか』と言うほどの新しさはない」と書いていた。
- **挿絵について:** 手がかりが文章だけで思い浮かばないのは書き方の問題で、挿絵で補うと、文章で伝わらないことが見えなくなる。読むページも文章だけの作りなので、挿絵は今回は足さない。

これを受けて、`scripts/writer_guide.md` に、最初の数段落で場所・人物・目的を分からせ、状況の疑問を抱えさせないこと、核の手がかりの物の場所と形を誰でも知っている語で書くこと、お題があるときは真相をお題ならではの事柄に関わらせることを足した。評価役の質問（読みやすさ、引き込み）と読者役の質問（場面が分かったのは何段落目か）にも足した。
