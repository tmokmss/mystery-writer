# 08 同じ筋を三つの文体で書いた「白いシャツ」（初稿の題は「姉の嘘」）

[実験07](../07-reversal/README.md)への人間の感想を受けて、核の仕掛けで驚かせることを優先した新作を、三つの文体で書き分けた。筋は三つとも同じで、文体だけを変えている。評価役（Opus・Sonnet・Codex、`scripts/judge_prompt.md`）と読者役（Haiku・Sonnet、`scripts/reader_prompt.md`）に読ませ、2稿まで直した。

07への人間の感想は次のとおり。
- 「十日前に高校生をはねて逃げたのは、義父の軽トラックだった　ここは意外だったけど、それ以外は予想できたなあ」
- 「ちゃんと肝心の部分で意外さを出したい」
- 「今の文体は〜したが連なってたり、短文の連続だったりで、余り好きじゃないかも」
- 文体の参考として挙げた三つの方向（連城三紀彦・宮部みゆき・米澤穂信）に対して、「新作を、文体は1〜3の3通りで書いてみて」

## 筋

- 梅雨の夜、義兄の浮気相手の路子が、自分の喫茶店の二階で殴り殺される。義兄は「家にいた」と言い、姉も「十時から夫婦でナイター中継を最後まで聞いていた」と証言する。その夜の試合は雨で中止で、嘘は崩れ、義兄は有罪になる。
- 真相: 姉は試合の中止を知っていた（昼、洗濯物の愚痴のついでに自分で言っている）。崩れるための嘘をついて夫を有罪にし、自分は「夫をかばった哀れな妻」として疑いの外に出た。路子を殺したのは姉。
- ひっくり返すのは「かばう嘘」の意味。核を「誰が」より「なぜ、どういう嘘か」に置いた。

## 文体（作家の特徴は記憶から書いている。文章は真似ず、文の長さ・文末・感情の書き方を参考にした）

- `renjo-*`（連城三紀彦の方向）: 叙情的な長い文で回想する。読点でつなぐ長文と、間を作る短文を混ぜる。
- `miyabe-*`（宮部みゆきの方向）: 生活感のある軽い一人称。煮豆の鉢、見合いの写真、着物などの細部と、語り手の感情を地の文で書く。
- `yonezawa-*`（米澤穂信の方向）: 理知的な一人称。冒頭の一般論、解決編の「順に考えてみる」で始まる推論、最後の「筋は通っている。少なくとも、今度は。」の対句。

## 結論

- **文体の評価:** 評価役はどの文体についても、07で指摘された「〜た。」の単調な連続が減ったと見た。
  - 連城の方向は、長文と短文の対比と冒頭の回想の一文が評価された。解決編の仕掛けの説明だけが論文のように浮くと指摘された。
  - 宮部の方向は、語り手の声と生活の細部、結末の「それが、なによりおそろしかった」が評価された。語り手が「聞いていなかった」と断る一文が、かえって手がかりの合図になると指摘された（v2で削った）。
  - 米澤の方向は、三つの中でヒントが最も抑えられていて核が守られている（v1のOpus）と評価された。解決編の推論の段落が講義調で感情が消える、と指摘された。
- **核の驚き（v1）:** 評価役は「ばれるための嘘」の驚きを3〜4とし、連城と米澤の方向では核で一番大きな驚きが出ていると判定した回が多かった。宮部の方向は、語り手の念押しで決め手が目立ち、核より後ろの動機（夫を閉じこめる）のほうが驚くと判定された。
- **読者役（v1、各文体2本）:** 6本とも問題編の時点で姉を犯人と見抜いた。核の「ばれるための嘘」は、Haikuの3本がそれぞれ「とても意外」と答え、Sonnetの3本は「予想どおり」だった。決め手の一言（姉の「雨で中止ですって」）が、刑事の「試合は中止になっている」と直結してしまうことを、全員が見抜いた理由に挙げた。
- **v2で直したこと（三つの文体で共通）:**
  - 姉が夜に出かけた手がかりとして、毎晩欠かさないアイロンがけの籠に、事件の翌日、前夜の分のシャツが皺のまま残っていた、を足した。
  - 決め手の一言を洗濯物の愚痴の中に埋め、語り手の「聞いていなかった」の念押しを削った。
  - 嘘を言い出したのは姉だと統一し、義兄の本当の証言が言い訳として聞き流されたことにした。刑事に「奥さんは、ご主人をかばうので精一杯だったんでしょう」と言わせた。
  - 中止の時刻（昼に決まっていた）と喫茶店の位置（坂の上、徒歩十分）をそろえ、題名を「白いシャツ」、挑戦文を「路子を殺したのは誰か」だけにした。
- **v2の結果:** Opusの評価役は三つとも意外さ2、Codexの評価役は2〜3で、筋の穴は一通り塞がった一方、犯人当てとしては易しいままと判定された。登場人物が実質三人で、逮捕された夫を除くと姉しか残らないため。読者役の6本中2本（宮部・米澤の方向のHaiku）は問題編の時点で義兄を犯人と読み、皺のシャツや「ばれるための嘘」で驚いた。新たな穴として、皺のシャツは雨に濡れた洗濯物だから仕上げられなかったとも読めること、往復二十分ならアイロンの時間は残ることが挙がった。
- **評価役と読者役の新しい観察:** 驚きの一番大きいところとして、核より後ろにある「夫が姉に、ありがとうと泣いて礼を言う」「夫を誰のものにもならない場所に閉じこめた」が挙がることが多かった。

## 人間の感想（v2）

- 文体: 「文体はどれもよくなったと思う　ただ冒頭は味わいがあったんだけど、それ以降は結局過去形の羅列になってる感じはあった」。冒頭は「今でも思い出すことがある」という語り手の今の声と情景で書かれているが、二章以降は起きたことを時間順に「〜た。」で報告する要約になっている（例: 連城の方向の「嘘は、それで終わりだった。義兄は…認めた。…聞いていた。…言い張った。」）。
- 人物の行動の筋: 結末で夫が面会のたびに姉へ礼を言う・頭を下げることについて、三回続けて食い違いを指摘された。
  - 「夫としては濡れ衣着せられてる感はあるんじゃないの」（夫は無実なのに有罪にされている）
  - 「妻は夫に嘘つこうって提案した側だよな　意味わからんぞ」（v2で「嘘を言い出したのは姉」にそろえたため、夫が姉に感謝する理由が消えた）
  - 「夫は自分がやってないことを知ってるんだから、嘘つこうとはならなくない？」（逆に夫が言い出したことにすると、無実の人が自分から嘘を持ちかける理由がない）
  - 筋が通る形は、姉が夫に頼まれもせず刑事の前でアリバイを言い出し、夫は九時の訪問と口論を隠したくてそれに乗った、というもの。夫から見ると、姉は頼まれもしないのにかばって嘘をつき、それが裏目に出たので、面会で「すまない、俺のためにあんな嘘まで」と頭を下げることになる。改稿はしていない。
  - 評価役（Opus・Sonnet・Codex）はv1とv2のどちらでもこの食い違いを挙げなかった。v1で評価役が「誰が嘘を言い出したか」の食い違いを挙げたのを、書き手が夫の動機を確かめずに直したことで、別の食い違いが生まれた。
- これを受けて、書く前に人物ごとの「知っていること・望んでいること・言動の理由」の表を作る手順（`scripts/writer_guide.md`）と、評価役の質問の16番「人物の行動の筋」、13番の要約の段落の指摘を足した。
- 足した質問で連城の方向のv2を評価し直すと（`judge_opus-check`・`judge_codex-check`）、OpusとCodexの両方が16番で、聴取で「私が頼んだわけじゃない」と姉を責めた夫が面会で泣いて礼を言う食い違いを挙げた。Opusは「自分を陥れた相手に礼を言う」典型と判定し、Codexは夫が受け止め直す一言がほしいという軽い指摘だった。13番では、二人とも有罪から面会までの段落を要約として挙げた。
